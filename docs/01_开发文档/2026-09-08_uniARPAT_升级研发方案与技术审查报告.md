## 2. 项目立项背景与学术定位声明

### 2.1 学位论文逻辑架构
- **第二章（已发表 npj 工作）**：基础篇——ARPAT 相对位置编码注意力 Transformer，攻克晶体长程周期性相互作用表征，实现单晶格声子态密度与动力学稳定性预测。
- **第三章（本工作：uniARPAT 升级版）**：方法篇——从单物理场迈向**电子-声子双连续态密度的统一联合表征**，解决任务间特征干扰与谱形锐利度瓶颈，构建零初始化门控跨模态特征交互机制与无泄漏 Shape-Scale 解耦架构。
- **第四章（应用篇）**：物性篇——从微观态密度到全温区宏观热力学函数推导，并结合定性热电/热物理描述符实现材料高通量粗筛与第一性原理精算复核。

### 2.2 严格学术声称边界（Anti-Overclaiming）
- **绝不声称“计算了微观电-声耦合矩阵元 $\alpha^2 F(\omega)$”**：明确界定跨模态注意力是潜空间能谱级唯象关联调制；
- **绝不声称“精确预测了热电优值 $zT$ 或超导 $T_c$”**：明确界定宏观输运计算为“唯象预筛选描述符”，严格依赖后续 DFT/BoltzTraP2 精算做最终定论。

## 4. Head 参数量精确重构表（参数对齐为约 0.8M）

彻底纠正旧方案中“30.7M vs 1.5k”的畸形结构，将两端输出头严格对称对齐在 **~0.8M 参数量**：

```
[phDOS 输出头: DeepConv1dHead] (0.788M)
Layer 0: Conv1D (in=512, out=256, k=3, p=1) + GELU  --> 512×256×3 + 256 = 393,472
Layer 1: Conv1D (in=256, out=256, k=3, p=1) + GELU  --> 256×256×3 + 256 = 196,864
Layer 2: Conv1D (in=256, out=256, k=3, p=1) + GELU  --> 256×256×3 + 256 = 196,864
Layer 3: Conv1D (in=256, out=1,   k=3, p=1)         --> 256×1×3   + 1   = 769
总参数量: 787,969 (~0.7880M)

[eDOS 输出头: MultiScaleResidualHead] (0.788M)
并联多尺度层 (Layer 0):
  - 分支 A (k=3): Conv1D (in=512, out=128, k=3, p=1) --> 512×128×3 + 128 = 196,736
  - 分支 B (k=5): Conv1D (in=512, out=64,  k=5, p=2) --> 512×64×5  + 64  = 163,904
  - 分支 C (k=7): Conv1D (in=512, out=64,  k=7, p=3) --> 512×64×7  + 64  = 229,440
  拼接输出通道: 128 + 64 + 64 = 256
残差卷积层 (Layer 1):
  - Conv1D (in=256, out=256, k=3, p=1) + GroupNorm   --> 256×256×3 + 256 + 512 = 197,376
投影输出层 (Layer 2):
  - Conv1D (in=256, out=1,   k=3, p=1)               --> 256×1×3   + 1   = 769
总参数量: 788,225 (~0.7882M)
```

**消融基准公平性确立**：两端输出头参数完全对称（差异仅 256 个参数，误差 $<0.03\%$），彻底排除容量悬殊对消融实验结论的干扰。

## 5. Shape-Scale 双分支数学规范与不可辨识性消解

```
                                [晶体结构输入]
                                       │
                                       ▼
                       [ARPAT 共享几何 Encoder]
                                       │
                 ┌─────────────────────┴─────────────────────┐
                 ▼                                           ▼
       [专用 eDOS Decoder]                         [专用 phDOS Decoder]
                 │                                           │
                 └──────► [Post-Decoder Zero-Init 门控] ◄────┘
                                       │
                 ┌─────────────────────┴─────────────────────┐
                 ▼                                           ▼
      [多尺度残差 eDOS Head]                       [深度 Conv1D phDOS Head]
                 │                                           │
                 ▼                                           ▼
      [eDOS_shape ∈ [0, 1]]                       [phDOS_shape ∈ [0, 1]]
       (支持带隙处精确预测为 0)                     (峰值绝对归一化为 1.0)
                 │                                           │
                 └──────────────┬────────────────────────────┘
                                ▼
                 [GlobalMaskedPool(H_enc)]
                                │
                                ▼
                   [标度回归头 MLP (3层, ~74k参数)]
                                │
                                ▼
                   [对数标度预测: ŝ_e, ŝ_p]
                                │
                                 │
                                 ▼
        [绝对物理能谱: ŷ_phys = ŷ_shape · exp(ŝ)] (ŷ_0^phdos 严格置 0)
```

### 5.1 数学定义与严格约束
1. **边界置零物理准则**：
   根据晶格动力学统计定义，声学支在深负虚频区极限为 0，在代码中显式锁定边界 $\hat{y}_0^{\text{phdos}} = 0$（$\omega = -280\text{ cm}^{-1}$ 处无物理态）；eDOS 则严格遵循非负非线性投影与费米能级物理约束。
2. **ReLU 归一化消解不可辨识性并保护带隙**：
   $$\hat{y}_{\text{shape}} = \frac{\text{ReLU}(z)}{\max_j(\text{ReLU}(z_j)) + 10^{-6}} \in [0, 1]$$
   - **保留精确零态**：当网络输出 $z \le 0$ 时，$\text{ReLU}(z) = 0$ 精确成立，使半导体禁带能区态密度严格为 0，彻底根除 Softplus 导致的禁带伪态；
   - **自愈退避机制**：若全谱输出偶发 $\max(\text{ReLU}(z)) \le 10^{-4}$，平滑回退为 Softplus 分支，持续供给正梯度杜绝死神经元；
   - **尺度唯一确定**：保证 $\hat{y}_{\text{shape}}$ 的最大值严格恒等于 1.0，从而使标度因子 $\exp(\hat{s})$ 唯一对应真实物理谱的最大峰强（Peak Intensity），完全消解标度乘积不可辨识性。
3. **全局掩码池化（GlobalMaskedPool）规范**：
   对原子特征张量 $\mathbf{H}_{\text{enc}} \in \mathbb{R}^{B \times L \times 512}$ 与原子有效掩码 $M \in \{0, 1\}^{B \times L}$（0 为填充，1 为有效原子）：
   $$\mathbf{h}_{\text{crystal}} = \frac{\sum_{i=1}^L M_i \cdot \mathbf{H}_{\text{enc}, i}}{\sum_{i=1}^L M_i + 10^{-6}} \in \mathbb{R}^{B \times 512}$$
4. **离群截断与 Huber 标度损失**：
   训练集中 `edos_max` 存在极端样本（最大 10618，p99.9 为 384），在训练前对标度标签施加软截断：$s_{\text{true}} = \log(\text{clip}(y_{\text{max}}, \text{min}=10^{-4}, \text{max}=500.0))$。
   标度头采用抗离群的 Huber 损失：
   $$\mathcal{L}_{\text{scale}} = \text{SmoothL1Loss}(\hat{s}, s_{\text{true}})$$

## 6. 物理空间损失函数修正与条件带隙掩码机制

### 6.1 形状相关性损失（带平坦谱退避机制）
在 $[0, 1]$ 归一化空间中计算 Pearson 相似度：
$$\mathcal{L}_{\text{shape}} = \begin{cases} 
1 - \frac{\sum_i (\hat{y}_i - \bar{\hat{y}})(y_i - \bar{y})}{\sqrt{\sum_i (\hat{y}_i - \bar{\hat{y}})^2 \sum_i (y_i - \bar{y})^2} + \epsilon} + 0.5 \cdot \text{MSE}(\hat{y}, y), & \text{if } \text{Var}(y) \ge 10^{-4} \\
\text{MSE}(\hat{y}, y), & \text{if } \text{Var}(y) < 10^{-4} \text{ (平坦谱退避)}
\end{cases}$$

### 6.2 逐样本条件带隙掩码（保护金属，精准约束半导体）
针对每个样本 $b$，先在线检测真值 eDOS 在费米面 $E_F \approx 0$（索引 63..64）处态密度：
$$\mathbb{I}_{\text{gap}}^{(b)} = \mathbb{I}\left( y_{\text{true}}^{(b)}(E_F) < 10^{-3} \right)$$
- 若 $\mathbb{I}_{\text{gap}}^{(b)} = 0$（金属材料）：**禁带损失恒为 0，绝对不产生误惩罚**；
- 若 $\mathbb{I}_{\text{gap}}^{(b)} = 1$（带隙绝缘体/半导体）：在 Fermi 窗口（索引 56..72，约 $[-1.18, +1.34]\text{ eV}$）内定位真实零值态区间，在归一化形状空间 $[0, 1]$ 施加带内二次惩罚并对带隙宽度 $N_{\text{gap}}$ 归一化（避免峰强极大的绝缘体产生过大绝对梯度而破坏多尺度损失平衡）：
$$\mathcal{L}_{\text{gap}}^{\text{edos}} = \frac{1}{\sum_b \mathbb{I}_{\text{gap}}^{(b)}} \sum_{b: \mathbb{I}_{\text{gap}}^{(b)}=1} \frac{1}{N_{\text{gap}}^{(b)}} \sum_{E \in \text{gap}^{(b)}} |\hat{y}_{\text{shape}}^{(b)}(E)|^2$$

### 6.3 真实物理空间声子总态数守恒
通过输入有效原子数 $N_{\text{atom}} = \sum_{i} \mathbb{I}_{\text{atom}_i > 0}$，在恢复后的物理绝对谱施加 $3N$ 守恒（频网步长 $\Delta \omega = 20\text{ cm}^{-1}$）：
$$\mathcal{L}_{\text{sum}}^{\text{phdos}} = \left( \frac{\sum_j \hat{y}_{\text{physical}}(\omega_j) \Delta \omega - 3 N_{\text{atom}}}{3 N_{\text{atom}}} \right)^2$$

### 6.4 静态加权总损失
$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{shape}}^{\text{edos}} + 3.0 \cdot \mathcal{L}_{\text{shape}}^{\text{phdos}} + 0.5 \cdot (\mathcal{L}_{\text{scale}}^{\text{edos}} + \mathcal{L}_{\text{scale}}^{\text{phdos}}) + 0.2 \cdot \mathcal{L}_{\text{gap}}^{\text{edos}} + 0.1 \cdot \mathcal{L}_{\text{sum}}^{\text{phdos}}$$
