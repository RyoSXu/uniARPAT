## 判读

**1）原 baseline − O0：旧几何打分路径的贡献（旧骨架内）**

- 事实：O0 同时移除局部层与旧几何打分。`LocalGlobalEncoder.forward` 对 `O0` 拒绝任何几何输入（`records` 或 `prepared_geometry` 非空即抛错）；全局层 `LegacyContentGlobalLayer.forward(h, padding_mask)` 只接收原子状态与 mask，`h` 来自原子序号嵌入（`atom_feat = z_only_proj`）；尺度头（`eta_head`）读取 encoder 输出 `memory` 的池化量，原子级 phDOS 头同样读取 `memory`。因此 O0 对结构不敏感，与同组成预测谱差约 1e-7 的结果一致。
- 因此，该差值衡量的是**旧骨架中全部结构输入路径**的作用，不是单个几何项。
- 结果：可分辨差异集中在 phDOS（blind R² +0.0099 [+0.0021, +0.0183]，blind 失败率 −0.78 pp [−1.34, −0.26]；oracle R² +0.0104 [+0.0023, +0.0178]）与 eDOS blind MAE（−0.0269 [−0.0515, −0.0019]）。eDOS R² 与失败率在两种口径下区间都含 0。
- 判读：支持旧几何路径**有条件、幅度较小**的贡献，主要在 phDOS；不支持其对 eDOS 中位 R² 或失败率有可分辨贡献。不证明其方向参数化符合 E(3)。
- 补充（推断）：仅依赖原子组成的 O0 已达 eDOS blind R² 0.4691，与原 baseline 的 0.4729 差距不可分辨。在本协议下，结构路径对 eDOS 中位 R² 的增量较小；这是对数值的解读，未做单独分解验证。

**2）O1 − O0 与 C1 − G0：局部更新在两种骨架中的收益**

- 旧骨架（O1 − O0）：eDOS blind R² +0.0102*，eDOS blind MAE −0.0429*，eDOS oracle 失败率 −0.91 pp*，phDOS R² +0.0177*（blind）/ +0.0175*（oracle）；eDOS blind 失败率 −0.56 pp 与 eDOS oracle R² +0.0039 区间含 0。
- 新骨架（C1 − G0）：eDOS blind R² +0.0121*，eDOS blind MAE −0.0435*，eDOS blind 失败率 −1.17 pp*，eDOS oracle 失败率 −1.04 pp*，phDOS R² +0.0140*（blind）/ +0.0159*（oracle）；eDOS oracle R² +0.0090 区间含 0（下限 −0.0001）。
- 判读：局部更新在两种骨架中方向一致、幅度相近。两者差异主要在显著性（旧骨架的 eDOS blind 失败率区间含 0，新骨架显著），但二者之差未被区间分辨（见 4）。收益同时包含局部层的参数与容量（O1 比 O0 多 342,144 个参数；C1 比 G0 同样多出局部层参数）与训练轨迹，不能拆开。
- 与 2026-10-12 G0 日志一致：C1 − G0 的 eDOS blind R² +0.0121* 与该日志的 C1 − G0 结果相同。

**3）O0 − G0 与 O1 − C1：骨架整体差异**

- 无局部（O0 − G0）：eDOS blind R² +0.0204*，eDOS oracle R² +0.0154*；eDOS 失败率 blind −2.77 pp*、oracle −2.90 pp*；phDOS R² +0.0193*（blind）/ +0.0185*（oracle）。eDOS MAE 与 phDOS 失败率区间含 0。
- 有局部（O1 − C1）：eDOS blind R² +0.0184*，eDOS oracle R² +0.0103*；eDOS 失败率 blind −2.16 pp*、oracle −2.77 pp*；phDOS R² +0.0230*（blind）/ +0.0201*（oracle）。
- 判读：两种局部条件下旧骨架都优于新骨架，幅度相近，说明这一骨架差距不依赖是否加入 C1，也不是由局部分支引入的。O0 与 G0 都没有结构输入，因此 O0 − G0 是两个“纯内容骨架”的差异。它包含：可学习 Q/K/V/O 投影、post-norm 与 pre-norm 位置、残差与 FFN 结构、内部初值（O0 沿用原 baseline 未训练张量；G0 沿用未训练 B+ L2/G6 参考的剩余张量，二者来源不同），以及参数量（G0 75,552,068，O0 69,248,324）。G0 参数更多却更差，容量不是该方向的充分解释。
- 当前不能唯一归因于 LayerNorm、Q/K/V 或残差；设计要求的后续拆分尚未进行。
- 按项目平局描述线（|ΔR²| < 0.02 且 |Δ失败率| < 1 pp，见 `decisions.md`），骨架差的 eDOS 失败率（−2.2 至 −2.9 pp）与 C1 − G0 的 eDOS blind 失败率（−1.17 pp）超出线外；多数局部与 phDOS 差值在线内。平局线只描述单次比较，不关闭假设。

**4）两种局部收益之差：局部与骨架的交互**

- (O1 − O0) − (C1 − G0) 的 12 项区间全部含 0；点估计 |Δ| 在 eDOS blind R² 上为 0.0020、eDOS oracle R² 上为 0.0051，失败率最大 0.61 pp。
