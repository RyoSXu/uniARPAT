## 证据

- **可复现工具：**`tools/eval/edos_error_attribution.py`；新增基础合同测试 `tests/test_edos_error_attribution.py`。脚本会拒绝覆盖已有结果，除非显式传 `--force`。
- **对齐与重现：**测试行数 2,287；`test_index.npy` 与 ID 锚定的 D4 sidecar 完全同序，D4 phDOS 分数与 B7 样本表一致。重新加载 epoch 33 checkpoint 后，eDOS oracle 与 blind 逐样本 R²分别复现官方 CSV，最大差值小于 `2e-5`。
- **官方 Q1 基线：**oracle eDOS med/fail=`0.51835/5.728%`；blind=`0.48012/8.658%`。
- **主要谱形关联：**相邻 bin 粗糙度定义为归一化谱形 `0.5 × Σ|p[i+1]−p[i]|`。以 train p90 `0.3516001` 分层，test 高组 `n=221`，oracle 中位 R² `0.3248`，其余 `0.5318`，差 `−0.2070`，bootstrap 95% CI `[-0.2488, -0.1432]`。失败率差 `+3.18` 个百分点，95% CI `[-0.25, +7.27]`，尚不能确认失败率增幅。
- **coverage 混杂敏感性：**高粗糙度组中只有 33/221 条部分 coverage。仅在全覆盖样本中比较时，高粗糙度仍有 188 条，oracle 中位差 `−0.1423`，bootstrap 95% CI `[-0.2045, -0.0947]`；因此主关联不是仅由 mask-off 子集造成。高熵与高 peak-share 在全覆盖样本中的失败率差仍分别为 `+5.72/+7.44pt`，95% CI 均不跨零。
- **失败尾部：**train p90 以上的高熵谱（`n=235`）失败率 `10.64%`，其余 `5.17%`，差 `+5.47` 个百分点，95% CI `[+1.57, +9.33]`；高 peak-share 谱（`n=236`）失败率 `11.86%`，其余 `5.02%`，差 `+6.84` 个百分点，95% CI `[+2.85, +11.01]`。这些是目标侧诊断分层，不证明具体模型机制。
- **结构代理：**高 atom-count 组的 oracle 中位差 `+0.0081`（95% CI `[-0.0233, +0.0545]`）；高 unique-species 组差 `+0.0011`（`[-0.0319, +0.0329]`）。高体积/原子 p90 组中位数反而较高，差 `+0.0681`（`[+0.0404, +0.1038]`），但失败率差 CI 跨零。原子数、元素数、体积/原子、晶胞长宽比、训练集元素稀有度未显示简单、稳定的结构复杂度越高则 eDOS 越差关系。
- **coverage 敏感性：**58/2,287 个测试样本有部分 bin 不受 coverage 支持；共 1,906/292,736 个 bin 为 mask-off（0.65%），目标质量在 mask 外为零。生产 `evaluate_split` 取出 `edos_cov` 但 `per_sample_spectral_metrics` 对全部 128 bins 评分；这与 glossary 所述“coverage mask 用于评估”不一致。按受支持 bin 另算的全体 oracle med/fail 为 `0.51968/5.903%`，blind 为 `0.48193/8.526%`，对总成绩影响很小；但部分覆盖子集的 unmasked oracle fail 为 `12.07%`，blind fail 为 `25.86%`。本次不擅自改变官方分数定义。
- **blind 尺度：**oracle 与 blind 的 74 条样本由通过变为失败，7 条由失败变为通过；绝对 gamma 误差与 oracle–blind gap 的 Spearman `ρ=0.635`，说明 blind 尺度恢复是另一个误差通道，而非 oracle 谱形错误的替代解释。
- **边界：**高/低分层为观察性关联；bootstrap CI 未做多重比较校正。旧 `log-2026-09-14-eDOS归因.md` 属于 pre-Q 口径，本次只以 Q1 B7 重验结论，不直接比较两个测试池的分层效应。

## 结论

- **状态：closed（本次归因审计）；根因仍未证实。**当前最强的 oracle 误差关联是高粗糙度/复杂谱形的中位 R²损失；高熵和高峰值集中度则是更清晰的失败率尾部。简单结构标量没有解释这些主要分层，因此暂不据此升级为更复杂的几何消息结构。
- coverage 评分实现与术语约定存在不一致，但 mask-off bin 仅占 0.65%，替代 masked 分数对总体指标影响很小；该问题需单独决定是否新增并行指标或改变官方评分口径，不在本任务内修复。
- blind gamma 误差与 gap 相关，适合与 oracle 谱形误差分开看待；不可将修复 gamma 头当成 oracle 形状准确率的解释。
