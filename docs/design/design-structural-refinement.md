# 大方向路线图：结构条件谱形突破

目标是让模型从周期晶体结构中提取有用信息，并把它转换为更准确的 eDOS 谱形，同时保护 phDOS。本页记录
研究地图，不是封闭的候选清单、固定顺序或实施授权；Agent 可以提出这里没有列出的方向，也可以重构这些问题。

## 要理解的三个问题

1. **Encoder：结构信息是否被有效表示？**模型如何编码周期性、局部配位、方向和多尺度环境？哪些结构差异应保留在原子或晶体表示中，并能影响最终谱形？可以考虑现有 encoder 的改造，也可以提出全新结构编码器。
2. **Decoder/head：如何把表示转成不同谱？**共享 encoder 是否足够，eDOS 与 phDOS 是否需要独立 decoder、head 或更大的任务专属模块？B7 已使用不同的任务 query 和输出 head，但共享 decoder 参数；这只是当前实现事实，不预设最佳分工。
3. **数据与学习：eDOS-only 数据怎样发挥作用？**可讨论直接监督、预训练、迁移或其他训练机制，并同时评估标签质量、数据划分和它与架构的匹配。当前本地候选审计不支持简单扩充该集合以填补最近邻支持缺口，但没有测试其预训练或表征迁移价值。

## 当前证据与边界

- Q1 valid 同组成材料对中，目标谱差中位 TV 约 `0.270`，B7 预测约 `0.016`：支持结构条件响应不足的假设，但没有定位问题只在 encoder、decoder 或 head。
- 高粗糙度 eDOS 更容易出错；单独的 slope-loss pilot 没有改善精度，不能据此排除针对谱形的其他建模方式。
- G2、联合边内容、谱差辅助等具体实现没有获得精度提升。结论只针对被测方案，不等于结构信息、其他 encoder、任务 decoder 或所有辅助学习都无效。
- eDOS 与 phDOS 的 R²不可只凭数值高低解释为物理难度排名；两类谱的统计分布和输出口径不同。

## 方案空间

共享结构 encoder 加任务专属 decoder/head 是合理假设；几何 encoder 重构与任务专属解码器也可以作为一个整体架构评估。还可以提出其他共享方式、任务关系、谱表示、损失或数据学习方案。无需为了模块级归因把互相依赖的改动拆成连续小实验，也无需因为路线图未列出就排除新想法。

候选比较应围绕预测机制、现有证据、可用训练信号、成本和独立验证价值展开。主指标可看 blind eDOS 中位 R²与失败率，并保护 phDOS；若主张改善结构条件谱形，应配套能检验该机制的读数。具体设计和预算随选定假设制定，不在本路线图预先规定。
