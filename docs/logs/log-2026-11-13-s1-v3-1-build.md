# 日志：2026-11-13 — 视图 s1_v3_1（统一声子标签规则）

## 决定与依据

用户决定（2026-11-13）：对所有材料用同一套标签规则，从库表重新构建，而不是修补 v3。

- 规则 1：JARVIS 声子谱不作为标签。依据：跨来源测量（`results/runs/phonon_sources_20261112/report.json`，128 格）中，JARVIS 对 MP 声子的中位 E 为 0.37，MP 声子对 PhononDB 为 0.038；v3 基线在 valid 上，旧材料中 JARVIS 标签的平均 E 为 0.490，MP 为 0.198。
- 规则 2：计算结构与输入结构匹配不上（默认匹配不通过或晶系不同）的旧标签不用，eDOS 与 phDOS 一样。依据：v3 基线中这类 phDOS 行失败率 32%。
- 规则 3：旧标签被排除时，按新材料的同一规则从已链接的记录中选替代（来源优先级、体积最接近），没有就留空；一个标签都不剩的行移除。
- 不变：切分规则（化学式哈希，盐值同 v3）、其余标签、体积与"有争议"标记、test 只生成不读取。

### 与 v3 基线的配对比较

- 范围：两版 valid 都有、且标签来源相同的行（eDOS 6,267，phDOS 2,949）。
- 单位：phDOS 的 C 两版不同，v3.1 的 E 乘 C(v3.1)/C(v3) 换到 v3 单位。

| | 平均 E（v3 → v3.1） | 差值的 95% 区间（自助法） | 中位 E | R² 中位 | 失败率 |
|---|---|---|---|---|---|
| eDOS | 0.2803 → 0.2815 | [−0.004, +0.006] | 0.109 → 0.104 | 0.568 → 0.582 | 4.76% → 4.79% |
| phDOS | 0.1686 → 0.1615 | [−0.010, −0.004] | 0.112 → 0.103 | 0.797 → 0.810 | 2.31% → 2.88% |

- phDOS 分来源（平均 E）：旧材料 0.184→0.174，MP 0.151→0.149，PhononDB 0.091→0.094。
- 判读：
  - 事实：同一批样本上，phDOS 的平均 E、中位 E 和 R² 中位都变好，失败率略升（约多 17 个样本）；eDOS 没有可分辨的变化。
  - 限制：两次运行都只有一个 seed，最佳轮次也不同（20 对 25）。区间只反映样本抽样的波动，不含换 seed 的波动，所以还不能断言变好来自数据清理。
