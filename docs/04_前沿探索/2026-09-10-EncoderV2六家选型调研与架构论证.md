## 0. 结论速览

- **硬筛淘汰（当前固定环境原样不可行）**：PET（`BuildExtension` + C++17）、Orb（Git `pynanoflann` + 本机无 CMake）、MGT（作者配套仓含 `triton==3.1.0`）。
- **不作为依赖**：MACE 官方包（锁 `e3nn==0.4.4`，与已装 `0.5.6` 冲突）、eSCN/EquiformerV2 官方栈（旧栈 Torch 1.13 / 新栈 Torch 2.4，均非当前 2.2.1）、ComFormer（缺原生扩展 + 源码错误 + 根 LICENSE 为 GPL-3.0）。
- **采用路线**：在现有 `e3nn 0.5.6` 上**自研 ACE-style 等变块**（不是 `pip install mace-torch`），`N=3` 局域块 + 1 层全局 Transformer。
- **只借鉴不依赖**：PET-MAD-DOS 的谱头思想、MGT 的双视角 router 思想。
- **两招评分（修正后）**：谱感知 mask 预训练 8/10（需接 observed 谱 token 才算完整重构）；轻量双视角 MoE 7/10（先共享 memory + 软门控 + 消融）。

## 2. 六家调研卡（校正版）

### 2.1 MACE / ACE

- **原理**：ACE 用径向基 + 球谐构造系统多体局域基；MACE 把高相关阶张量积放进等变消息传递，在节点上高效形成高体阶消息。[MACE 论文](https://arxiv.org/html/2206.07697)；[ACE 理论](https://arxiv.org/abs/1911.03550)。
- **相对 2021 二体消息模型的增量**：高 body-order message、对称张量收缩、体阶增长与层数解耦；四体消息在其基准上两层即可达高精度。
- **环境**：**官方 `mace-torch` 不可直装**。官方 `setup.cfg` 要求 `Python>=3.10` 且精确 `e3nn==0.4.4`（[依赖文件](https://raw.githubusercontent.com/ACEsuit/mace/develop/setup.cfg)），与已装 `0.5.6` 冲突。基础 MACE 无 Triton/flash-attn/必须 CUDA 扩展，但可选 `cuEquivariance` 不属本路线。可行的是自研 ACE-style 块，不是装官方包。
- **权重**：有。`MACE-MP-0a` 覆盖 89 元素，MPtrj，PBE+U，small/medium/large；`MACE-MPA-0` 为 MPtrj+sAlex；另有 OMAT/OMOL 等不同领域模型。入口为 [mace-foundations](https://github.com/ACEsuit/mace-foundations) 与 [HF 组织](https://huggingface.co/mace-foundations)。均为能量/力势模型，不是 eDOS/phDOS encoder 权重。
- **接口**：官方 `MACE.forward()` 返回 `node_feats`、`node_energy`、energy/forces/stress（[源码](https://raw.githubusercontent.com/ACEsuit/mace/develop/mace/modules/models.py)）；`node_feats` 为完整 irreps，仅 `0e` 为旋转不变量。descriptor API 默认返回 invariant（[文档](https://mace-docs.readthedocs.io/en/latest/guide/descriptors.html)）。无 `[B,L,512]+global` 标准接口，需取 `0e` + mask pooling + Linear + lattice adapter。
- **谱证据**：无直接 eDOS/phDOS head/checkpoint。foundation paper 有 phonon/红外等力/MD/声子分析间接证据（[论文](https://arxiv.org/html/2401.00096)），不等价于直接回归 DOS。
- **License**：MACE 代码 MIT；`MACE-MP-0a/0b` 权重官方表为 MIT；OMAT/MATPES/OMOL/MH 等按表多为 ASL；ACE Julia 生态另行核对。
- **原文勘误**：旧文“纯 PyTorch + e3nn 0.5.6 即装即跑”错；“Small 1.8M/Medium 4.7M/Large 15M”与官方 release 数字不一致，不应引用；“DeepH/HamGNN 迁移证实 DOS 先验”无官方证据，已删。

### 2.2 eSCN + EquiformerV2

- **原理**：eSCN 把每条边主轴对齐到边向量，将稠密 SO(3) 张量积改写为稀疏 SO(2) 运算；EquiformerV2 在此卷积上加等变 attention、renorm 与 separable spherical activation。[eSCN](https://arxiv.org/html/2302.03655)；[EquiformerV2](https://arxiv.org/abs/2306.12059)。
- **增量**：约 `O(L^6)` 到 `O(L^3)` 化简，使 `Lmax=6` 在 OC20/OC22 可行；EquiformerV2 将其嵌入 Transformer，非 DOS 专用架构。
- **环境**：**官方原样不可行**。独立仓库锁定 Python 3.8 + Torch 1.13.1 + e3nn 0.4.4（[环境文件](https://raw.githubusercontent.com/atomicarchitects/equiformer_v2/main/env/env_equiformer_v2.yml)）；现代 FAIR-Chem 要求 Torch 2.4 系。当前缺 `torch_scatter`/`torch_sparse`。未发现必须 Triton/外部 flash-attn 的官方证据。
- **权重**：有但领域窄。EquiformerV2 官方 31M/153M（All+MD）在 checkpoint 表明确标注；S2EF-2M 档约 80M 级（`N@12_L@6_M@2` 配置，README 主表未直接标参数量，以 config 为准）（[checkpoint 表](https://github.com/atomicarchitects/equiformer_v2#checkpoints)）；eSCN 主模型约 200M 量级，能量/力/弛豫为主。
- **接口**：现代 backbone 可返原子 `node_embedding`，取 `l=0,m=0` 为标量；全局标准输出为 energy head pooling，无通用 global embedding；需另接 mask、pool、512 投影。丢弃 `l>0` 会浪费主要成本。
- **谱证据**：无。OC20 的 pDOS 分析数据不是其训练输出。
- **License**：两仓库代码 MIT；checkpoint/数据集授权按模型表另核，不用 OC20 CC BY-4.0 代替。
- **原文勘误**：旧文“纯 Python 直接跑在 torch 2.2.1”错；“OMAT24 checkpoint”未经证实，已删；“谱特征提取器”无引用，已降为无证据。

### 2.3 PET

- **原理**：局部有向边编码为 token，平滑 cutoff 局部 Transformer 更新 edge-message；原始 PET 非内禀严格等变，ECSE 为事后精确对称化协议。[论文](https://arxiv.org/html/2305.19302)。
- **增量**：放宽 irreps/CG 约束，直接在 Cartesian edge feature 上用标准 attention/MLP；边级消息避免一次聚合瓶颈。ECSE proof-of-principle 开销可达 backbone 三个量级，非免费等变层。
- **环境**：**环境不可行，淘汰**。官方 `setup.py` 用 `BuildExtension` 编译 `src/neighbors_convert.cpp`（[文件](https://github.com/spozdn/pet/blob/main/setup.py)），而 PyTorch 2.2 构建器加 `-std=c++17`，GCC 4.8.5 不支持。不存在官方免编译安装路径。
- **权重**：原始 Zenodo 含源码/设置与大体积 checkpoint（[Zenodo](https://doi.org/10.5281/zenodo.7967079)）；UPET/PET-MAD 在 HF 提供力场权重（[PET-MAD](https://huggingface.co/lab-cosmo/pet-mad)）；PET-MAD-DOS 另有 DOS 模型与 calculator（新包入口 `upet.calculator.PETMADDOSCalculator`，旧 `src/upet/ase/dos/calculator.py` 路径已迁移，以现仓为准）。
- **接口**：`TARGET_TYPE` 支持 atomic/structural，structural 用 `global_add_pool`/`global_mean_pool`；无 `[B,L,512]+global token` 合同；普通 PET 旋转性质非硬等变。
- **谱证据**：六家中直接 eDOS 最强。PET-MAD-DOS 输出 `dos_raw`、`dos_denoised`、`bandgap`、`fermi_level`（另有 `per_atom=True` 逐原子选项，字段名以现仓 `PETMADDOSCalculator.calculate_dos` 为准），能量间隔 0.05 eV；属后续 UPET 生态，无 phDOS 证据。
- **License**：原始 PET 代码 MIT；UPET 代码 BSD-3-Clause；Zenodo/DOS checkpoint/数据按各自记录核对。
- **原文勘误**：旧文“纯标准 PyTorch、100% 免编译”错；“PET-MAD-DOS 2024 专发论文”年份/出处不准，已按 arXiv:2508.17418 与 UPET 仓库口径修正；“MIT 全覆盖”错，已拆分。

### 2.4 Orb-GNS / Orb

- **原理**：Orb-v2 为 Encoder-Processor-Decoder 图网络，边含位移方向与距离，平滑 cutoff attention，坐标去噪预训练后监督能量/力/应力；非硬等变。[论文](https://arxiv.org/html/2410.22570)。
- **增量**：扩散去噪预训练、通用材料规模数据、平滑邻域 attention；面向 MLIP，非 DOS encoder 创新。
- **环境**：**固定环境不可行，淘汰**。`orb-models==0.4.1` README 要求另装 Git 版 `pynanoflann` 并明示不在 PyPI（[README](https://raw.githubusercontent.com/orbital-materials/orb-models/v0.4.1/README.md)）；其构建文件需本地 CMake + C++14（[CMake](https://raw.githubusercontent.com/dwastberg/pynanoflann/af434039ae14bedcbb838a7808924d6689274168/CMakeLists.txt)），本机无 CMake。Orb-v3 要求更高 Torch，非替代方案。
- **权重**：有。Orb-v2 / `orb-d3-v2` / `orb-mptraj-only-v2` 及 XS/SM，数据 MPtrj+Alexandria 或 MPtrj（[MODELS](https://github.com/orbital-materials/orb-models/blob/v0.4.1/MODELS.md)）。无 DOS head。
- **接口**：官方输出 graph energy、node force、stress；力为节点向量，非旋转不变 atom feature；无通用 embedding 合同。
- **谱证据**：无官方 eDOS/phDOS/head/checkpoint。
- **License**：Orb models Apache-2.0；`pynanoflann` BSD-2-Clause。
- **原文核验**：旧文对此家“环境不可行”判定正确，予以保留；权重获取口径收紧为官方 MODELS + S3。

### 2.5 ComFormer

- **原理**：iComFormer 用距离 + 相对三个周期参考向量的角度构造 SE(3)-不变图；eComFormer 用位移向量 + 球谐 + tensor product 构造 SO(3)-等变图。两者为两个变体，非官方组合双流 encoder。[论文](https://arxiv.org/html/2403.11857v1)。
- **增量**：晶胞被动对称、周期图片、手性区分写进图构造，复杂度 `O(nk)`。核心完备项为周期向量相关距离/角度，不应把显式二面角记为其原生提供。
- **环境**：**官方原码不可直接运行**。源码显式导入 `torch_sparse`/`torch_scatter`（当前未装）；官方环境为 Python 3.10/CUDA 11.6（[README](https://github.com/divelab/AIRS/blob/main/OpenMat/ComFormer/README.md)）；源码存在 `comforemr` 拼写与 `super(MatformerConv, self)` 类名错误（[源码](https://raw.githubusercontent.com/divelab/AIRS/main/OpenMat/ComFormer/comformer/models/transformer.py)）。
- **权重**：未确认官方 foundation checkpoint；论文为 MP/JARVIS/MatBench 任务训练结果，README 以从头训练为主。
- **接口**：官方以图级 pooling 后标量/分类为主，无原子 hidden + global token 标准 API。
- **谱证据**：无直接 DOS/PDOS/能带输出；仅 bandgap、formation energy、total energy、Ehull、体/剪切模量。bandgap 不是 DOS 曲线。
- **License**：AIRS 根 LICENSE 为 GPL-3.0，ComFormer `setup.py` 仅有 MIT classifier，子目录无独立许可，不能按 MIT 处理；闭源集成前需上游明确授权，故不依赖。
- **原文勘误**：旧文“环境可行/纯 PyTorch”错；“距离+角+二面角完备”夸大，已修正；“MIT”错，已改 GPL-3.0 风险。

### 2.6 MGT

- **原理**：并行编码 SE(3)-不变标量图与 SO(3)-等变方向图，去噪 + 对比预训练，再用 MoE-inspired router 按任务融合图级表示。[正文](https://www.nature.com/articles/s41467-026-73627-7)；[作者配套代码](https://github.com/Turningl/MGTransformer)（非大厂组织仓，以论文标题+联系邮箱对应认定）。
- **增量**：多视角非单流；角/边噪声恢复 + 跨视角对比；下游 attention gate 融合而非拼接。任务为 MP/JARVIS 形成能、带隙、模量、Ehull、GMAE/HOIP。
- **环境**：**环境不可行，淘汰**。作者配套仓 `environment.yml` 固定 Python 3.9、Torch 2.5.1/cu124、e3nn 0.5.4、DGL 1.1.1、PyG pt25/cu124，并含 `triton==3.1.0`（[文件](https://github.com/Turningl/MGTransformer/blob/main/environment.yml)），触发本任务 Triton 硬禁。注：同仓 `README` 另写 `e3nn==0.5.3`，与 yml 的 `0.5.4` 不一致，此处以 yml 为准。
- **权重**：有。作者配套仓含 pretraining 与 formation/bandgap/moduli/Ehull/GMAE 等 finetuned checkpoint，tutorial 约 12.24M 参数，大权重/数据另有 Zenodo。但运行栈仍为作者锁定栈，无当前 Torch 2.2.1 验证。
- **接口**：作者仓 `forward(se3_graph_batch, so3_graph_batch)`（`models/mgt.py`）在 finetune 返回 batch 标量，pretraining 返回 loss；不是 `[B,L,512]` encoder，无通用 global token API。
- **谱证据**：无 eDOS/phDOS/PDOS/能带/s谱 head；标量任务不等于谱证据。
- **License**：代码 MIT；论文/数据/checkpoint 分开核对。
- **原文勘误**：旧文“环境可行/纯 Python 无障碍”错；旧 Zenodo DOI 口径混淆数据与权重，已拆分；“直接映射 `[B,L,512]`”错，已按 `mgt.py`/`experts.py` 修正。

## 4. eSCN vs ACE 二选一

此处 ACE 指**现有 e3nn 0.5.6 上自研 ACE-style 块**，不是装官方 `mace-torch`。10 分制，分数越高越好；实现成本分数越高表示成本越低。

| 维度 | 权重 | eSCN 移植 | ACE-style 自研 | 依据 |
| :--- | :---: | :---: | :---: | :--- |
| 实现成本 | 30% | 4.5 | **8.0** | eSCN 需 SO(2) 对齐、Wigner-D、球面采样、PyG/FAIR-Chem 版本；ACE 可用 e3nn irreps/tensor product + 纯 Torch 稀疏边 |
| 小样本上限 | 35% | 7.5 | **8.5** | eSCN 高 `Lmax` 上限高但证据来自百万级能量力；11k 谱样本更需高体阶先验 + 浅层 + 正则；两者均无直接 DOS 证据 |
| 维护性 | 25% | 4.5 | **8.0** | eSCN 横跨 OCP/FAIR-Chem/独立仓，版本分叉；ACE-style 只维护图构建、irreps、block、1 层全局层 |
| 环境适配 | 10% | 2.5 | **8.0** | eSCN 官方依赖不对齐；自研 ACE 不引 `e3nn==0.4.4` pin、PyG 原生扩展、Triton、flash-attn |
| **加权** | 100% | **5.4** | **8.2** | 选 ACE-style；MACE-MP 权重仅作隔离环境参考 |

**裁定**：先做 `N=3` ACE-style 局域块。未来有百万级无标签结构、工具链升级、且 `Lmax>=4` 消融稳定增益时，再把 eSCN 作独立 P2 分支；不把两套主干同时塞入 v2。

旧文 7.23 vs 9.28 已废弃：其“MACE 零阻碍/小样本压制/18-22M 彻底解决过拟合”均无实验支撑，且隐瞒了 `e3nn==0.4.4` 冲突。

## 5. Encoder v2 骨架（可实施规格）

### 5.1 层数、通道、稀疏图

| 模块 | 规格 | 理由 |
| :--- | :--- | :--- |
| 周期图 | CIF 分数坐标 + 晶格 `h` 枚举图片 `T`，`r_cut=5.5 Å`；`max_neighbors=48` 上限，保留真实半径边 | 稀疏边；边带 `T`；禁把分数坐标当欧氏距离 |
| 节点初值 | `Embedding(Z, 96)` + occupancy + 确定性元素属性 MLP -> `128x0e` | 元素属性须由元素/CIF 派生，不输 DFT 电荷/磁矩 |
| 局域块 | `N=3` residual ACE blocks；`nu=[2,2,3]`；`Lmax=2`，主 irreps `128x0e + 48x1o + 24x2e`，另小 `0o` 手性通道 | `nu=2` 覆盖三体角，末块 `nu=3` 承担四体/扭转；浅层防过平滑 |
| 原子投影 | 取 `0e` + 受控 `0o`；`0e` 走 MLP，`0o` 只走线性/由 `0e` 门控，再 `Linear->512` | 仅标量/伪标量可进旧 decoder；禁把 `l>0` 直接喂普通 Linear |
| 全局层 | `[global_token, atom_tokens]` 上 1 层标准 Transformer，`d=512`，8 heads，FFN 1024；不加坐标依赖伪 bias | 输入已旋转/平移不变，标准 attention 保置换不变 |
| 参数 | 目标 12–20M；`Lmax=3`、`nu=3` 作独立消融，不先追 75M | 11k 样本先控方差再定上限 |

旧文“18–22M 精简 70% 彻底解决记忆”改为目标区间 + 消融决定；`128x0e+64x1o+32x2e` 收紧为 `128x0e+48x1o+24x2e` 以控显存。

### 5.2 距离、角、二面角、晶格清单

1. **距离**：64 维 Bessel/Gaussian radial basis × 五次平滑 cutoff；`f_cut(r_cut)=0` 且一、二阶导连续为 0；边含中心/邻居元素 embedding 与 occupancy；`r=0` 处取极限处理。
2. **角**：ACE 球谐聚合 + tensor product 隐式产生 `cos(theta)` 三体不变量；另在 ablation 保留 line-graph `cos(theta)`，避免“用了方向”误记为“用了角”。
3. **二面角**：三条周期位移边算 `phi`，加 `cos(k phi)`/`sin(k phi)`，`k=1..4`；`cos` 为 `0e`，`sin` 为 `0o`/伪标量分支；若定 O(3) 目标则删 `sin` 并接受镜像不可区分。
4. **周期性**：边存整数 `T` 与 Cartesian 位移 `r_j-r_i+hT`；邻居与 line graph 均以此为准；对等价晶胞重标定做单测。
5. **晶格**：`G=h^T h` 6 独立分量、`det(h)`/体积、`G^{-1}` 6 分量、局部边相对晶格投影；`G` 只表度规，手性由 `0o`/signed dihedral 表。
6. **对称性/占位**：空间群号、晶系 embedding、occupancy 只作 scalar；缺失用 unknown bucket，不要求 CIF 必有正确对称标签。

### 5.3 与 query decoder 对接

```text
CIF: Z, frac_pos, h, T, spacegroup, occupancy
 -> pure-Torch periodic sparse graph (r_cut=5.5 A)
 -> radial + spherical harmonics + line-graph angle/dihedral + lattice scalars
 -> ACE-style equivariant blocks x 3
 -> invariantize: 0e (+ controlled 0o) -> atom_proj
 -> H_atom [B,L,512]
 -> [global_init, H_atom] -> one 8-head global Transformer
      |                                  |
      |                                  +-> H_atom [B,L,512], mask_atom [B,L]
      +-> h_global [B,512]                +-> old edos/phdos query decoder
                                          +-> old heads/loss/eval unchanged
```

边界：`memory=H_atom`，`memory_key_padding_mask=mask_atom`；`h_global` 接 `ScaleHead`/global adapter。禁把 `l=1/2` 原始系数交旧 decoder；禁让 decoder 读绝对笛卡尔坐标。旋转、平移、置换、图片重编号、晶胞基变换逐项单测。

旧文 `[B,1,512]` 与 `[B,512]` 混用，已统一：`ScaleHead` 用 `[B,512]`，仅当作 token 拼接时才为 `[B,1,512]`。

## 6. 两招复核

### 6.1 谱感知预训练：mask 能量 bins

**结论：可做，但“只 mask 目标 bin”不是完整自监督。** Encoder 只看 CIF 时，随机遮目标只是 loss mask/谱增强；完整重构还需预训练 decoder 接收未遮蔽谱 bin/value token，微调/推理再移除。

协议：

1. Encoder 输入恒为 CIF 结构；预训练 head 另接能量坐标 embedding、bin value、`observed_mask`，不进下游推理。
2. eDOS 128、phDOS 64 分别 20–35% 随机 mask + 一段连续 mask；Fermi 附近/phDOS 光学支可 oversample，验证集用自然分布。
3. 损失用 masked Huber + 一阶谱差分；约束非负与积分/scale，避免学均值谱。
4. 只复用已有 11k/已下载谱目标；不输 DFT 电荷/波函数；先做结构 split、去重、元素长尾处理。
5. 下游剥离 mask head；若只做 loss-mask，必须报 masked spectral regression，非无标签增益。

评分 **8/10**（旧文 9.5/10 下调）：零新增 ab initio 成本、与 128/64 query 轴匹配；风险为谱规模仍约 11k、归一化伪收益。

### 6.2 不变/等变双视角 MoE

**结论：做轻量版，不移植 MGT。** MGT 证据限于晶体标量 benchmark，且作者配套栈被 Triton 淘汰；此处只借鉴思想。

- `E_inv`：ACE `0e` + 周期角/二面角 + lattice metric；
- `E_eq_to_inv`：先对 `l=1/2` 做 equivariant product/contraction 得 `0e`（可留 `0o`），禁普通 Linear 直投并称不变；
- `router`：输入 `mean(H_inv)`、`mean(H_eq_to_inv)`、lattice token、spacegroup embedding，输出 per-channel sigmoid/softmax；先软门控不用 top-k；加 `1e-3` 量级负载/熵正则防 11k 路由坍塌；
- 第一版输出共享 `memory[B,L,512]`，让 eDOS/phDOS queries 在 cross-attention 自选通道；改双 memory 须同步改 decoder API。

评分 **7/10**（旧文 8.0/10 下调）：“电子偏 invariant、声子偏 equivariant”仅为假设，须做 gate 可视化、固定 gate、单视角、无 router 消融。

## 7. 落地分阶段（不设本周/下周硬时间）

- **P0 骨架**：纯 Torch + e3nn 0.5.6 写 3 层稀疏周期 ACE encoder + lattice/dihedral；输出对齐 `[B,L,512]+[B,512]`；过旋转/平移/置换/图片/晶胞基单测。
- **P1 谱预训练**：存量谱 mask 重构；验证少样本带隙/DOS 收益；报告归一化口径。
- **P2 MoE**：顶层双流 + 软门控；与 `decoupled_decoder` 对接；做路由消融。
