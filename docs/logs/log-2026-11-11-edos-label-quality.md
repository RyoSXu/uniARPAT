# eDOS 标签质量测量：分辨率与 Static（2026-11-11）

[标签契约 v2](../design/design-2026-11-11-label-contract-v2.md) 执行计划第 3 步的电子谱部分，在 PhononDB 下载期间提前做（用户经评审会话同意）。
只读，不训练，不改库表、冻结标签或 checkpoint；旧 test（test_q1）材料一条谱都不读。声子谱部分（64/128/256）等 PhononDB 完成后再做。
这里只列证据，“用哪个分辨率”“哪些 Static 组进训练集”由用户决定。

## 口径

- 脚本 `tools/data/spectral_store/measure_edos_label_quality.py`（`nice 19`，3 进程，约 6 分钟）。
  产物 `results/runs/edos_label_quality_20261111/{report.json, pairs.parquet}`，本地，不进 Git。
- 窗口 [−6, 6] eV，128 格（箱宽 0.09375 eV）与 256 格（0.046875 eV）。v2 两侧都用 `common.exact_bin`；v1 两侧都用旧规则 `box_average`。
- 每原子 E = Δx·Σ((a/N_a − b/N_b)²)/C，N 取各自计算晶胞的原子数。
- **C 的取法**：
  - v2 的 C 按 `fit_task_normalizer` 同一定义，在旧 train 材料（17,483 个）的规范 eDOS 上拟合：128 格 C = 11.971，256 格 C = 14.046。
    v1 沿用 C = 5.5427。v2 的 C 是临时值，正式值等新训练集定好后重拟。
  - 256 格主口径用 256 格自己拟合的 C（下称“自身 C”）。这样 E 在两种分辨率下都表示“误差平方积分 ÷ 同分辨率下标签自身的平方积分均值”，可以直接比。
  - 256 格同时给出沿用 128 格 C 的数（下称“128 格 C”）。分得更细后能看见更多尖峰，标签自身的平方积分大 17%，所以用 128 格 C 时 E 系统偏高约 17%。
- **配对规则**（每个材料一对）：
  - 重复计算：MP 规范任务对同材料另一个 NSCF Uniform 任务，选计算体积最接近输入结构的一个。9,203 对，全部同泛函；其中旧 train 4,514、旧 valid 573、新材料 4,116。
  - Static：规范任务对同材料体积最接近的 Static 任务，57,846 对。
- 金属/有隙按规范谱判定：E=0 处空带宽度 < 0.15 eV 记为金属，与 `verify_store fallback_v2` 相同。
- h2 对照：valid 2,313 个材料的 blind eDOS E，取自 `results/runs/phdos_head_20261106/analysis/exports/h2_s42_samples.csv`。
  它只存在于旧契约（v1，128 格），只能和 v1 列比较。还没有任何模型在 v2 标签上训练过。

### 尾部（v2 128 格）

- 均值受极少数异常对支配。
  - GGA Static 金属组最大的一对 E ≈ 131,000（4 原子金属，原子数和体积都一致），一对就占该组 E 总和的 71%。
  - GGA Static 中 E > 10 的有 201 对（0.4%）。去掉这些后，有隙/金属组均值为 0.220 / 0.299。
  - GGA+U Static 只有 2 对超过 10。
- 重复计算组 E > 1 的约 3.7%，前 1% 的对贡献了 41% 的 E 总和。
  原子数或体积不一致的对只有 17 对，不能解释尾部；推断是磁态或占据不同的另一次计算（未逐条核实）。
- 旧 train、旧 valid 与新材料三部分的重复计算中位数分别是 0.014 / 0.015 / 0.016，彼此一致。

## 判读（事实与推断分开）

1. **标签噪声的中位数很小，均值由少数“同材料两次计算结果明显不同”的情况决定（事实）。**
   - v2 128 格重复计算中位 0.014，但均值 0.204、P90 0.352。
   - 用中位数比较时，噪声远低于任何模型误差。用均值比较时，噪声与模型误差同一量级，原因是约 4% 的材料有两种明显不同的“正确答案”。
2. **旧分箱规则本身给标签加了噪声（事实＋推断）。**
   - 同样的重复计算对，v1 中位 0.108，v2 只有 0.014。按 C 换算到同一单位，v1 约为 v2 的 3.6 倍。
   - 推断：两次计算的能量采样点相对箱边的位置不同，`box_average` 漏掉的箱边面积也就不同。
   - 在旧契约下，重复计算噪声的中位（0.108）已是 h2 valid 中位（0.162）的 2/3，均值（0.379）甚至高于 h2（0.332）。旧标签的噪声在 h2 误差里占很大一部分。
3. **256 格对比 128 格（事实）。**
   - 用自身 C 时，重复计算中位从 0.014 升到 0.019（有隙 0.030→0.039），均值从 0.204 升到 0.222。
   - Static 组几乎不变：GGA+U 中位 0.061–0.078，GGA 0.079–0.085。
   - 即 256 格的标签噪声在比例上略高，但仍远低于 Static 差异和现有模型误差。256 格下模型误差会怎样，没有数据。
4. **Static 与规范标签的差异（事实）。**
   - 中位数约为同条件重复计算的 2.5–7 倍：GGA+U 0.06–0.08，GGA 约 0.08；对应重复计算是有隙 0.030、金属 0.011。
   - GGA+U 两组的均值（0.14–0.16）与 P90（0.31–0.32）不高于重复计算组。
   - GGA 两组的 P90 偏高（0.47 / 0.67），且有数百条数值异常巨大的谱，均值没有意义。
   - 与 h2 的比较只能在 v1 下做。Static 各组 v1 中位 0.34–0.57，都高于 h2 的 0.14–0.18；v1 下 Static 的差距被旧分箱规则在稀疏网格上的伪差放大（见[平移检查](log-2026-11-10-fallback-shift-check.md)），所以这一比较对 v2 下的去留只有参考意义。

## 局限

- 重复计算样本只来自有两次 NSCF Uniform 计算的材料（GGA 占 96%，GGA+U 只有 400 对），不一定代表全体。
- 金属/有隙的划分对稀疏网格不敏感，因为一律按规范谱判定。
- 没有在 v2 标签上训练的模型，v2 下“噪声 vs 模型误差”的比值要等第 5 步新基线。
- 尖峰截断未施加；新契约的截断阈值要在新标签上重拟（第 2 步）。
