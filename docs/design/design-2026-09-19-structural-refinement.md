# 研究方向

## 1. 元素初始化模块
目前固定为 ZP (原子序号 → Embedding → LayerNorm → Linear → Encoder)

## 2. Encoder

研究模型如何保留周期性、局部环境以及同组成材料之间的结构差异。
周期镜像几何与局部原子表示更新已接入，结构信息已参与消息内容。当前固定联合训练，以 valid blind 中位 R² 为主指标，两任务等权选点并分别检查 R² 与失败率；Oracle MAE 与同组成谱差仅作诊断。[修正骨架的完整 A/B+ 对照](design-2026-10-15-i1-a-encoder.md)已完成，blind 主表未检出相对 I1 的明确优势，本轮保留 I1，不继续更换局部公式。新选点已实现，后续对照须使用相同选点口径，再制定表示、传播或联合监督干预，同时保留旋转及等价晶胞一致性要求。

最终两类谱须满足 **E(3) 不变性**，包括整体平移、旋转和反射。中间可使用等变特征，但须通过
保持对称性的运算生成不变输出。设计时比较距离/夹角等不变量与等变中间特征加不变读出两条
路线，分别说明依据和成本；几何、完整模型数值证据和架构保证不能互相替代。具体要求见
[`design-2026-10-04-e3-output-invariance.md`](design-2026-10-04-e3-output-invariance.md)。原子重排与等价晶胞表达另作
一致性检查。

## 3. Decoder 拆分

研究在共享结构编码之后，为两类谱设置独立 decoder 是否更合适，以及共享到哪一层。

## 4. 大规模数据利用

利用大量结构数据进行预训练，也探索 eDOS-only 数据的监督学习与迁移，最终看它们能否改善当前任务。
