## 结果

两臂各2000步完整结束，判定为`joint_adaptation_fit_only`。所有16对的目标差均非零，没有用
零目标差样本凑通过数。以下“残留”均以该任务的零谱差预测作为参考，不是相对原模型准确率。

### 1. 联合臂获得全对拟合见证，冻结臂只通过一半

| 指标 | 冻结encoder | 联合encoder／读出 |
|---|---:|---:|
| 首次全部16对通过 | 2000步内未达到 | 第700步 |
| 第2000步通过对数 | 8／16 | 16／16 |
| 末步平均谱差MSE | 0.0274869 | 0.000032602 |
| 末步整体MSE残留 | 1.44894% | 0.001719% |
| 末步平均谱差TV误差 | 0.0274278 | 0.00107528 |
| 末步整体TV残留 | 9.37977% | 0.367725% |
| 末步最差pair的MSE残留 | 73.5313% | 0.129526% |
| 末步最差pair的TV残留 | 83.7287% | 2.09921% |

- 每对门槛为MSE残留≤1%、TV残留≤10%。冻结臂均值已经很低，却有8对未通过，所以不能由
  平均损失下降宣布全部可拟合。各检查点最多也只有8对通过。
- 联合臂第200步达到8对通过，第600步14对，第700步首次16对；第700…1800步的预定检查均
  通过，**第1900步回退至14对**（pair5和pair14），第2000步恢复16对。第700至2000步的14个检查点
  中有13个通过。可拟合权重存在，但优化过程不是单调稳定；完整轨迹和回退均保留。
- 具体例子：pair0（`mp-aaaaabjd`／`mp-aaaaarxw`，同24原子的P/Cd计数）目标谱差TV为
  `0.211629`，源预测仅`0.000104`，源memory匹配相对RMS为`0.001995`。冻结读出末步残余TV
  占目标83.73%；联合后为0.181%，预测TV达到`0.211771`。这是一对原信号微弱、但实际网络通过
  联合适配能拟合的实例，不是跨材料族的泛化证据。

## 结论与交接

- **状态：complete；获得联合网络的小样本可拟合性见证。**在同样初值、目标和2000步预算下，
  encoder参与适配使16个固定train材料对全部达到门槛；冻结encoder的实际读出没有达到同一门槛。
  本轮支持encoder适配对这批样本学习效率／可达到拟合程度的作用，不支持将前两轮失败解释成
  整条调用链不可能学习这些差异。
- **仍不能推出：**固定表征绝对没有标签信息、只有解冻才能拟合、几何在某一层被彻底丢失，
  或方案能跨组成泛化。冻结臂已拟合8对，剩余失败仍可能涉及条件差、优化与预算；联合臂是整块
  encoder加读出的组合，不能单独归功于G2几何Value消息。一个选样／初始化也不能代表全部Q1。
- 前两轮全配对任务每对只有10次暴露，本轮每对2000次。这个差别提示原10轮结果没有证明
  学习充分，但本轮同时缩小了数据规模，不能单独把全体失败归罪于暴露次数不足。
- **下一项具体建议：**保持这16对、初值、读出和预算，将encoder可训练范围收窄为6个G2消息
  模块，冻结其余encoder。若仍能获得16／16拟合，支持只适配几何Value分支已足够；若失败，只
  否定这个更新范围，不能断言G2无用。这将沿调用链缩小成功所需的更新范围；尚未启动新训练。
- status和index已同步结果与下一项建议；默认模型、全局流程规则及既存decisions修改保持。
  本轮新增小样本入口、测试与结果未提交；之前两轮已由`7075fdc`保存。
