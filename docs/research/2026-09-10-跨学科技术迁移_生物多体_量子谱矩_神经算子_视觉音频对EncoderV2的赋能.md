$$D(E) = -\frac{1}{\pi} \operatorname{Im} \operatorname{Tr}\left[ (E + i\eta - \hat{H})^{-1} \right]$$

预测态密度本质上是一个**从离散晶体几何到连续算子本征谱函数的无限维映射问题**！
这就要求我们的编码器必须具备：

4. **受限环境下的极端计算吞吐**（突破老旧系统无 Triton 的算子瓶颈）；

跨越材料力场狭隘边界，从**生物结构预测、量子紧束缚谱论、科学计算神经算子、3D 点云视觉与音频频域建模**五个顶级学科汲取养分，是构建自主突破性 Encoder v2 的必由之路。

## 2. 领域一：生物大分子结构预测（AlphaFold 2/3 / Pairformer）向晶体几何块的迁移

### 2.1 三角乘法更新（Triangle Multiplicative Update）张量收缩数学本质

在 AlphaFold 2/3 (Evoformer / Pairformer) 中，残基/原子间的几何关系由二维边对表征（Pair Representation）$Z \in \mathbb{R}^{B \times N \times N \times c_z}$ 维护。其核心运算为**三角乘法更新（Triangle Multiplicative Update, TMU）**：

#### (1) 流出边模式 (Outgoing Mode, AF2 Algorithm 11)
$$A_{ik} = M_{ik} \odot \left[ \sigma(W_{ga} \tilde{Z}_{ik}) \odot (W_{pa} \tilde{Z}_{ik}) \right] \in \mathbb{R}^c$$
$$B_{jk} = M_{jk} \odot \left[ \sigma(W_{gb} \tilde{Z}_{jk}) \odot (W_{pb} \tilde{Z}_{jk}) \right] \in \mathbb{R}^c$$
$$X_{ij} = \sum_{k=1}^N A_{ik} \odot B_{jk} \quad \Longleftrightarrow \quad \text{einsum}(\text{'b i k c, b j k c -> b i j c'}, A, B)$$
$$\Delta Z_{ij} = \sigma(W_g \tilde{Z}_{ij}) \odot \left( W_o \text{LayerNorm}(X_{ij}) \right)$$
$$Z_{ij} \leftarrow Z_{ij} + \Delta Z_{ij}$$

#### (2) 流入边模式 (Incoming Mode, AF2 Algorithm 12)
$$X_{ij} = \sum_{k=1}^N A_{ki} \odot B_{kj} \quad \Longleftrightarrow \quad \text{einsum}(\text{'b k i c, b k j c -> b i j c'}, A, B)$$

**物理直觉**：
将边 $(i, j)$ 视为三角形底边，更新遍历所有共享端点 $k$。若边 $i \to k$ 与边 $j \to k$ 在空间中真实相交闭合，特征逐元素积 $A_{ik} \odot B_{jk}$ 产生谐振共鸣，将三角形几何刚性约束一次性注入底边 $(i, j)$。

### 2.2 标量空间完全表达 3-body（键角）与 4-body（二面角）的理论证明

#### 定理：外尔不变性第一基本定理 (Weyl's First Fundamental Theorem for $O(3)$)
> 三维空间中任意点集的旋转/平移/反演标量不变量，均可完备表示为两两相对位移点积 Gram 矩阵 $G_{ab} = \mathbf{r}_a \cdot \mathbf{r}_b$ 的连续多项式函数。

1. **3-body 键角三角形完备性（启发式论证，非严格证明）**：
   对于空间三原子 $(i, j, k)$，由余弦定理：
   $$\mathbf{r}_{ik} \cdot \mathbf{r}_{jk} = \|\mathbf{r}_{ik}\| \|\mathbf{r}_{jk}\| \cos \theta_k = \frac{1}{2} \left( d_{ik}^2 + d_{jk}^2 - d_{ij}^2 \right)$$
   三角形的全部内外几何自由度完全由三边长 $(d_{ij}, d_{ik}, d_{jk})$ 决定。边特征 $z_{ik}$ 与 $z_{jk}$ 经由径向基（RBF）离散化后做逐元素积：
   $$[A(z_{ik}) \odot B(z_{jk})]_c = \sum_{p, q} W_{cp}^{(a)} W_{cq}^{(b)} \phi_p(d_{ik}) \phi_q(d_{jk})$$
   直接在标量空间张成了双变量函数空间 $\mathcal{H}(d_{ik}, d_{jk})$；再结合底边自身的 $d_{ij}$ 特征，在网络宽度足够、优化理想的假设下，双层 MLP 能够以较高精度逼近连续三体势函数 $V(d_{ik}, d_{jk}, \theta_k)$（依据 Stone-Weierstrass 定理的启发式类比，实际表达能力受限于 RBF 基数量、隐维与训练优化，不构成任意精度保证）。
2. **4-body 二面角闭合传递性（假设性外推，待实验验证）**：
   空间四原子构成的二面角 $\phi$ 完全由 6 个两两距离决定。当模型堆叠 **2 层** 三角乘法更新模块时，边特征沿回路 $i \to k \to j \to l$ 连续收缩，代数上覆盖了四元环的传递闭包，有望隐式编码二面角扭转相关的几何信息（该覆盖为必要条件而非充分条件，实际能否内化二面角能量需消融实验验证）。

### 2.3 为什么几何对空间能彻底绕过 Clebsch-Gordan 群论展开？

传统等变图网络（如 e3nn）将几何挂载在原子**节点**上（表示为球面谐波不可约表示 $l=0, 1, 2, \dots$），节点相互作用必须经过 Clebsch-Gordan (CG) 张量积展开，其朴素实现开销随阶数呈 $\mathcal{O}(l_{\max}^6)$ 爆炸（现代 e3nn / cuEquivariance 已通过对称收缩与融合核大幅优化，实际开销低于该上界），且高阶实现往往依赖定制 CUDA 编译。

而在 Pairformer 体系中，几何信息从一开始就被降维投射在**无向/有向边标量对**上。**两两欧氏距离本身就是 $E(3)$（平移、旋转、反演）不变量**。当模型完全在内积不变量流形上执行张量收缩时，可以在不显式构造 CG 系数的情况下建模多体几何（这是一种以放弃方向等变、损失矢量/张量分辨力为代价的权衡，而非无代价的“彻底保真”）。

### 2.4 稀疏晶体图适配：周期多重边与规范平移闭合条件（STMU 算法）

#### (1) 晶体小单胞周期多重边挑战
对于单胞仅有 $1 \sim 5$ 个原子的材料（如 FCC Cu, Si, 钙钛矿），截断半径 $r_{\text{cut}} = 5.5\,\text{Å}$ 远大于晶格常数。中心原子会与其在不同晶格位移 $\mathbf{n} \in \mathbb{Z}^3$ 处的周期性自身副本成键。稠密 $N \times N$ 对矩阵彻底失效（此时 $1 \times 1$ 无法表达 12 个等价配位键）。

#### (2) 周期三角规范平移闭合定理（Periodic Gauge Closure Condition）
考虑三条周期边：$e_{ik} = (i, k, \mathbf{n}_{ik})$，$e_{jk} = (j, k, \mathbf{n}_{jk})$，底边 $e_{ij} = (i, j, \mathbf{n}_{ij})$。
三者在欧氏实空间中构成封闭三角形的充要条件为：
$$\mathbf{r}_{ij} = \mathbf{r}_{ik} - \mathbf{r}_{jk} \quad \Longleftrightarrow \quad \mathbf{n}_{ij} = \mathbf{n}_{ik} - \mathbf{n}_{jk}$$

#### (3) 稀疏三角更新（Sparse Triangle Multiplicative Update, STMU）
预先构建满足规范闭合条件的三角形索引三元组 $\mathcal{T} = \{ (\text{idx}_a, \text{idx}_b, \text{idx}_{\text{target}}) \}$（注：$\mathcal{T}$ 本身的枚举构建代价未包含在下式内，是 STMU 落地的另一主要开销）。
收缩过程转化为稀疏聚合：
$$M_t = A[\text{idx}_a] \odot B[\text{idx}_b] \in \mathbb{R}^{T \times c}$$
$$X = \text{ScatterAdd}(\text{src}=M_t, \text{index}=\text{idx}_{\text{target}}, \text{dim}=0) \in \mathbb{R}^{E \times c}$$
复杂度由稠密的 $\mathcal{O}(N^3)$ 降至稀疏图上的 $\mathcal{O}(|\mathcal{T}|) \approx \mathcal{O}(N \cdot deg^2)$（$deg$ 为平均配位数；仅当 $deg$ 视为有界常数时才近似线性。例：$L=256, deg\approx30$ 时 $E\sim7680, T\sim230k \gg N$）。

### 2.5 纯 PyTorch 2.2.1 生产级稀疏三角更新实现（零编译）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SparseTriangleMultiplication(nn.Module):
    """
    基于原生 PyTorch 2.2.1 的晶体稀疏三角乘法更新模块 (STMU)
    完全规避 C++/CUDA 扩展编译，严格兼容 glibc 2.17 / gcc 4.8.5。
    """
    def __init__(self, c_edge: int = 128, c_hidden: int = 128, mode: str = "outgoing"):
        super().__init__()
        assert mode in ["outgoing", "incoming"]
        self.c_edge = c_edge
        self.c_hidden = c_hidden
        self.mode = mode

        self.norm_in = nn.LayerNorm(c_edge)
        self.proj_a = nn.Linear(c_edge, c_hidden)
        self.gate_a = nn.Linear(c_edge, c_hidden)
        self.proj_b = nn.Linear(c_edge, c_hidden)
        self.gate_b = nn.Linear(c_edge, c_hidden)

        self.norm_out = nn.LayerNorm(c_hidden)
        self.proj_out = nn.Linear(c_hidden, c_edge)
        self.gate_out = nn.Linear(c_edge, c_edge)
        
        nn.init.constant_(self.gate_out.bias, 1.0)
        nn.init.xavier_uniform_(self.proj_out.weight)

    def forward(self, z: torch.Tensor, tri_a: torch.Tensor, tri_b: torch.Tensor, tri_target: torch.Tensor):
        """
        z: [E, c_edge] 晶体稀疏图边特征
        tri_a, tri_b, tri_target: [T] 满足周期闭合条件的三角形边索引 (int64)
        """
        num_edges = z.size(0)
        z_norm = self.norm_in(z)

        # 1. 投影与门控
        a = self.proj_a(z_norm) * torch.sigmoid(self.gate_a(z_norm))  # [E, c_hidden]
        b = self.proj_b(z_norm) * torch.sigmoid(self.gate_b(z_norm))  # [E, c_hidden]

        # 2. 拓扑收集与标量核乘积 (3-body 相互作用核心)
        tri_feat = a[tri_a] * b[tri_b]  # [T, c_hidden]

        # 3. 原生 scatter_add 归约到底边 (纯原生底层原子操作)
        idx_exp = tri_target.unsqueeze(-1).expand(-1, self.c_hidden)
        x_agg = torch.zeros(num_edges, self.c_hidden, device=z.device, dtype=z.dtype)
        x_agg.scatter_add_(dim=0, index=idx_exp, src=tri_feat)

        # 4. 门控残差输出
        x_norm = self.norm_out(x_agg)
        delta_z = self.proj_out(x_norm)
        g = torch.sigmoid(self.gate_out(z_norm))
        return z + g * delta_z
```

## 3. 领域二：量子物理与紧束缚能谱理论（MACE-H / SlaKoNet / 矩定理）向输入先验的迁移

### 3.1 矩定理（Theorem of Moments）与自闭合随机游走（Closed Random Walks）严格推导

根据微观单粒子量子力学，态密度 $D(E)$ 的第 $n$ 阶原点谱矩 $\mu_n$ 满足迹定理：
$$\mu_n \equiv \int_{-\infty}^{+\infty} E^n D(E) dE = \frac{1}{N} \sum_{\alpha=1}^N E_\alpha^n = \frac{1}{N} \operatorname{Tr}(\hat{H}^n)$$

将算子投影至局域正交归一原子轨道基底 $\{|i\rangle\}$：
$$\mu_{i, n} = \langle i | \hat{H}^n | i \rangle = (\mathbf{H}^n)_{ii}$$
在基底乘积中插入完备性条件 $\sum_j |j\rangle \langle j| = \hat{\mathbf{I}}$，立即导出经典的 **Cyrot-Lackmann 局域矩定理**：
$$\mu_{i, n} = \sum_{j_1, j_2, \dots, j_{n-1}} H_{i j_1} H_{j_1 j_2} \dots H_{j_{n-1} i}$$
**数学本质**：原子的第 $n$ 阶能谱矩，严格等于微观紧束缚图上以原子 $i$ 为起点、经历 $n$ 步跃迁最终返回自身的**所有闭合随机游走路径（Closed Random Walks of length $n$）的跃迁振幅总和**！

---

### 3.2 前四阶谱矩的物理能带形态学对应（$\mu_1 \sim \mu_4$ 与 Haydock 递推连分数）

引入中心矩 $\mu_{i, n}^c = \langle i | (\hat{H} - \mu_{i, 1}\hat{\mathbf{I}})^n | i \rangle$ 与纯非对角跃迁矩阵 $\bar{\mathbf{H}}$：

| 谱矩阶数 | 图回路拓扑特征 | 固体物理与微观能带本质对应 |
| :--- | :--- | :--- |
| **一阶矩 $\mu_{i, 1}$** | 单点自环 ($H_{ii} = \epsilon_i$) | **能带中心重心**：对应原子有效电负性与主轨道在位势能。 |
| **二阶中心矩 $\mu_{i, 2}^c$** | 往返二步环 ($\sum_j H_{ij}^2 \approx Z_i t^2$) | **局域配位数与有效带宽**：带宽 $W \approx 2\sqrt{\mu_2^c} \approx 2\sqrt{Z_i}|t|$。 |
| **三阶中心矩 $\mu_{i, 3}^c$** | 三角形三元闭环 ($\sum_{jk} H_{ij} H_{jk} H_{ki}$) | **成键偏度 (Skewness)**：密排堆积(FCC/HCP)三元环密集 $\implies$ 能带非对称倾斜。 |
| **四阶中心矩 $\mu_{i, 4}^c$** | 四元环与二面角往返回路 | **能隙双峰分裂倾向 (Kurtosis)**：峰度 $\beta_2 \to 1.0$ 与双峰分布相关，可作为 Peierls 畸变与带隙开启的参考性关联指标之一（相关性而非直接判据，需结合其他证据） |

#### Haydock 递推连分数解析桥梁：
对角超前格林函数展开为连分数：
$$G_{ii}(z) = \frac{1}{z - a_0 - \frac{b_1^2}{z - a_1 - \frac{b_2^2}{\ddots}}}$$
其前两层系数与前四阶矩满足**完全闭式的一对一代数解**：
$$a_0 = \mu_{i, 1}, \quad b_1^2 = \mu_{i, 2}^c, \quad a_1 = \mu_{i, 1} + \frac{\mu_{i, 3}^c}{\mu_{i, 2}^c}, \quad b_2^2 = \mu_{i, 2}^c \left( \beta_{2, i} - 1 - \gamma_{1, i}^2 \right)$$
**重要推论（待验证）**：在紧束缚近似成立的前提下，前四阶局域矩可解析约束态密度主峰-双峰拓扑与带隙趋势，为谱矩先验提供理论动机（实际 DOS 还受长程、多轨道与自能展宽影响，需实验验证）。

### 3.3 现代紧束缚深度学习剖析：MACE-H vs. SlaKoNet 的得失与局限

- **MACE-H (arXiv:2508.15108, 2025；npj Comput. Mater. 2026)**：利用高阶等变多体张量积预测实空间 LCAO 哈密顿矩阵元 $\mathbf{H}_{ij}$。**适配阻碍**：uniARPAT 的 11k 样本只有最终连续 DOS 谱线，没有中间态 DFT 哈密顿矩阵标签，直接监督路径缺失（需迁移/弱监督才能复用）。
- **SlaKoNet (J. Phys. Chem. Lett. 2025, Choudhary；65 元素 / TB-mBJ / JARVIS-DFT，约 2 万材料)**：利用网络学习 Slater-Koster 参数，并构造 $H(\mathbf{k})$ 求解能带/DOS。**适配阻碍**：在批次训练下，大晶胞多 $k$ 点对角化计算复杂度为 $O(N_k \cdot N^3)$ 量级，反向传播开销大、显存压力高（具体“数百毫秒”取决于体系与硬件，此处为量级估计，非实测基准）。

### 3.4 零对角化提取：单次 BMM 矩阵幂恒等式（$L\sim100$ 量级 GPU 上约 $<0.5\,\text{ms}$，取决于硬件，待实测）

结合矩定理与矩阵代数恒等式（要求 $\bar{\mathbf{H}}$ 对称且对角线为零），提取前四阶矩**无需矩阵对角化**，全过程仅需 **1 次批量矩阵乘法（`torch.bmm`）**：
1. **二阶矩**：$\mu_{i, 2}^c = \sum_j \bar{H}_{ij}^2$ $\implies$ 元素平方求和，**0 次矩阵乘法**；
2. **中间矩阵**：$\mathbf{M} = \bar{\mathbf{H}} \bar{\mathbf{H}}$ $\implies$ **单次 `torch.bmm`**；
3. **三阶矩**：$\mu_{i, 3}^c = \sum_j M_{ij} \bar{H}_{ij}$ $\implies$ 矩阵点乘沿行求和，**0 次矩阵乘法**；
4. **四阶矩**：$\mu_{i, 4}^c = \sum_j M_{ij}^2$ $\implies$ 元素平方求和，**0 次矩阵乘法**。

### 3.5 纯 PyTorch 2.2.1 周期谱矩先验编码器（`PeriodicSpectralMomentEncoder`）

```python
import math
import torch
import torch.nn as nn

class PeriodicSpectralMomentEncoder(nn.Module):
    """
    单次 BMM 零对角化晶体谱矩先验编码器 (SMPE)
    注意：
    1. 本模块输出的是基于启发式指数跳跃的“伪谱矩”物理指纹，而非 DFT 真实哈密顿量的量子矩；
    2. 输入 distances 为最小镜像约定的稠密 [B, L, L] 距离，已将小单胞多重周期镜像坍缩为一条，
       与 §2.4 的多重边建模不一致，因此 SMPE 仅作为粗粒度先验，精细多体几何仍由 STMU 负责。
    在图卷积前向之前，为每个原子节点注入 [μ1, log(1+μ2), Skew, log(Kurt)] 物理指纹。
    """
    def __init__(self, d_model: int = 512, r_cut: float = 6.0, r0: float = 2.0, alpha: float = 1.5):
        super().__init__()
        self.r_cut = r_cut
        self.r0 = r0
        self.alpha = alpha
        self.site_energy_table = nn.Embedding(119, 1)
        nn.init.normal_(self.site_energy_table.weight, 0.0, 1.0)
        
        self.proj = nn.Sequential(
            nn.Linear(4, d_model // 2),
            nn.GELU(),
            nn.Linear(d_model // 2, d_model),
            nn.LayerNorm(d_model)
        )

    def forward(self, atom_idx: torch.Tensor, distances: torch.Tensor, mask_atom: torch.Tensor):
        """
        atom_idx: [B, L], distances: [B, L, L] (经过最小镜像约定的实空间距离), mask_atom: [B, L]
        """
        valid_mask = (~mask_atom).float()
        pair_valid = valid_mask.unsqueeze(2) * valid_mask.unsqueeze(1)
        
        # 构造紧束缚等效跃迁算子 (余弦平滑截断)
        within_cutoff = (distances <= self.r_cut) & (distances > 0.05) & (pair_valid > 0.5)
        f_cut = 0.5 * (1.0 + torch.cos(math.pi * distances / self.r_cut))
        H_bar = torch.where(within_cutoff, torch.exp(-self.alpha * (distances - self.r0) / self.r0) * f_cut, torch.zeros_like(distances))
        
        # 对角线清零
        eye = torch.eye(H_bar.size(1), device=distances.device, dtype=torch.bool).unsqueeze(0)
        H_bar = H_bar.masked_fill(eye, 0.0)
        H_bar = 0.5 * (H_bar + H_bar.transpose(1, 2))

        # 核心算法：单次 BMM 求解全部高阶中心矩
        mu2_c = (H_bar ** 2).sum(dim=-1)      # [B, L]
        M = torch.bmm(H_bar, H_bar)           # [B, L, L] (单次 BMM)
        mu3_c = (M * H_bar).sum(dim=-1)       # [B, L]
        mu4_c = (M ** 2).sum(dim=-1)          # [B, L]

        # 提取一阶在位能矩
        mu1 = self.site_energy_table(atom_idx.clamp(0, 118)).squeeze(-1) * valid_mask

        # 无量纲尺度变换与数值鲁棒化
        sigma_sq = torch.clamp(mu2_c, min=1e-4)
        f_mu1 = mu1
        f_mu2 = torch.log1p(mu2_c)
        f_skew = torch.clamp(mu3_c / (sigma_sq * torch.sqrt(sigma_sq) + 1e-4), min=-3.0, max=3.0)
        f_kurt = torch.log(torch.clamp(mu4_c / (sigma_sq ** 2 + 1e-4), min=1.0, max=100.0))

        moments = torch.stack([f_mu1, f_mu2, f_skew, f_kurt], dim=-1) * valid_mask.unsqueeze(-1)
        return self.proj(moments) * valid_mask.unsqueeze(-1)
```

## 4. 领域三：科学机器学习与神经算子（Neural Operator / 神经格林函数）向解码对接的迁移

### 4.1 解释性类比：现有 Query Cross-Attention 可视为局域格林函数预解式的 Nyström 型神经积分（类比，非严格证明）

在微观凝聚态物理中，系统的预解式算子在复能级空间满足：
$$\hat{G}(E + i\eta) = (E + i\eta - \hat{H})^{-1} = \sum_n \frac{|\psi_n\rangle \langle \psi_n|}{E - E_n + i\eta}$$
其空间迹投影给出了态密度的连续定义：$D(E) = -\frac{1}{\pi} \operatorname{Im} \operatorname{Tr}[\hat{G}(E + i\eta)] = \sum_{i=1}^N D_i(E)$。

在 uniARPAT 现有解码器中：
$$\mathbf{h}(E_k) = \sum_{i=1}^N \alpha(E_k, i) \mathbf{v}_i, \quad \alpha(E_k, i) = \frac{\exp\left( \mathbf{q}(E_k)^T \mathbf{k}_i / \sqrt{d} \right)}{\sum_j \exp\left( \mathbf{q}(E_k)^T \mathbf{k}_j / \sqrt{d} \right)}$$
$$\hat{D}(E_k) = \mathbf{w}_{\text{out}}^T \mathbf{h}(E_k) = \sum_{i=1}^N \alpha(E_k, i) (\mathbf{w}_{\text{out}}^T \mathbf{v}_i)$$

#### 类比关系（非等价性证明）：
1. 能量 Query $\mathbf{q}(E_k)$ 作为连续谱参数探针，可类比为对偶复能量点 $z_k = E_k + i\eta$ 的可学习编码；
2. 原子 Memory 键向量 $\mathbf{k}_i$ 与值向量 $\mathbf{v}_i$ 可类比为微观原子的局域有效自能与轨道基底状态；
3. 注意力权重 $\alpha(E_k, i) \in [0, 1]$ 且 $\sum_i \alpha(E_k, i) = 1$，形式上类似于分波态密度（PDOS）对全态密度的配分概率权重：
   $$\alpha(E_k, i) \approx \frac{D_i(E_k)}{D(E_k)} = \frac{\langle \phi_i | \delta(E_k - \hat{H}) | \phi_i \rangle}{\operatorname{Tr}[\delta(E_k - \hat{H})]}$$
   但需注意：softmax 归一强制每个能量点权重和为 1，而真实 DOS 总量随 $E$ 剧烈变化，尺度信息必须由 ScaleHead 另行承担；因此上式是 Fredholm 连续核积分算子**启发的** Nyström 型离散求积类比，不构成代数严格等价（无核等价误差界）。
**结论（修正）**：uniARPAT 的 Cross-Attention 解码范式可解释为**多体局域格林函数预解式启发的 Nyström 型神经积分器**，该视角用于指导尺度解耦与守恒设计，而非经验黑盒的严格定理。

---

### 4.2 传统网格回归 vs. 神经算子的物理范式代差

传统网格回归将 DOS 视为固定长度的离散向量（如 128 维），面临致命的**网格锁定（Mesh-dependency）**与**高频谱偏置（Spectral Bias）**，导致尖锐的 Van Hove 奇点被平滑钝化。
而神经算子（如 FNO, Neural Green's Functions）学习的是连续函数空间之间的无限维映射 $\mathcal{A}(\mathbb{T}^3) \to \mathcal{U}(\mathbb{R})$。其输出具有**连续可微性**，支持**任意能量网格的超分辨率推理（零样本泛化能力取决于训练覆盖，需实验验证）**，有助于保真热力学连续积分（如连续声子自由能与低温热容）。

---

### 4.3 环面神经算子（Torus FNO）：利用流形拉回消除单斜/三斜晶系几何畸变

晶胞处于周期环面 $\mathbb{T}^3 = \mathbb{R}^3 / \mathbb{Z}^3$ 上。对于非正交晶系（如单斜、三斜），其实空间线元由度规张量 $\mathbf{G} = \mathbf{A}^T \mathbf{A}$ 决定。
标准 FNO 假设正交欧氏空间，会导致严重的剪切畸变。借鉴 **Geo-FNO 流形拉回（Pullback）理论**：
在分数参考环面 $\mathbf{s} \in [0, 1)^3$ 上计算离散傅里叶展开，其系数与物理倒易波矢 $\mathbf{k}(\mathbf{n}) = 2\pi (\mathbf{A}^{-1})^T \mathbf{n}$ 处的物理展开完全恒等！
**核心改造（启发式，有待验证）**：谱乘子核由具有真实物理长度量纲的物理波矢与倒易度规重参数化：
$$\mathbf{W}_{\text{spec}}(\mathbf{n}; \mathbf{A}) = \operatorname{ComplexMLP}\left( \mathbf{k}(\mathbf{n}), \|\mathbf{k}(\mathbf{n})\|_2, \mathbf{G}^{-1} \right)$$
以缓解不同晶系的几何各向异性畸变（“彻底消除”缺乏证明，应表述为缓解；其中 $k(n)$ 为标准晶体学倒易矢量，Geo-FNO 原文贡献的是可学习形变拉回思想，而非该解析公式本身）。

---

### 4.4 无网格环面谱算子（Mesh-Free NU-TFNO）与全息 Memory 极点-留数重构

为避免在三维空旷晶胞内划分 $32^3$ 网格导致显存溢出，我们提出**无网格环面连续谱算子（Mesh-Free NU-TFNO）**：
1. 选取低频紧致倒易整数核集 $\mathcal{K}_{\text{modes}}$（当 $k_{\max}=2$ 时仅 125 个模态）；
2. 连续非均匀正变换：$\hat{\mathbf{z}}(\mathbf{n}) = \sum_{j=1}^N \mathbf{h}_j \exp\left( -i 2\pi \mathbf{n}^T \mathbf{s}_j \right)$；
3. 度规协变频域滤波：$\hat{\mathbf{u}}(\mathbf{n}) = \mathbf{W}_{\text{spec}}(\mathbf{n}; \mathbf{G}^{-1}) \hat{\mathbf{z}}(\mathbf{n})$；
4. 逆变换投影回原子：$\Delta \mathbf{h}_i = \frac{1}{|\mathcal{K}|} \sum_{\mathbf{n}} \operatorname{Re}\left[ \hat{\mathbf{u}}(\mathbf{n}) \exp(i 2\pi \mathbf{n}^T \mathbf{s}_i) \right]$。
计算复杂度仅为 $O(N \cdot |\mathcal{K}| \cdot d)$，$N=256, |\mathcal{K}|=125$ 量级下单次前向预计 $<1\,\text{ms}$（取决于硬件与实现，待实测），无 3D 体素显存占用（显式 $\exp$ 矩阵本身为 $B\times N\times |\mathcal{K}|$ 量级，需计入）。

### 4.5 尺度头（ScaleHead）算子级硬守恒重构：phDOS $3N$ 绝对守恒与 eDOS 价电子锚定

#### 守恒律 A：声子谱 $\int D_{\text{ph}}(\omega) d\omega \equiv 3N$ 绝对解析守恒
含有 $N$ 个原子的晶胞，声子模式数严格等于其力学自由度总数 $3N$（$N$ 由 CIF 原子坐标行数精确给出）。
**算子级硬归一化**：
取消 phDOS 的 MLP 尺度预测，将其重构为**守恒投影算子**：
$$\hat{D}_{\text{ph}}^{\text{phys}}(\omega) = 3N \cdot \frac{\operatorname{Softplus}(u_{\text{ph}}(\omega))}{\int_0^{\omega_{\max}} \operatorname{Softplus}(u_{\text{ph}}(\omega)) d\omega + \epsilon}$$
**数学性质**：对任意网络参数，此算子输出的声子积分在所采用的离散求积规则下恒等于 $3N$（连续积分误差取决于网格离散与 $\omega_{\max}$ 截断，不存在字面意义的“绝对 $0.00\%$”连续误差）。

#### 守恒律 B：电子谱基于价电子总数 $N_{\text{val}}$ 的有界弹性锚定
电子态密度积分受限于总价电子数 $N_{\text{val}} = \sum_i Z_i^{\text{val}}$。将原本在 $[10^{-1}, 10^3]$ 剧烈波动的对数尺度预测，改造为学习紧致有界的相对比例常数：
$$\text{scale}_e = N_{\text{val}} \cdot \left[ \gamma_0 + \tanh(\operatorname{MLP}(h_{\text{crystal}})) \cdot \Delta \gamma \right]$$
彻底根除训练初期尺度头剧烈发散问题。

## 5. 领域四：3D 视觉点云感知（Point Transformer v3）向老系统工程加速的迁移

### 5.1 PTv3 核心解密：以空间填充曲线（SFC）连续内存访问取代离散图检索

在老旧系统（gcc 4.8.5, 无 nvcc）下，传统稀疏图算子（Scatter/Gather）的 GPU 显存带宽利用率通常偏低（原文“不足 15%”为经验性估计，取决于 kernel 与硬件），且深层大矩阵开销大。
**CVPR 2024 Point Transformer v3 (PTv3)** 表明：利用 1D 空间填充曲线（Morton 码或 Hilbert 码）对 3D 空间进行网格编码，空间邻近的原子在 1D 序列中倾向于连续，将注意力切分为固定大小的局部连续 Patch（$P = 16$ 或 $32$），即可复用底层高度优化的密集 GEMM（`torch.bmm` 或 `scaled_dot_product_attention`），有望显著提升张量核心利用率（原文“80% 以上”为方向性期望，待实测）。

---

### 5.2 周期环面 $\mathbb{T}^3$ 的边界断裂难题与多相循环平移序列化（MPTSS）

标准莫顿曲线无法处理周期边界，跨边界紧邻原子会被分置于 1D 序列的首尾，导致局部 Window 注意力断裂。
我们提出**多相环面循环位移序列化（Multi-Phase Torus Shift Serialization, MPTSS）**：
在深度编码器的 6 个层中，交替注入正交互补的坐标平移相位：
$$\boldsymbol{\phi} \in \{ (0, 0, 0), (0.5, 0, 0), (0, 0.5, 0), (0, 0, 0.5), (0.5, 0.5, 0), (0.5, 0.5, 0.5) \}$$
**启发式动机（非定理保证）**：任何跨越胞界成键的原子对，在平移后有更大概率在某一网络层中变为晶胞内部的紧邻点，多层残差累加后可提升周期近邻覆盖率。作为数据增强型启发式策略，其“无死角 100% 覆盖”缺乏证明（Morton 邻近为概率性保证，且当 $r_{cut}$ 超过半胞尺寸时单次 0.5 平移仍可能不足），需实测验证。

### 5.3 纯向量化莫顿位运算与 GEMM 局部注意力

- **纯向量化莫顿编码**：在纯 PyTorch 64 位整数张量上执行位掩码交织，完全免编译；
- **显存估算（非实测，以十进制 GB 计，待基准测试）**：对于 $L=256, B=32$ 的构型，传统密集 RP 矩阵（$L\times L\times576$ float32）理论量级约为 **$4.83\,\text{GB}$**，而序列化局部注意力特征部分理论量级约为 **$0.60\,\text{GB}$（估算下降约 87.5%，未计三角形索引表 $\mathcal{T}$ 与 $\exp$ 中间矩阵，实际以 profiling 为准）**，有望在老旧显卡上支持更大 batch 训练。

## 6. 领域五：音频与时序多模态（Audio-MAE）向谱感知自监督预训练的迁移

### 6.1 连续物理谱的“平滑插值欺骗”病理分析

态密度由于 DFT 高斯展宽，相邻能量 bin 高度相关。若采用传统散点随机掩码（如随机挖掉 50% 的单一 bin），网络可能仅凭一维线性样条插值就获得很高的重构分数（原文“$R^2 > 0.98$”为示意性估计，未经本项目实测）。**这种“平滑插值欺骗”风险会使模型退化为平滑滤波器，难以学到晶体微观物理——该判断为待验证的假设，需对比实验确认。**

---

### 6.2 针对 eDOS / phDOS 的三大结构化物理阻断掩码策略

借鉴 **Audio-MAE（Huang et al., NeurIPS 2022，高掩码率 spectrogram MAE；原文以 80% 随机非结构化掩码为主，time/frequency 结构化掩码仅为消融对照）** 的高掩码动机，针对 DOS 的连续谱特性，我们**原创提出**以下三大结构化掩码（系本报告的新设计，非 Audio-MAE 原有结论，待实验验证）：
1. **费米能级带隙阻断（Fermi-Level Bandgap Blanking，提案值）**：抹除费米能级 $E_F \pm 1.25\,\text{eV}$ 区间（bin 数取决于能量网格划分，此处约 16 bins 为示例），迫使模型从化学价态与对称性推断金属/绝缘体转变与能隙宽度；
2. **Van Hove 奇异点共振峰簇遮蔽（Van Hove Peak Masking）**：动态探测态密度的尖锐峰值，向两侧扩展整段抹除，迫使模型依据晶体场配位多面体分裂重构共振峰位与峰高；
3. **声子光学支高频全频带阻断（Optical Phonon Blanking）**：彻底抹除 $>400\,\text{cm}^{-1}$ 的高频光学支，迫使模型从低频声学支斜率（弹性刚度）与原子质量外推恢复完整动力学矩阵。

---

### 6.3 物理守恒预训练损失：Smooth-L1 + 一阶导数全变分（TV Loss）+ 自由度守恒项

单纯依赖 MSE 损失会导致均值回归（奇异点被抹平）。构建联合预训练损失：
$$\mathcal{L}_{\text{pretrain}} = \mathcal{L}_{\text{SmoothL1}}(\hat{y}_{\mathcal{M}}, y_{\mathcal{M}}) + \lambda_{\mathrm{TV}} \mathcal{L}_{\mathrm{TV}}(\hat{y}, y) + \lambda_{\mathrm{cons}} \mathcal{L}_{\mathrm{cons}}(\hat{y})$$
其中**一阶差分全变分损失** $\mathcal{L}_{\mathrm{TV}} = \frac{1}{K-1} \sum_i |(\hat{y}_{i+1} - \hat{y}_i) - (y_{i+1} - y_i)|$ 专门惩罚平滑过渡，强制锐化能带奇点边缘；$\mathcal{L}_{\mathrm{cons}}$ 约束声子自由度积分误差。

### 7.2 模块落地实施路径与分阶段验证计划

| 迭代阶段 | 核心开发任务 | 预期收益与验收指标 | 风险防范策略 |
| :--- | :--- | :--- | :--- |
| **阶段 1 (P0)** | 1. 挂接 `PeriodicSpectralMomentEncoder` (单次 BMM 提取伪谱矩先验)<br/>2. 替换 `ConservativeScaleOperator` (phDOS 离散求积 $3N$ 守恒) | 1. 缓解尺度头震荡，phDOS 在离散求积意义下守恒；<br/>2. 有望提升 11k 小样本在带隙边缘的 Pearson 相似度（待实测）。 | 仅增加 1 次 `bmm`，下游解码器接口保持不动，架构风险较低（仍需回归测试）。 |
| **阶段 2 (P1)** | 实现 `SparseTriangleMultiplication` (STMU) 替换旧版静态 `RPEncoding` | 1. 引入 3-body 键角与 4-body 二面角相关的几何归纳偏置（待消融验证）；<br/>2. 缓解 $L \times L \times 576$ 稠密显存压力（理论估算，实测以 profiling 为准）。 | 采用原生 `scatter_add_`，保证在 `gcc 4.8.5` 下免编译；但三角形枚举 $\mathcal{T}$ 构建与负载均衡是新增风险点。 |
| **阶段 3 (P2)** | 启动基于 `PhysicalSpectralMasker` 与 `SpectralMAELoss` 的自监督谱感知预训练 | 若结构化遮蔽假设成立，有望在零样本/少样本子集上使下游 NormMAE 下降（原文“$15\% \sim 25\%$”为先验期望，非承诺指标，需实验校准）。 | 采用带隙与高频支结构化整段遮蔽， hypothesis 是阻断样条插值偷懒，需与随机掩码基线对比。 |
