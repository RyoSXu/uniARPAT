# 研究方向

## 1. 元素初始化模块
目前固定为 ZP (原子序号 → Embedding → LayerNorm → Linear → Encoder)

## 2. Encoder

研究模型如何保留周期性、局部环境以及同组成材料之间的结构差异。
局部模块：采用 A 还是 B+，以及内部宽度、更新公式和残差连接。
全局模块：注意力、FFN、归一化与残差的具体形式。
整体编排：局部与全局各调用几次、怎样排列、传递什么状态。

## 3. Decoder 拆分

研究在共享结构编码之后，为两类谱设置独立 decoder 是否更合适，以及共享到哪一层。

## 4. 大规模数据利用

利用大量结构数据进行预训练，也探索 eDOS-only 数据的监督学习与迁移，最终看它们能否改善当前任务。
