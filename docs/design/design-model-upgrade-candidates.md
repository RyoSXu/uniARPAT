## 候选 1：联合接收/发送/径向边内容（优先）

### 瓶颈假设链（事实→推断→干预→可证伪预测）

**事实（代码，本轮只读核对）：**
1. G2a 单边内容为可分形式（`design-g2-periodic-multi-image-message.md` 预注册，`model/transformer.py::PeriodicEdgeMessage.forward`）：
   `m = c(d)·[W_v h_j ⊙ σ(W_g φ_RBF(d))]`。`h_i` 不进入单边内容，聚合后才以残差相加。
2. B7 本身内容为 `h_j`，几何只进打分（`model/transformer.py::TransformerEncoderLayer.forward`）。
3. ComFormer 固定作者源码的内容为联合非线性（C-T，commit `4a16c68…`，`ComformerConv.message`，
   `def message` 起于 87 行，R3 复核按其 raw 计数为 86–96 行）：
   `c_ij = lin_msg_update(cat(value_i, value_j, lin_edge(edge_attr)))`，两层 Linear+SiLU；
   门控 `sigmoid(bn_att((query_i⊙key_j)/√C))`；对应 C-P（ICLR 2024）式 (2)–(3)。本轮下载固定 raw
   核对，SHA-256 `2733bbd7…` 与 R3 复核登记一致。
4. 项目误差事实：Q1 valid 320 个同组成材料对的目标／预测谱差 TV 中位 `0.2697/0.0160`；结构判异 275/320
   （多元素 299 对中判异 258 对，其 TV 中位 `0.2823/0.0171`）。B7 对同组成结构差异的谱响应不足。

**推断（非定理）：**可分内容把“接收端条件×发送端×距离”的逐边通道级交叉项推迟到聚合后的 FFN，
而 FFN 只见各邻居贡献之和；需要按接收态逐邻居选取／变换发送特征的环境不易高效表达。这与事实 4 相容，
但事实 4 也可由标签来源、训练支持、读出或优化解释，推断不构成根因判定。

**干预（单函数）：**只替换 G2a 的单边内容映射；周期边、cutoff、RBF、聚合与融合位置全部不变（见下）。

**可证伪预测：**匹配种子、同预算的 Q1 M1×10 成对 valid 中，处理臂相对**新跑对照**按统一判定口径通过
（blind eDOS `Δmed ≥ +0.02`、`Δfail <+1pt`，oracle eDOS 同向 `Δmed ≥ 0`，phDOS 与 blind 保护通过；
均见检验草案，全部为待确认提案）；机制辅助检查**复用既有配对误差定义**：同一材料对的带符号谱差预测
误差（预测谱差与目标谱差的 TV 误差，沿 `results/edos_spectral_support_q1_valid_pairs.csv` 与冻结读出
探针已用口径）下降，且整体 valid 通过——不以预测谱差 TV 数值增大或靠近总体目标中位 `0.2697` 为成功，
不新增诊断链。整体平局或退化即 park，即使机制读出移动也不晋级。

**最强反证：**G2a 内容已生效且通路核验显示影响到达输出（encoder/decoder 相对 RMS `0.0537/0.0637`、
eDOS 谱 TV `0.0147`），10-epoch 成对 pilot 仍平局（oracle Δmed `−0.0066/−0.0048`）；冻结读出与联合适配
探针表明“结构响应变大”不自动带来留出收益；B7 注意力打分本身已是接收—发送双线性权重，6 层×512 维
FFN 可合成部分交叉项。

**替代解释：**同组成谱差含 eDOS 标签来源／计算设置差异（未验证；D4b 是 phDOS 来源证据，按 R2 纠正不得
用于 eDOS）；谱形稀有度导致训练支持不足（四分位证据）；损失／读出偏向共同谱形。以上任一都可解释事实 4
而不支持本干预。

### 原方法（外部，有定位）与本项目提案（自拟）分开

**原方法（ComFormer，仅作机制来源，不迁移整模型）：**
- C-P：ComFormer，ICLR 2024，式 (2)–(3)（第 6 页）。
- C-T：`divelab/AIRS` commit `4a16c68…`，`comformer/models/transformer.py::ComformerConv.message`：
  `key_j = key_update(cat(key_i, key_j, lin_edge(edge_attr)))`；
  `out = lin_msg_update(cat(value_i, value_j, lin_edge(edge_attr))) ⊙ sigmoid(bn_att((query_i*key_j)/√C))`。
- 边界：作者使用 Matformer 式周期近邻键图（多镜像边）＋图级池化、默认隐维 256；其 `e_ij` 是图构建的键特征。不继承其 MP 基准收益、
  不变性或接口；论文公式与代码以各自定位引用，不混写。

**本项目提案（自拟，不是论文公式）：**
- **保留不变：**`utils/g2_periodic_edges.py::build_g2_edges`（同一批周期边：R=5.5 Å、全镜像、排除
  `i=j,T=0`；`shifts` 继续存储但本候选不消费）、quintic cutoff `c(d)`、64 中心 RBF `φ(d)`、
  `1/√max(1,deg)` 的 `index_add` 聚合、每层消息残差位置、零初始化标量 `α`。
- **只改内容函数**（`W_i, W_v, W_g, φ1, φ2, W_o` 为每层独立参数；`[;]` 为拼接）：

  ```
  u_i = W_i h_i,  v_j = W_v h_j,  e = W_g φ_RBF(d_ijT)     各 [E,512]
  c_ij = φ2( SiLU( φ1( [u_i ; v_j ; e] ) ) )               [E,1536]→[E,256]→[E,512]
  m_{i←j,T} = c(d_ijT) · c_ij
  h_i ← h_i + α · W_o( max(1,d_i)^(−1/2) · Σ_(j,T) m_{i←j,T} )
  ```

- **张量形状与 mask/pooling/梯度：**h `[B,L,512]`；边 `batch/dst/src/distances` 各 `[E]`（padding
  发送/接收端已在 `build_g2_edges` 排除）；gather `u_i,v_j` `[E,512]`；concat `[E,1536]`；隐藏 `[E,256]`；
  `m` `[E,512]`；`index_add` 聚合 `[B,L,512]`，不平均全 L。梯度上与 G2a 的差别：内容 MLP 经 concat
  对 `h_i` 也有直接梯度，每层消息同时回传接收端与发送端状态；decoder、H1、双谱头路径不变。
- **调用链→文件→符号（未来改动描述，本轮不实施）：**
  1. `model/transformer.py::Transformer.__init__`（约 211–217 行，现构造 `encoder.g2_msgs`）：
     新 flag 时构造 `JointPeriodicEdgeMessage`（或给 `PeriodicEdgeMessage` 加 `content_mode`）；
  2. `model/transformer.py::TransformerEncoder.forward`（590–608 行）：调用签名不变，仍传
     `batch/dst/src/distances`；
  3. `run_ablation_experiments.py`（`--use_g2` 位于 731 行）与 `utils/experiment_config.py`（92–93 行）：
     新增默认关闭 flag，不开放 cutoff/宽度等扫描参数；
  4. 测试沿 `tests/test_g2_periodic_edges.py` 合同扩展：关闭路径、`α=0` 恒等、置换等变、梯度有限。
- **旧 checkpoint 与关闭路径：**flag 关闭时不建模块、state-dict 键不变，`utils/b7_cif_inference.py::
  load_b7_model` 的 `strict=True` 语义保持；开启时新增键只能缺键加载 B7 共享权重；G2a `_g2edge`
  检查点不能 strict 载入（内容键不同）；`α=0` 初始化保证起点恒等，但这是初始化合同不是数值兼容证明；
  不跨归一化方案复用 checkpoint。

### 与 G2a 的实质区别（单函数与组合归因边界）

- 相同：边集合、cutoff、RBF、聚合归一化、融合位置、`α` 机制。不同：**仅单边内容函数**及其梯度到达
  `h_i`。但“只换内容函数”同时改变了参数量、非线性形式、gate 形式与接收输入：胜出只支持**整个内容
  函数改版**，不能单独证明接收条件或任何角度作用；容量差异是明确的替代解释（不做参数匹配臂，但必须
  承认这一点）。“新臂 vs 新跑 G2a 臂”归因的是内容函数整体；“新臂 vs G2 关对照”测的是“边路径＋内容”
  的组合包，不能归因到子模块（检验草案的参照臂安排见下）。
- **新增能力的代数反例：**设发送特征 `h_j=(1,0)`（两通道），同一距离 d 下两个**接收状态不同**的环境
  （`h_i` 不同，例如不同元素或已分化的环境状态；仅接收编号不同而 `h_i` 相同不构成反例）分别需要
  通道 1、通道 2。G2a 内容 `c(d)·g(d)⊙W_v h_j` 不依赖 `h_i`，对二者完全相同；B7 注意力只能对整向量
  按标量（每头一个）缩放；联合内容可对不同 `h_i` 输出 `(1,0)` 与 `(0,1)`。
- **失效/等价情形：**(i) 若所需交互可写成 `f(h_i)·Σ_j s(h_j,d_j)`，且聚合后表示仍能区分这些输入，
  FFN可能合成所需交互；单凭代数可分离不能断言实际残差和保留了足够信息；(ii) 单邻居时 FFN 只见残差和 `h_i+m`，`h_i` 与 `m` 各自的信息可能已不可分辨，
  **不能**普遍声称 FFN 可模拟任意二元交互，也不能反过来说联合内容在此必有增益；(iii) 若两环境的 `h_i`
  与 `(h_j,d)` 多重集相同，任何对这些输入的置换不变聚合（含本提案）都相同——本提案不新增几何信息，
  须引入能够区分环境的额外信息，角信息只是可能来源之一；(iv) 按距离的通道缩放已由 G2a 门控部分覆盖。
- **明确边界：**这是单层表达与归纳偏置差别，**不证明整个 B7 不可表达**；B7 注意力权重已联合依赖
  `h_i,h_j`，多层 FFN 可补出部分类似关系。

### 针对全体 Q1 的价值与剩余不确定性

- 覆盖面论据：同组成欠区分（320 valid 对）与多元素局部环境都相关，不限于单元素 `37/2313=1.60%`
  子集；本候选不依赖同质 Value 盲点立论。
- 不确定性：无直接证据表明缺失的接收端条件内容是约束精度的瓶颈；发生频率与收益未知；G2a 平局是强
  反证；胜出时仍不能排除参数／容量增加的解释（见上）；同组成配对误差移动不等于泛化收益
  （训练拟合／响应变大一律不算收益）。

### 成本推导（解析量级；不新跑资源测试）

## 候选 2：结构—谱监督（训练期辅助对比项，备选假设；接口契约变更未批准前不实施）

### 瓶颈假设链

**事实（项目）：**谱稀有度与错误相关（valid 按 train 目标谱最近邻 TV 四分位：中位 R²
`0.6336→0.3695`、失败率 `2.30%→11.76%`，train 为 `0.6828→0.5257`）；同组成欠区分（预测谱差 TV
`0.0160` vs 目标 `0.2697`）；高粗糙度谱过平滑（粗糙度偏差中位 `−0.318`，95% CI `−0.328…−0.312`；
高梯度边差分误差占比 `+0.142`）。**事实（外部，本轮核对）：**Mat2Spec（Nature Communications
13:949，**2022**，Methods 式 (6)–(10)，第 10–11 页）以“特征/标签概率嵌入＋分布对齐＋批内监督对比”
联合训练；源码 `gomes-lab/Mat2Spec` commit `5ec842f…`：`forward`（386–415）结构 GNN＋标签支＋特征支，
共享预测权重 `W` 产谱、`emb_proj` 投影；`compute_c_loss`（423–432）为批内 InfoNCE 式（相似度矩阵、
温度 τ、分母剔除对角正对）；`compute_loss`（434–486）SumNorm 分支默认 `1·两支回归 + 1.1·分布项 +
0.1·对比项`。本轮下载固定 raw 核对，SHA-256 `9c3a65a6…` 与复核登记一致；纯余弦版本（454 行）是注释。

**推断：**现有监督逐样本约束谱形，但对“谱身份相近而结构不同”的样本缺少表征级区分压力，可能加剧
共同谱形偏置；这是与“encoder 缺几何信息”竞争的解释，不是已证明的监督缺口。

**干预：**不动 encoder／decoder／几何，只给训练目标加一项结构—谱对比辅助（仅 eDOS）；主损失不变。

**可证伪预测：**同预算成对 valid 中按统一判定口径通过（blind eDOS `Δmed ≥ +0.02`、`Δfail <+1pt`、
oracle 同向、保护通过，均见检验草案）；机制辅助**复用既有误差定义**：同一材料对的带符号谱差预测误差
（预测谱差与目标谱差的 TV 误差，沿既有配对口径）下降、谱稀有度四分位差距按既有分组收窄，且整体
valid 通过——不以预测谱差 TV 数值增大为成功，不新增诊断链。平局／退化即 park。

**最强反证：**已失败的纯谱差探针（冻结读出：train TV 误差 `−6.11%` 但主 valid `+2.73%`，主 valid 256
材料 eDOS oracle 中位 R² `0.4687→−0.8478`；联合适配：TV 改善区间 `−0.00212…0.00859` 跨零且 oracle/blind
中位 R² `−1.1274/−1.1641`、失败率 `85.55%/86.72%`）说明监督改动可能破坏共有谱形；C2.1b 有限探针
（ep33、valid 32 batch、两个末层 FFN 权重）中位余弦 `0.074/0.009`、无 `<−0.10`，未发现可支持改权重的
有方向机制，但也不是“全局无负冲突”证明，对新增辅助项既不支持也不否定；Mat2Spec 论文式 (7)(9)(10)
与源码权重 `1/1.1/0.1` 并不完全一致，不能称“论文原配方”。

**替代解释：**稀有谱差距可由标签支持不足或数据分布解释；同组成欠区分可由 eDOS 标签来源／计算差异
解释（未验证）；过平滑可由损失、读出或容量解释。

### 原方法（外部，有定位）与本项目提案（自拟）分开

**原方法（Mat2Spec，仅作机制来源）：**论文 Nat. Commun. 13:949 (2022) Methods 式 (6)–(10)（作者 PDF
`https://www.cs.cornell.edu/gomes/pdf/2022_kong_natcomm_dos.pdf`；复核日志注明 PDF 截图检查未完成）；
源码 commit `5ec842f…` 的 `compute_c_loss`/`compute_loss` 如上。原方法含概率嵌入（标签支 MLP＋按谱维
高斯分量）与分布对齐（对称分量 KL 加权），**本提案不迁移该机器**；其权重、回归分支也不照搬。

**本项目提案（自拟）：**只加一项批内监督对比辅助（eDOS 单任务，phDOS 不加，保单因素＋保护）：
- 表征：`z_s = MLP_z(global_masked_pool(memory)) ∈ R^128`（复用 `model/heads.py::global_masked_pool`；
  与 H1 共用池化但独立投影头，不动 H1）。
- 标签支（仅训练期）：`z_y = MLP_y(p_e) ∈ R^128`，`p_e` 为该样本 SumNorm 归一化 eDOS 目标（128 bins）。
- 损失：`L = L_main + λ_c·L_con`。`L_main` 是**当前生产训练总目标**：双谱 `sumnorm_klw_loss`
  （`loss_edos + λ_ph·loss_phdos`）加 H1 eta/gamma 等生产辅助项，以 `model/model.py::basemodel.
  train_one_step` 的实际求和为准（289–330 行一带）；本提案不改动其中任何一项，`sumnorm_klw_loss`
  只是其组成部分。`L_con` 为本项目自拟：先 L2 归一化 `ẑ_s=z_s/(‖z_s‖₂+ε)`、`ẑ_y=z_y/(‖z_y‖₂+ε)`
  （`ε=1e-8`，提案；否则向量模长会改变有效温度），再
  `L_con = −mean_i log( exp(ẑ_s_i·ẑ_y_i/τ) / Σ_{j=1..B} exp(ẑ_s_i·ẑ_y_j/τ) )`。
  **分母含正对（j=i）**：Mat2Spec `compute_c_loss` 的分母是 `b_sum−b_diag`（排除正对），两种变体不同，
  本提案不继承作者变体的行为。`λ_c=0.1`、`τ=1` 为**本项目待确认提案**：作者源码中的 `0.1` 是其组合
  损失（两支回归＋1.1 分布项＋对比项）内的权重，该权重含义不随迁移，不称“源码默认”。
- **正/负样本与假负例：**正对＝(结构, 自身谱)；负例＝同 batch 其他样本的谱嵌入。相似谱假负例是明确
  失效模式：目标 TV≈0 的样本对（如同组成多形、近同谱材料）会被当负例推开，可能浪费容量或碎片化
  表征；按 TV 剔除假负例属第二因素，本轮不入，只在结果异常时另立设计。
- **塌缩约束：**本分母下全常量嵌入给出 `L_con=log(B)`；更低损失通常需要区分样本，但全常量解也
  可能是驻点，不能保证实际梯度使其离开。主谱损失约束memory到谱的路径，两个投影头仍可能塌缩；
  不保证有用结构、不排除维度塌缩。如候选获选，相关观察须并入已批准pilot，不能独立延伸诊断链。**不承诺保峰：**过平滑修复
  没有机制保证，粗糙度诊断只是动机线索。
- **训练侧特征路径（关键接口事实与拟议改动）：**当前 `Transformer.forward` 只返回预测 dict
  （`results['edos'/'phdos'/…]`），`basemodel.train_one_step` 拿不到 memory。拟议：flag 开启时在
  `Transformer.forward` 内部（memory 与 `mask_atom` 同作用域；`mask_atom = mask[:, 2:2+atom_len]`，
  与 `data_preprocess` 的 mask 同一约定）计算并**追加** `results['con_z'] =
  con_proj(global_masked_pool(memory, mask_atom))`，既有键语义不变；`train_one_step` 用
  `outputs['con_z']` 与 `MLP_y(edos_target)` 计算 `L_con` 并加进总损失。**这是公共 forward 契约变更，
  不自动成立**，须协调者/用户批准后才可实施。
- **头参数注册：**两个头必须在 flag 开启的模型构造期注册为 `Transformer` 子模块，
  `model/model.py` 97–105 行的 `get_optimizer(self.model[key], …)` 才会把它们纳入 optimizer 参数组；
  事后挂载则必须显式加入 param_groups，本提案不采用事后挂载。
- **checkpoint 与导出：**开启时辅助头为新键进入 state dict；正式runner的保存/恢复须沿
  `utils/ablation_checkpoint.py` 的 `build_ablation_checkpoint` 等既有通道核对，不能只看basemodel的历史接口。
  如从B7载入，只允许明列的新头键缺失；**旧 checkpoint 兼容不自动成立**：
  `utils/b7_cif_inference.py::load_b7_model` 为 `strict=True`，含辅助头键的 checkpoint 不能直接载入
  推理入口。推理模型flag关闭且导出权重须明确剥离新头键；仅关闭flag不能修复多余state-dict键。
  原始训练checkpoint保留，另存推理产物并验证输出一致；flag关闭不建头、无新键。不跨归一化方案
  复用 checkpoint。
- **CIF-only 推理：**标签支与对比项只在训练图中；推理走原 `Transformer.forward`→decoder→CNN 与 H1，
  `utils/b7_cif_inference.py` 入口不变（在上述导出约定下）。
- **调用链→文件→符号（未来改动描述）：**`model/losses.py` 新增 `supervised_con_loss`；
  `model/model.py::basemodel.train_one_step`（257 行起，291–292 行为 eDOS/phDOS 主损失，289–330 一带
  含 H1 等辅助项）加辅助项；`model/transformer.py::Transformer.forward` 增加可选 `con_z` 输出；
  `model/heads.py` 新增两个小投影头；`run_ablation_experiments.py` 新增默认关闭 flag。

### 与已失败纯谱差探针的实质区别

- 探针以“带符号概率谱差 MSE”为**唯一**目标（配对任务、1620 步、冻结特征或只开 encoder），未约束
  共有谱形，主 valid oracle 崩至 `−0.8478`；本提案保留完整谱主监督为绝对主体，辅助项不回归任何谱差、
  不做配对差分、不替换读出，从训练开始联合优化。
- 探针失败证明的是“纯差分回归破坏谱形”，不否定“表征级区分压力”这一不同机制；但同为监督改动，
  构成强反证，故本候选只作备选。
- 与候选 1 的区别：不修改encoder内容函数／几何输入，训练梯度仍会改变encoder参数。
  本轮仅推荐候选1进入下一步，候选2不是已排队的后续训练。

### 针对全体 Q1 的价值与剩余不确定性

- 价值论据：直接面向eDOS的谱形稀有度与同组成欠区分线索；phDOS作为共享主干的保护任务。
  在正确导出辅助头后可保持原推理接口；投影头参数较少，但训练成本仍待测量。
- 不确定性：**本候选收益未验证**（项目未全面检验过监督类改动，不作全局断言）；假负例与塌缩行为
  未知；`λ_c/τ` 未验证；训练拟合或响应变大不构成泛化收益。

### 成本推导（解析量级）

  标签，不新增数据契约。显存／耗时增量未测，不承诺百分比。

  （默认关），不扫描 `λ_c/τ`、不开假负例剔除变体；退化 → park 记录，不转小样本拟合、权重扫描或

### 缺口分层

- **阻止开工（不能用“无”掩盖）：**(1) 训练期可选 `con_z` 输出路径是公共 `Transformer.forward`
  契约变更，未获批准前不得开工；若不批准且不允许其他取特征手段，候选 2 降级为不可实施的备选假设。
  (2) 判定阈值、`λ_c/τ`、宽度与训练预算全部是待确认提案，未确认前不得开工。(3) 候选 2 收益未验证；
  备选身份不因候选 1 的结果自动转正。
- **实施后才能测量：**批内近同谱假负例发生率、塌缩／嵌入有效秩、辅助梯度与主损失梯度的关系（可复用
  C2.1b 式探针思路但不预设结论）、资源增量、valid 指标。

## 被筛除项：显式角信息（搁置，不递归调查）

- **已核对事实：**B7 每对仅一个逐分量折回镜像、方向分量进任意 `rp_proj` 打分
  （`utils/relative_features.py::compute_relative_features`、`utils/rp_encoding.py::RPEncoding.forward`）；
  G2 枚举全镜像但 `model/transformer.py::TransformerEncoder.forward` 只把距离传入消息，`shifts` 存而
  未用；iComFormer 的角是相对三条周期参考向量的夹角（C-P §3.2/§4.1，经 R3 复核纠正）；ALIGNN 原始角
  余弦在线图边上、复杂度 O(Nk²)（R3 复核纠正：不是指数，也不能因复杂度理由淘汰）。
- **为何排在最后（不是因缺因果证据被单独淘汰；B 与 C 都无项目因果证据）：**按三准则——
  信息可用性：没有任何已定位的 Q1 角度混叠或基底表达误差贡献证据，连可判定的失效样本都未定位；
  迁移范围：必须交代两向量与周期参照（需按 `shifts` 用 `(f_j−f_i+T)A` 重建边向量、按共同中心配对边并
  保持镜像身份），连带改边向量传递、键对构造与聚合，属组合干预难以归因；可证伪性：缺少能定位其失效
  模式的现成证据对象。valid平局不能唯一定位原因是三项候选共有的限制，此处排序主要依据尚未明确的
  周期角输入与更广的迁移范围，不是认定角机制不可检验。G2a（径向）失败**不能**解释为角信息缺失；
  同质 Value 盲点只覆盖 valid 1.60% 单元素，不足以为全体 Q1 立案。
- **恢复条件（当前不调查）：**出现可定位的 Q1 角混叠误差证据（例如经批准的只读诊断显示近同径向、
  不同角环境的样本对主导错误），或候选 1 平局后用户重新定向。届时先写独立设计，明确两向量、周期
  参照、成本 O(Σ_i d_in·d_out) 与单因素边界。
