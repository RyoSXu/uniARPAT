# 研究方向

## 1. 元素初始化模块
目前固定为 ZP (原子序号 → Embedding → LayerNorm → Linear → Encoder)

## 2. Encoder

研究模型如何保留周期性、局部环境以及同组成材料之间的结构差异。
目前的限制是限制在于：几何影响“汇总多少”，但没有直接进入“汇总的内容”。要做到根据当前晶体的邻居和几何环境，生成这个原子在当前材料中的特征，让结构信息参与原子间内容与表征更新，而不只调节注意力权重，使结构差异能更直接地改变原子状态。改进周期镜像几何表示，并研究旋转及等价晶胞描述下的一致性。

## 2. Decoder拆分

研究在共享结构编码之后，为两类谱设置独立 decoder 是否更合适，以及共享到哪一层。

## 3. 大规模数据利用

利用大量结构数据进行预训练，也探索 eDOS-only 数据的监督学习与迁移，最终看它们能否改善当前任务。
