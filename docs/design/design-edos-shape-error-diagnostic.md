# 设计：eDOS Q1 valid 预测形状误差诊断

> 关联 `docs/status.md` 的 eDOS 当前关卡。此项只诊断 B7 已有预测，不是训练实验；结果只决定是否值得提出一个新的单因素训练设计。

## 目标与成功判据

- **问题：**Q1 test/valid 的高粗糙度、高熵目标谱 R²较低，但目前不能判断预测是否被过度平滑、峰位是否偏移，或误差只是分散在其他 bin。
- **对象与基线：**冻结 B7 `_e9ctl` epoch 33，在 Q1 valid 2,313 条上比较目标 SumNorm 谱和模型 oracle 谱形；先确认逐样本 oracle R²能复现 C2.1b valid 记录（最大绝对差不高于 `2e-5`）。预测与目标均按每条谱总量归一化，以隔离 H1 gamma 尺度误差。
- **分层：**只用 Q1 train 目标谱定义粗糙度 p90 阈值（当前 `0.351600`），不根据 valid/test 重新选阈值。主分析为高粗糙度组与其他样本；完整 coverage 子集作为敏感性复核。
- **预先指定的诊断量：**
  1. 主指标：每条谱 `predicted_roughness - target_roughness`，报告高粗糙度组中位数及 bootstrap 95% CI，并与其他组比较。
  2. 次指标：`predicted_peak_share - target_peak_share`、有符号及绝对最高峰 bin 位移。
  3. 局部证据：逐边一阶差分误差 `|Δpred - Δtarget|`；按该样本目标谱 `|Δtarget|` 的最高 10% 边与其余边分别报告平均误差和高梯度区误差占比。
- **次要分层：**用相同的训练集 p90 阈值复核高熵组，报告相同诊断量；它只用于一致性观察，不单独触发损失候选。
- **解释门槛：**若高粗糙度组的粗糙度偏差中位数为负且 95% CI 不跨零，并且高梯度区一阶差分误差更集中，则记为“与过度平滑相容”，再单独拟定形状损失设计；不将其称为因果根因。若峰位偏移明显而粗糙度没有系统性低估，不采用一阶差分损失候选。若主指标不复现或局部证据不一致，则关闭该假设，不训练。
- **推断边界：**固定 bootstrap 2,000 次；指标是预先限定的诊断，不作多重比较校正，不据此声明模型泛化改进。peak-share 仅为次指标，不因单独一个 CI 越零就触发尖峰损失路线。

## 改动

- 单一因素；默认关闭；关闭路径保持不变：本项没有模型因素，只有只读预测分析。
- 复用 `tools/eval/edos_error_attribution.py` 的 B7 推理、训练集阈值及样本对齐；新增目标/预测形状差、峰位和高梯度误差列，结果写入 `results/edos_shape_diagnostic_q1_valid_{samples,strata}.csv`，不覆盖已有归因结果。
- 不改变训练损失、网络、数据、标签、coverage 使用方式、官方评分或 checkpoint；不读取 Q1 test 来选择干预；不启动训练。

## 测试关卡

- 单元测试覆盖完全匹配谱的零形状误差、总体缩放不变性、粗糙度低估符号、峰位移动计数和高梯度边分组。
- 实际审计确认 checkpoint epoch 33、split 为 `valid`、样本数 2,313、C2.1b R²逐样本对齐，新增诊断值均有限；全库测试通过。
- 若满足“与过度平滑相容”，下一步只写新的单因素候选设计供用户评审；本设计本身不授权实现损失或训练。

## 成本与风险

- 成本为一次 B7 valid 前向和 2,000 次 bootstrap 汇总；不产生 checkpoint，不消耗训练预算。
- 最高峰 bin 对平台峰可能不稳定；因此同时报告 peak-share 和差分误差，峰位仅为诊断，不单独作为失败判据。
- valid 是模型开发切分，分层结果不是外部泛化证据；测试集只保留为后续冻结方案的一次确认用途。
