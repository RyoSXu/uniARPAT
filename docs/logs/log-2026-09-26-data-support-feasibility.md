## 证据

### 1. 隔离样本回收（1,334 训练侧）：无可回收标签，本支停止

- 名单与判据（事实，`data/quarantine_q1.json`、`index/z0_REPORT.md`）：共 1,682 条
  （train 1,334 / valid 164 / test 184），判据 `C(full)/N_val < 0.5`（MP-DOS NBANDS 截断，
  谱缺失大部分价电子权重）＋ 14 条 Delta 不可读且 `γ_label<0.1`。
- 截断程度深（事实，`index/z0_trunc.parquet`，1,668 条有值）：trunc 中位 `0.127`、
  75% 分位 `0.173`、最大 `0.496`；`(0.4,0.5)` 区间只有 11 条，无边缘案例。
- **E0 窗口内标签已空**（事实，`v2_processed.parquet`）：隔离组 `edos_mask` 未覆盖 bin 中位数
  为 `128/128`（全部掩掉），尾部 16 bin 质量占比中位 `0.000`（保留组 `0.1125`），末 8 bin 全零
  占比 `68.4%`（保留组 `6.6%`）。窗口内没有可修复的谱内容。
- 截断是系统性的（事实）：隔离组 1,659 条声子来自 PhononDB、23 条 JARVIS、**0 条**来自 MP
  原生双谱（18,644 条零隔离）；隔离组原胞原子数中位 `55.5` 对保留组 `8.0`（均值 58.3 对 11.8）。
  大胞体系触发 NBANDS 截断。
- 修复路径评估（推断，依据上述事实）：
  - (a) 同材料替代 MP DOS task：Delta 全表 691,978 行（GGA 498,455 / GGA+U 178,372 /
    HSE06 10,836）但无 `material_id`，归属需对全表做结构匹配；即便找到替代 task，同为大胞
    体系、大概率同样被 NBANDS 截断。成本高且物理上希望渺茫。
  - (b) JARVIS eDOS 替代：optB88vdW 泛函，三源验证中配准后 r=0.79、系统性能移 +1 eV，
    混用即改变标签口径 → 改变质量标准，不授权。
  - (c) 自行重算 DFT：超出范围。
- **结论：按预设停止条件，隔离样本回收支停止。**不存在可靠同源修复；(b)(c) 均超出质量标准
  或范围。若要单独尝试 (a) 的归属审计，须另行立项并接受可能回收为 0。

### 2. D3 同源新增数据：有可靠新增，可用量如下

- 双谱（eDOS+phDOS）宇宙已穷举，phDOS 侧无免采集余量（事实，`v2_release/README.md` 与
  获取日志）：JARVIS 缺口 28,852 条已全量拉取、phDOS 命中率 13.1%（3,768→3,600 唯一）；
  PhononDB 10,034 条已全量复算（9,938 映射）；MP 声子 26,609 条已在 census 内。
- **eDOS-only 候选：121,420 条**（精确计数：有效 eDOS 154,373 − 有 MP 声子 26,609 − 当前池
  6,344 外源声子增量）。这是上限，需减去质量损耗（大胞 NBANDS 截断在该宇宙中的比例未知，
  当前池经验损耗率约 6–7%）。
- **双谱恢复候选：7,965 条**（census 记录"有 MP 声子无 eDOS"，当前池零收录；`edos_absent.json`）。
  参照增量落实率 7,358/7,724 ≈ 95%，若 REST/Delta 归属可落实 eDOS，可新增双谱至多约 7,500 条；
  是否可落实未验证，需一个小规模落实审计。
- 去重口径：材料级按 canonical mpid 排除当前 24,988 条，可精确执行；组成级隔离需处理后
  公式数据（成本项）。注意现有 split 本身不是约化组成隔离的（冻结读出探针测得 valid 168 组中
  51 组在 train 出现过），新数据若强制组成隔离会比基线更严；公平比较时统一口径即可，
  不必比基线更严。
- 标签兼容性：eDOS 为 MP 单源、泛函配对铁律可沿用（Delta run_type 中 GGA/GGA+U 占 98.9%，
  HSE 仅血缘对合法）；同一 E0/P0 网格、winsorize 与 SumNorm 加工口径适用；新材料需补
  Z0 `N_val` 审计（H1 γ 监督目标依赖它），有现成流程。质量过滤（截断、coverage）同等适用。
- 训练侧影响：eDOS-only 样本需要 phDOS loss 掩码。这是实验因素的一部分（数据＋掩码），
  不属于质量标准变化；phDOS 作为保护项监控。
- 能补的不足：直接对应已测最大落差（valid 按谱形支持距离四分位中位 R² `0.6336→0.3695`、
  失败率 `2.30%→11.76%`）与未见组成泛化。121k 宇宙允许按组成／结构新颖度定向选样，
  而非随机扩充。
- 处理成本（估计，基于获取日志历史速率）：`tools/getdata/` 加工脚本已退役，`tools/data/`
  保留 fetch／build_v2_cache／a6_split 等批准入口。全流程（拉取提取→归属→Z0→质量过滤→
  train 侧追加缓存）全量约 1 周；先做 10–20k 定向子集约 2–3 天。冻结 split 与 valid/test
  不动，只在 train 侧追加。

## 结论与建议

1. **隔离样本回收（1,334 训练侧）：停止。**没有可靠新增数据可言——窗口内标签已空，同源修复
   物理上渺茫，异源修复改变质量标准。
2. **D3 同源新增：候选证据成立，但可用量未经验证。**121,420 是候选池名单计数，不是已通过
   质量审计的可训练数量；7,965 是待落实候选，外推落实约 7,500 亦未验证。方向上它对应已测
   最大落差（支持距离分位 `0.6336→0.3695`），但**是否值得进入精度对照，取决于模型调研最终
   要检验的数据假设**（例如：需要谱形稀有度覆盖，还是组成覆盖，还是同组成结构多样性）。
   推荐形态仅作记录：10–20k eDOS-only 定向子集、phDOS loss 掩码、等算力成对对照、
   主验收＝全体 Q1 valid eDOS 中位 R²／失败率、机制读出＝支持距离分层（冻结为"到原 Q1 train"）、
   保护＝blind／phDOS／近组不退化。
3. 本轮未重建缓存、未批量采集、未训练；上述数字均为既有产物的只读计数与统计。
