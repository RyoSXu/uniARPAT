# 结构条件谱形突破：五个研究方向

1. **Encoder：怎样读懂晶体结构？**研究模型如何保留周期性、局部环境以及同组成材料之间的结构差异，使这些差异影响最终谱形。
2. **拆分 Decoder：eDOS 与 phDOS 是否应分别生成？**研究在共享结构编码之后，为两类谱设置独立 decoder 是否更合适，以及共享到哪一层。
3. **大规模数据利用：更多材料怎样帮助双谱预测？**利用大量结构数据进行预训练，也探索 eDOS-only 数据的监督学习与迁移，最终看它们能否改善当前任务。
4. **谱的预测形式：模型应怎样生成整条曲线？**当前模型直接输出固定网格上的谱；这一方向研究谱形还可以怎样表示和生成。它讨论输出形式，与第 2 条讨论是否拆分 decoder 不同。
5. **结构与标签的对应关系：CIF 是否提供了预测目标谱所需的信息？**检查目标谱的差异是否还受计算条件或标签处理影响，明确哪些差异能从结构中学到。
