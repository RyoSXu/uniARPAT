# docs 索引（中英对照，历史中文名冻结保留）

> 给人看：`README.md`；给 agent 看：本页 + `STATUS.md` + `GLOSSARY.md`。中文目录不再改名，只加英文别名。

| 路径 | 英文别名 | 回答什么 | 先看哪篇 |
|---|---|---|---|
| `docs/STATUS.md` | live status | 现在做到哪、下一棒是谁 | 全文（<3分钟） |
| `docs/GLOSSARY.md` | glossary | 术语/口径/五态 | 术语卡住时 |
| `01_开发文档/待开发总清单Backlog.md` | backlog | 唯一任务总表+Phase+ verdict | Phase 表、E9/B7/Q1条 |
| `01_开发文档/决策纪要Decisions.md` | decisions | 已定结论+现行数字 | 有争议先查它 |
| `01_开发文档/数据加工规范DataSpec.md` | data spec | v2数据施工图纸 | 动数据时 |

| `01_开发文档/2026-09-10-Design-*.md` | designs | 大任务专项设计 | 按需一篇 |
| `01_开发文档/archive/` | archive | 过期方案/验收报告 | 只读备查 |

命名规则：新文档用英文 `YYYY-MM-DD-topic.md`；工作日志沿用 `日志-YYYY-MM-DD-<主题>.md`（历史格式冻结）；verdict 脚本一律 `tools/eval/*_verdict.py`，禁放 `/tmp`。
