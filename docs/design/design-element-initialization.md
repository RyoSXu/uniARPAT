# 元素初始化：当前 ZP 方案与研究边界

更新日期：2026-10-02。状态：**用户已在路线图中固定 ZP，作为后续结构研究的元素初始化方案**。
本页说明当前代码职责、已有证据和使用限制；历史实验协议保留在各自设计与日志中。

## 1. 当前方案

```text
原子序号 Z → Embedding → LayerNorm → Linear → 初始原子表示 h⁰ → Encoder
```

对应模式为 `atom_feat_mode="z_only_proj"`，公式为：

```text
atom_src = atom_proj(atom_norm(tok_emb(atom_idx)))
atom_proj = Linear(d_model, d_model, bias=True)
```

目前 `d_model=512`。入口仅使用原子序号，不读取质量、半径、电负性，不保留常数性质分支。
Embedding 提供可学习的元素身份向量；LayerNorm 规范通道分布；Linear 学习进入 Encoder 前的仿射变换。
各通道没有预先指定的物理含义。

**固定的是模块结构与已记录的初始化规则；Embedding、LayerNorm、Linear 仍随训练更新。**
后续让同一种元素在不同晶体环境中获得不同表示，是 Encoder 的职责。
尚未设置新的通用初始化规则，历史 ZP100 使用的对齐规则见第 5 节。

## 2. 研究基线、最优参考与历史对照

| 名称 | 元素入口 | best epoch | 职责 |
|---|---|---:|---|
| ZP100 | `Embedding → LayerNorm → Linear` | 89 | 当前元素方案的已训练研究基线；seed 42、100 轮 |
| A100 | 元素 embedding 与三项性质分别编码、归一化、拼接投影 | 73 | 保留为历史性能对照 |
| B100 | A100 的数值输入全部替换为同一个常数 | 87 | 消除性质中的元素差异的历史对照 |

  eDOS oracle 为 219/2,313 对 195/2,313，净增加 24 个失败材料。
- ZP100 未通过当时“R²下降 <0.02、失败率增加 <1pp”的全部门槛；本次选择不修改该历史结论。

  相对 A100 的 phDOS oracle/blind 差值区间均低于零，已有结果存在明确性能代价。

新一轮实验的预算、选点规则和采用标准在执行前另定；此前讨论的 1.5pp 容忍范围尚未确认为新规则。

## 3. 已完成诊断支持什么

诊断使用固定的 2,048 条 train 子集、2,313 条 valid 与 128 条 train 探针。
设计见[诊断协议](design-element-identity-diagnosis.md)，产物见
[`20261002T095909Z`](../../results/eid_diagnosis_s42/20261002T095909Z/report.md)。

| 事实 | 可支持的判断 | 尚不能推出 |
|---|---|---|
| Z/ZP 在相同 train 子集上也落后于 B | 差距已存在于训练样本的拟合，不能仅用泛化解释 | 一定缺容量或必须增加共享偏移 |
| 参数参与优化器，检查到更新及有限梯度 | 未发现所检查路径中的漏参数、冻结或断梯度缺陷 | 历史每一步优化都有效，或从未发生任务冲突 |
| B 的性质输入是常数；B 与 Z/ZP 共享参数初值不同 | B 的优势不能来自常数输入中的元素差异；参数化与初值仍是混合解释 | B 式常数分支是必要的 |
| ZP 与 Z 初值及训练随机状态对齐，差异较小 | 该次单层投影没有解决已有差距 | 所有投影、宽度或初始化方案都无效 |

诊断复核的解释边界：

- ZP 投影权重 init→latest 的相对变化约 12.09%，不能仅凭绝对 RMS 约 0.0053 说“投影没学”。
- 深层方差、余弦或注意力熵接近，不代表逐材料表示相同，也不证明早期训练轨迹已锁定。
- valid 的 24 组逐样本 R²交叉核对中有 2 组未过原容差：ZP best 的两项 phDOS 各有一个材料
  差约 4.8e-6。复核未发现失败分类变化，中位数变化 <3e-8。重复前向存在数值差异；
  具体 GPU kernel 原因尚未确证。
- 原报告中的交换初始化对照和恢复比例判据仅为建议；没有实施，不能按区间含零判断某种因果解释成立。

当前证据足以描述 ZP 的已知代价和实现状态，尚未定位 B 优势的单一根因。
入口额外参数、共享偏移和非零偏置的连续训练队列暂不优先安排。

## 4. 元素初始化与原子环境更新的职责

训练中更新 Embedding 参数，学习的是所有材料共享的元素向量。
前向中更新原子表示，生成的是某个原子在当前晶体环境中的状态；两者不能混为一谈。

当前基础 `TransformerEncoderLayer` 每层用 `q=k=v=src`，将距离与方向编码加入注意力打分，
再加权汇总当前原子特征，经过残差、LayerNorm 与前馈网络更新状态：

```text
alpha_ij = softmax_j(feature_score_ij + geometry_score_ij)
message_i = sum_j(alpha_ij * h_j)
```

因此几何参与了计算，也能通过改变不同元素特征的混合比例影响原子表示。
目前基础路径没有直接把边几何加入被汇总的消息内容。

**从公式可推导的限制：**当所有有效原子的初始特征均为同一个 `c` 时，
`sum_j(alpha_ij * c) = c`。在关闭 dropout 的评估模式下，共享前馈网络继续保持这些状态相同，
仅改变几何打分无法生成不同的环境表示。这里限定当前基础 Encoder、通常的有效原子 mask，
并忽略浮点误差；G1 hub、G2 消息、宏观晶格分支、多体 Encoder 等额外路径需分别分析。
本次没有新增数值实验来验证该推导。

后续优先研究几何如何参与消息内容及原子状态更新，并同时考虑周期镜像与方向对称性。
这是一条待检验的结构假设，尚未证明它解释了全部结构响应不足或改动后必然提升精度。

## 5. 当前代码与初始化协议

| 调用环节 | 文件与符号 | 职责 |
|---|---|---|
| 组装模型 | `model/transformer.py::Transformer.__init__` | 按模式创建入口参数；保留顶层参数名与创建顺序 |
| 元素编码 | `Transformer._encode_atoms` | 原子索引 `[B,L]` → 初始表示 `[B,L,D]`；包含 Z/ZP 与历史性质模式 |
| 输入与几何 | `Transformer.forward` | 去除两个晶格哨兵槽，对齐 mask，调用元素编码，再进入几何与 Encoder 路径 |
| 原子更新 | `TransformerEncoder.forward / TransformerEncoderLayer.forward` | 逐层聚合和更新原子状态 |
| 历史运行约束 | `run_ablation_experiments.py::validate_zproj_config / train_and_eval` | 执行 ZP100 的受控对齐流程与 valid-only 约束 |
| 历史初始化 | `utils/zproj_alignment.py::prepare_reference / apply_alignment / restore_training_rng` | 重建未训练 Z 参考、复制共享参数、设置恒等投影、对齐随机状态 |

局部整理将原有元素编码语句移入私有方法 `_encode_atoms`；模块仍注册在原位置。
`tok_emb.*`、`atom_norm.*`、`atom_proj.*` 等 checkpoint 键不因方法提取改变。
当前 `token_num=118` 接受索引 0..117；两个晶格哨兵槽不进入 embedding，Q1 的真实元素范围未触及该上界。
本次未扩大元素索引契约。

历史 ZP100 投影初值为单位矩阵/零偏置，共享参数和训练随机状态与**未训练 Z100** 对齐。
它不使用 B100 或任何训练好的权重，也不在前向中依赖参考模型。
直接构造 `Transformer(atom_feat_mode="z_only_proj")` 使用模型通常的参数初始化，不能替代历史 ZP100 初值。

**现有训练入口仍是历史实验入口：**`apply_alignment` 固定核对 Z100 seed-42 指纹和 512 维投影，
因此换 seed、Encoder 或其他影响参数的配置，不能直接套用该固定指纹。
把它改为适用于新实验的通用初始化协议，需要单独明确控制变量并实施；本次保留历史流程。
CLI 默认仍是 `legacy3`，当前 ZP 必须显式指定 `--atom_feat z_only_proj`。
本页没有授权新训练、补种子、续训或 test 评估。

## 6. 后续工作顺序

1. 用当前 ZP 结构作为入口，调查并设计结构消息与原子状态更新。
2. 新候选进入实施前，明确其初始化协议、研究对照、train/valid 指标、预算和采用标准。
3. 出现可复现的入口瓶颈时，再考虑 ZP 的层数、宽度、非线性、归一化位置或初始化改动。

ZP 是本阶段选定的研究起点，尚未证明其最优或与 A/B 无性能差异。
