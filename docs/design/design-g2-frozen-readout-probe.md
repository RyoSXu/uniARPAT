# 设计：冻结 G2 表征的结构谱差读出实验

## 授权与问题

- 马尚酱已确认：执行冻结 encoder、重新训练现有读出的机制实验，以同组成组内打乱对应为对照；
  区分训练内可学习性与留出组成泛化。它不要求先证明整体准确率会提高。
- 假设：固定 G2 epoch 10 的 encoder 表征中，有原读出尚未充分利用、可跨组成预测 eDOS 结构
  谱差的信息。唯一实验因素是读出训练时表征与目标的对应关系（正确／组内随机）。
- 复用现有 decoder、eDOS query、target token 和 CNN head；两臂从完全相同的 G2 权重开始。
  不训练 encoder，不改变模型架构；本次训练出的读出是机制探针，不直接替换生产共享 decoder。
- 本次按已确认的机制实验口径验收；整体 `+0.02` 是候选方案晋级条件，不作本次机制成立条件。
  不改写全局实验纪律或默认方案。

## 数据边界（训练前固定）

- 输入仅 Q1 train／valid 和 `output/ablation_m1_g2edge/checkpoint_latest.pth`（M1、ep10、seed42）。
  复用上轮 `g2_structure_path_q1_pairs.csv` 的同元素绝对计数、不同缓存结构配对，并逐行核对 ID。
- train：2,591 对、3,115 材料、1,331 个绝对计数组、1,198 个约化组成组。
- valid：320 对、394 材料、170 个绝对计数组、168 个约化组成组。
- 约化组成是元素计数除以最大公约数；它把同元素比例、不同晶胞大小归入一组。valid 配对中有
  51 个约化组成在原 Q1 train 出现过，因此**主验收只用剩余 163 对／117 个约化组成组**。
  这117组既不进入本轮读出训练，也未出现在 encoder 原始训练集中。全部320对只作补充描述。
- 不重分配或改写 Q1 缓存；不读取 test。验证标签不用于超参、步数或 checkpoint 选择。
- 缓存原始冻结 encoder 的真实原子 token，按 batch 补 padding；源模型 eval 前向与缓存读出
  前向须在概率谱 TV `1e-5` 内一致。缓存不包含标签派生的输入特征。

## 两臂与优化预算

1. **matched：**每个材料的表征对应自身目标。
2. **shuffled：**每个优化 batch，在所有涉及的绝对计数组内部独立均匀生成一一置换；同组在该
   batch 内共用该置换。置换允许固定点，每个 batch 重新抽样，防止两材料组恒定互换后学到反向
   对应。元素计数、表征集合与目标集合完全保留。该随机生成器与 pair 顺序生成器独立。

两臂验收时均恢复真实材料对应，和原始未训练读出 `original` 一起比较。

- 只学习 eDOS 读出参数：decoder、eDOS query embedding、eDOS target token、eDOS CNN head。
  encoder 参数不进入优化器；缓存与源 checkpoint 运行前后哈希一致。
- 每次16对（32次材料前向）；每轮无放回遍历2,591对，最后batch保留；**10轮、每臂1,620步**。
  两臂相同 pair 顺序、初值、固定 FP32、AdamW（lr `5e-5`、betas `0.9/0.99`、weight decay `0.01`）、
  梯度裁剪 `1.0`，不扫参数、不根据 valid 提前停止。取最后一步权重。
- 读出保持 eval 模式但启用梯度，关闭 dropout；避免独立 dropout 噪声替代真实结构差异。
  这是两臂共享的可学习性实验设置。
- 对每对 `(a,b)`，`p=softmax(logits)`，`q` 为原始 SumNorm 目标，优化
  `mean((128 * ((p_a-p_b)-(q_a-q_b)))**2)`。128只调节数值尺度，不引入目标标准化差异。
- 每对权重为 `全部pair数 / (约化组成组数 × 该组pair数)`，使整个epoch各约化组成等权。
  两臂目标、权重、batch 和预算相同。此目标不约束两材料共有谱形，所以还要报告单样本准确率代价。
- 原始读出、两臂最终读出只在开始／结束做完整 train/valid 评估；过程中只记录训练目标。

## 判据及结果分支

- **主机制误差：**带符号谱差 TV `0.5*sum(abs((p_a-p_b)-(q_a-q_b)))`，先在约化组成组内
  取平均，再对组等权平均。补充逐对中位数、谱差 MSE／余弦、目标与预测 TV。
- **零谱差参考：**同组成结构预测完全相同，则机制误差等于目标 TV。它与 original、shuffled
  一起构成三项参考，防止仅比退化的 shuffled 臂好就宣布成功。
- **留出泛化成立：**主验收117组中，matched 相对每一项参考的组等权误差至少下降5%，且成对
  组成组 bootstrap（2,000次、seed20260926）的误差改善95%区间下限均大于0。5%为本轮预定实用
  响应线，不是全体准确率门槛；同时报告全部连续数值。
- **训练内学习成立：**train1198组中，相对上述每一项参考的组等权误差至少下降10%。满足但
  留出未满足时，只报告训练内学习及泛化未获支持，不称全面解决表达能力或已证明过拟合根因。
- **训练内也未成立：**只否定这一初值、读出、目标和预算下的干预；不推断 encoder 没有信息。
  检查预定正对照：在固定16个train材料对上直接优化各材料独立logits（零初值、Adam lr0.1、
  1,000步），相同谱差MSE应下降至少99%。它验证softmax目标与损失可优化，不证明decoder优化充分。
- 全部情形报告配对材料的 eDOS oracle/blind 中位R²和失败率；H1尺度头冻结。机制探针未按
  phDOS目标训练，不能声称phDOS保护通过或直接晋级生产。一个seed的区间不涵盖训练seed不确定性。
