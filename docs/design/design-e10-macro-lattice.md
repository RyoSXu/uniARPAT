# 设计：E10 宏观晶格状态

> 关联：[状态与计划](../status.md) 当前关卡，以及[结构表征方向](design-structural-refinement.md)。
> E10 只检验显式宏观晶格状态是否提供信息；不涉及 G2 周期多镜像消息、数据、标签、损失或读出结构。

## 目标与成功判据

当前 M1 可从原子对几何中间接推断材料的致密程度，但没有直接、晶胞尺度稳定的全局状态输入。E10
检验两个由 CIF 结构和元素组成唯一导出的标量是否能改善 Q1 B7：

\[
x_1=\log(V/N_{atom}),\qquad
x_2=\log\rho=\log\left(\sum_i M_i/V\right).
\]

- **对照：**新跑的 Q1、M1×10、seed 42、E0/P0、SumNorm KL/W1/Huber、H1 eta/gamma、dropout
  0.05 的 `_e10ctl`。
- **实验臂：**除 `--use_macro_lattice` 外完全相同的 `_e10macro`。
- **主指标：**oracle 测试 eDOS/phDOS 中位 R² 与失败率；Cv MAE、单轮耗时和显存为辅助指标。
- **pilot 提升门槛：**至少一个任务中位 R² 相对对照提升 `>= 0.02`，对应失败率不恶化 `>= 1pt`，另一个
  任务也不得有害退化。通过后才运行 Q1 M1×35 等算力确认并补 blind 评估。
- **停损：**未越过门槛即 E10 park；不扫描投影宽度、注入层、标量组合或融合方式。

## 改动

### 特征边界

- 从现有 `pos` 中重建晶胞矩阵并取 `abs(det(cell))` 得到 \(V\)；有效原子数来自现有 padding mask；
  原子质量来自项目已有周期表。
- 只使用 `log(V/N_atom)` 与 `log(total_atomic_mass/V)`；不使用原胞绝对体积 \(V\)、任何标签导出
  特征、外部数据库字段或预处理缓存。
- 两个标量使用**仅由 Q1 训练划分**计算的固定均值与标准差标准化；验证和测试不得参与统计。

### 融合路径

在 atom type/numeric feature 融合后、encoder 前加入：

\[
h_i^{(0)} \leftarrow h_i^{(0)} + \alpha\,f_{macro}(x_1,x_2),
\]

其中 `f_macro` 是小型两层 MLP，输出维度等于 `d_model`；标量 `alpha` 初始化为 0。关闭
`--use_macro_lattice` 时模块不实例化，既有状态字典、参数量和输出保持完全不变；开启时训练第 0 步
也严格等价于 B7，并由 `alpha` 渐进开启该残差。

这是最小融合路径：它只回答“显式信息是否有用”。若结果为 win，后续才讨论 crystal-state token 或
FiLM；二者不属于 E10。

## 测试关卡

1. 解析合同：手工立方晶胞的 \(V\)、\(V/N\) 与密度正确；padding 原子不改变 \(N\) 或质量。
2. 数据合同：训练统计有限、标准化后的训练特征有限；验证/测试只复用训练统计。
3. 模型合同：关闭路径 bitwise 等价；开启时初始前向等价；首步 `alpha` 获得有限、非零梯度，更新后
   macro MLP 获得有限、非零梯度。
4. 真实 Q1 CPU 单步冒烟：损失全键（含 H1）有限。
5. 训练：按上述 `_e10ctl` / `_e10macro` 成对 pilot 运行；结果、命令和结论写入 `results/` 与日期日志。

## 成本与风险

- 预计新增参数远小于 0.1M，计算和显存增幅应低于 1%。实际数值须随 pilot 记录。
- \(V/N\) 和密度并非完全独立；本轮不试图归因到单一标量，而只检验“宏观状态向量”这个单一假设。
- 原始 \(V\) 对晶胞选择敏感，故不作为本轮特征；这不要求本轮生成或训练不同晶胞表示。
- 模型可能通过原子对距离隐式获得部分信息，因此平局是合理结果，不应据此增加模块复杂度。

## 结果（2026-09-19）

`_e10ctl` 与 `_e10macro` 均为 Q1、M1×10、seed 42、E0/P0、SumNorm KL/W1/Huber、H1 eta/gamma、
dropout 0.05 的 oracle 测试口径。

| 臂 | eDOS 中位 R² / 失败率 | phDOS 中位 R² / 失败率 | Cv MAE |
|---|---|---|---:|
| `_e10ctl` | 0.4751 / 4.50% | 0.7220 / 1.22% | 0.2906 |
| `_e10macro` | 0.4691 / 4.46% | 0.7162 / 1.97% | 0.3002 |

增量（macro − 对照）为 eDOS −0.0060 / −0.04pt、phDOS −0.0058 / +0.74pt、Cv MAE +0.0096。
两项中位 R² 均未跨越提升门槛，故 **E10 park**；不做 35 epoch 或 blind 复核，也不扫描融合方式。
