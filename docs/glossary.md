# 术语表

只收录当前状态、设计和结果所需词汇；历史实验编号及证据以对应日志为准。

## 数据与评估

| 术语 | 含义 |
|---|---|
| **DOS / eDOS / phDOS** | 态密度；分别指电子与声子态密度。 |
| **CIF** | 晶体结构输入文件；blind推理只使用结构与模型内冻结常数。 |
| **Q1 / crystal-q1-v1 / pre-Q** | Q1存储划分18,706/2,313/2,287；完整结构修复版有效train为18,704。pre-Q是更早口径，不直接比较。[数据](data.md) |
| **Z0 / N_valence** | Z0为历史价电子审计；N_val是旧尺度侧车，来源包括占据谱积分和组成回退，不是逐任务赝势计数真值；新per_atom重建不使用它。 |
| **oracle / blind** | oracle使用标签尺度作诊断；blind由结构预测并重建，对应部署评价。两者分开报告。 |
| **中位R² / P10 / 失败率** | 典型水平、R²第10百分位、R²<0的材料比例；当前均是分任务报告项，主选点误差另列。R²受目标方差与背景影响，不直接比较任务难度。 |
| **联合blind R²（历史）** | `balanced_blind_r2`：两任务blind中位R²等权平均最大；旧实验不追溯改选点。 |
| **E / 联合blind全谱误差** | E为每原子全谱平方误差乘箱宽、除以任务train谱能量；`balanced_blind_energy`取两任务材料均值的等权平均，越低越好。train全零预测的平均E为1，非单材料R²零线。 |
| **双任务保护** | 当前固定A64 valid参照：eDOS/phDOS失败数≤196/99，中位R²下降各≤0.02；合格轮次中最小化联合E。它是点估计约束，不保证新材料不退化。 |
| **no_eligible_best** | 没有轮次通过保护，不能宣称best；latest只供恢复。 |
| **TV / signed谱差误差** | TV描述单位和谱形差异；signed谱差误差比较预测与目标的有符号差，不能只凭预测差幅度变大判断改善。 |
| **coverage mask** | True表示该箱有有限源采样点；False不自动等于物理零或坏标签。当前loss与正式全窗评分不据此删箱。 |

## 模型与训练

| 术语 | 含义 |
|---|---|
| **ZP / ZP100** | ZP为Embedding→LayerNorm→Linear的纯原子序号入口，参数继续训练；ZP100是旧Q1、seed42、100轮历史参考。 |
| **A100 / B100 / Z100** | 历史元素入口对照：三项性质、同架构恒定性质、删除数值分支；均seed42、100轮。 |
| **B7 `_e9ctl`** | 旧Q1、seed42、35轮、best33的历史参考，不是当前数据和新指标下已验证最优模型。 |
| **encoder / decoder / head** | 结构表示更新／由表示生成谱查询输出／产生最终谱形或总量。 |
| **I1 / I2 / I3 / I4** | 修正共同骨架上的简单径向C1／完整B+／完整A／完整B+加局部状态直连；I1保留性能参照，I4本次未采用。 |
| **A64 / W1 / LN1 / LN2 / LR1 / LR2** | 完整A 64/128参考／扩宽／内部pre-norm／外层post-norm／增量读出／去除内部显式加法。各自结论与旧配方绑定；LR2未自动并入新工作配方。 |
| **H1 eta/gamma（历史）** | sigmoid有界尺度头，eta用于phDOS、gamma用于eDOS；保留旧checkpoint语义，不把跨费米窗口态数通用地限制到价电子数以内。 |
| **per_atom总量** | 结构预测非负、无固定上限的每原子处理后窗口离散面积；乘原子数并除箱宽重建密度。不依赖N_val，也不宣称原加工面积严格守恒。 |
| **SumNorm / S / E+S** | 非零谱除以离散和得到形状；S为KL/W1/Huber。当前工作配方每任务E+S，两任务各50%、辅助权重1；零谱S=0、E正常监督。S不进入选点。 |
| **工作配方 / 性能参照** | 工作配方服务后续研究，须显式启用相应开关；I1和旧模型的历史成绩、checkpoint契约继续保留，不由工作配方更新宣称性能超越。 |
| **E0 / P0** | eDOS为[-6,6] eV、128箱；phDOS为[-280,980] cm⁻¹、64箱。 |
| **epoch / pilot / win / park / closed** | 完整训练遍历／有限探索；候选通过判据／暂不采用／暂停。范围限实际实验，不自动否定更大方向。 |

具体训练、选点与兼容边界见[长期约定](decisions.md)，当前证据与下一步见[项目状态](status.md)。
