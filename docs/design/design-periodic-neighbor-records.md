## 一条记录代表什么

每条记录代表一个中心原子 `i` 的一个周期邻居 `(j, T)`，逻辑标识为 `(b, i, j, T)`。
`b` 是所属晶体，`j` 是当前晶胞内的原子编号，`T` 是该原子的整数周期平移。
来自不同周期镜像的邻居分别记录，即使它们的 `j` 或距离相同。

设 `f_i, f_j` 为分数坐标，晶格矩阵 `A` 的每一行是一条实空间晶格基矢，单位为 Å：

\[
\mathbf r_{ijT}=(\mathbf f_j+\mathbf T-\mathbf f_i)\mathbf A,
\qquad d_{ijT}=\|\mathbf r_{ijT}\|.
\]

位移向量统一从中心 `i` 指向邻居 `(j,T)`；后续消息的发送方向是邻居向中心，即 `j → i`。
输入沿用现有 `pos` 和 `mask_atom`：`pos` 前两行存储 `(a,b,1/c)` 和晶格角（度），其余行为
分数坐标；需先恢复真实 `c`。`mask_atom=True` 表示填充槽。
现有晶格重建使用固定笛卡尔框架，不保存任意外部朝向；对物理旋转/反射做验收时，须把
重建向量映射到对应物理框架，再比较 `r'=rQ`。距离应不变，整体平移在相对位移中消去。

## 必须能够提供的六个字段

令 `E` 为当前批次的有向邻居记录总数。各数组按同一记录顺序对应：

| 信息 | 含义 | 形状、类型或单位 | 现有来源 |
|---|---|---|---|
| 所属晶体 `b` | 记录属于哪个样本 | `[E]`，整数 | `edges["batch"]` |
| 中心原子 `i` | 接收消息的原子 | `[E]`，整数 | `edges["dst"]` |
| 邻居原子 `j` | 发送消息的晶胞内原子编号 | `[E]`，整数 | `edges["src"]` |
| 周期平移 `T` | 与原始分数坐标配套的真实镜像平移 | `[E,3]`，整数、无量纲 | `edges["shifts"]` |
| 真实位移 `r` | 中心到邻居的实空间向量 | `[E,3]`，浮点，Å | `periodic_edge_vectors(pos, edges)` |
| 真实距离 `d` | 位移向量的长度 | `[E]`，浮点，Å | `edges["distances"]` |

这是逻辑上的完整记录，不要求重复存储向量，也不要求新增返回键或封装函数。
位移可按需重建，但必须与其余字段逐条对应，且其范数与记录距离在浮点容差内一致。

## 输入前置条件与现有检查

复用前，调用方须保证晶格参数物理有效且有限，`mask_atom` 为与原子槽对齐的 `[B,L]` 布尔数组，
所有非填充槽的分数坐标均有限。调用时须显式传入正、有限的 `R`，不依赖函数的默认 5.5 Å。
输入质量检查应在枚举前拒绝并报告异常输入，不把异常样本或原子槽静默当成合法空邻域。
这些是本规范的复用前置条件，当前枚举器尚未完整实施这些检查。
[半径审查入口](../../tools/eval/periodic_neighbor_radius_audit.py) 已在调用前检查正有限半径和
有效槽坐标有限性；入口检查不改变现有枚举器接口，也不表示所有调用方已得到相同保护。

现有检查与缺口的代码依据：

- [`build_cell_from_lattice`](../../utils/relative_features.py) 要求恢复后的 `a,b,c` 均在
  `(0.1,1000) Å` 内，否则触发长度断言；[`build_g2_edges`](../../utils/g2_periodic_edges.py)
  对计算出的非有限或 `s_min(A)<=1e-6 Å` 报错。非有限晶胞也可能先在 SVD 阶段失败。
  这些失败均中止当前批次，不静默跳过样本，也不返回合法空邻域。
- 现有枚举器只断言 `r_cut>0`，没有有限性检查。2026-10-03 CPU 核查中，`R=+inf` 导致枚举范围
  转成整数时溢出，最终静默返回 `E=0`；复用前须由调用方检查有限性，枚举器内该防护仍待实施。
- 现有枚举器用 `~mask_atom` 选择原子，没有检查有效槽坐标的有限性。NaN 距离不能通过
  `d<R`，会静默丢掉相应记录。2026-10-03 以 3 Å 立方胞、两个非填充槽、一个槽含 NaN、
  `R=3.01 Å` 核查，未报错且返回入度 `[6,0]`；这不是合法空邻域的证据。

## 保留与解释规则

1. **半径内完整保留。** 对有效晶体和有效原子，仅保留 `d < R` 的邻居；`R` 为正、有限的显式参数，
   当前阶段采用 `R=6.0 Å`。不能以固定镜像范围或静默 top-k 裁剪代替完整枚举。
2. **区分自身与跨胞镜像。** 排除且仅排除自身项 `i=j, T=(0,0,0)`；`i=j, T≠0` 保留。
   此排除规则在有效原子和半径筛选之后应用，不以删除所有零距离记录代替输入质量检查。
3. **保留多重邻居。** 不按 `(i,j)` 或相同距离合并记录；同一 `(b,i,j,T)` 不重复。
   记录顺序只服务于数组对应，不作为物理特征。
4. **保留真实几何。** 距离不截成统一上限，位移不换成只含符号或长度的信息。
   任一有向记录应有反向记录 `(b,j,i,-T)`：距离相等、位移相反。
5. **处理填充和空邻域。** 填充原子既不接收也不发送；没有邻居的有效原子仍保留在原子列表中。
   `E=0` 时各字段仍保持表中约定的形状，如位移和周期平移为 `[0,3]`。
6. **区分定位与物理特征。** 原子索引和 `T` 用于定位邻居。等价坐标或晶格基底表达下，
   编号和 `T` 可以变化；向量须按对应笛卡尔坐标框架变换，框架间的正交变换可能含反射。
   距离与物理邻域应一致。
   后续几何特征从真实距离、位移及相对关系构造。

分数坐标逐轴折回在现有枚举器中仅用于稳定枚举范围，不代表选定了最短实空间镜像。
返回的 `shifts` 已换回与原始分数坐标配套的整数平移，重建位移时直接使用它。

例如，边长 3 Å、每晶胞一个原子的立方晶体，在 `R=3.01 Å` 下应有六条邻居记录：
`i=j=0`，`T` 分别为 `(±1,0,0)`、`(0,±1,0)`、`(0,0,±1)`，距离均为 3 Å。
这是记录语义的合成例子，不是本轮半径选择。

## 现有实现与后续使用

- [`build_cell_from_lattice`](../../utils/relative_features.py) 恢复真实晶格及分数坐标。
- [`build_g2_edges`](../../utils/g2_periodic_edges.py) 枚举并返回原子索引、周期平移和真实距离；
  `k` 是枚举范围元数据，`L` 是原子槽数，均不作为边的几何特征。
- [`periodic_edge_vectors`](../../model/periodic_manybody.py) 按相同记录顺序重建真实位移。
- [`g2_indegrees`](../../utils/g2_periodic_edges.py) 可按中心统计有向记录数，含同一 `j` 的多个
  镜像及自身跨胞镜像，不是按原子编号去重后的数量。

独立几何核心现为 [`utils/periodic_geometry.py`](../../utils/periodic_geometry.py)：
`build_periodic_records` 在检查输入后复用枚举器，`periodic_edge_vectors` 重建相同方向的位移，
`PeriodicNeighborRecords` 提供 `batch/dst/src/shifts/vectors/distances` 六个字段及显式半径/掩码。
它拒绝非自身零长度记录，以免出现未定义的单位方向；不是静默删除异常邻居。
`from_edges` 不独立证明调用者的完整性或去重，旧模型中的位移函数保留冻结。

旧稠密路径 [`compute_relative_features`](../../utils/relative_features.py) 每个原子对只返回一个
分数坐标逐轴折回所得镜像，不保证斜晶胞中的笛卡尔最近镜像；其方向使用 `f_i-f_j`，从邻居
指向中心，距离还被截到 `cutoff*1.1`。它与本规范的方向、多镜像及真实距离约定不兼容，
不能替代这里的记录来源或把其输出直接作为 `r,d` 使用。

元素身份由原子索引关联到 ZP 初始化或当前原子状态；周期镜像引用同一 `j` 的状态，
其不同几何仍分别保留。两个以同一原子为中心的非零位移向量可用于计算键角，距离分布可用于
分析壳层；本文不预先选择角度编码、壳层划分或消息聚合公式。
