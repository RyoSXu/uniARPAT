## 一页结论（给马尚酱）

1. **现有实验可靠排除的范围很窄。**被否定的都是"特定组合"：G2a 那一种径向多镜像边条件消息、
   R2b 那一种低容量原子加性 phDOS 读出、R1b 那一种"坐标 MLP query + target 置零"组合、
   slope-loss 那一个权重 0.10。G2a 平局**不覆盖**角度／等变方向消息、接收—发送—边联合非线性内容、
   替换式（而非附加式）聚合，也不覆盖 35-epoch 或其他训练预算。
2. **训练拟合没有被当成泛化写进结论，但存在被误读的风险。**四个小样本探针的日志和正式 CSV 都明确
   限定为"32 个 train 材料的可拟合性见证"；但"encoder 参与更新使 16/16 通过"这类句子在多份日志中
   反复出现，且联合臂的 oracle 中位 R² 0.640 只是这 32 个训练材料的指标。同一时期真正的留出检验
   （冻结读出、联合适配在 117 个未见组成上）全部是**变差**，两者的落差必须一起读。
3. **冻结关闭分支没有被当作重新训练消融，日志表述正确。**edge_zero 的 eDOS oracle +0.0083 是
   "已训练权重依赖该分支"，不是 G2 收益；真正的对照是独立训练的 `_g2ctl`，其 Δmedian 仅 −0.000709
   且区间跨零。任何"G2 有用／无用"的引用都必须以后者为准。
4. **同组成谱差不足以定位 encoder。**B7 在 320 个 valid 同组成对上的目标／预测谱差 TV 为
   0.269746／0.016039（`results/edos_spectral_support_q1_valid_pairs.csv`，本轮复核），
   条件响应不足是事实；但同样现象可由读出收缩、标签来源差异（D4b）、谱形支持不足（valid 最远支持组
   中位 R² 0.3695、失败率 11.76%）解释。冻结读出探针把响应放大 2.97 倍反而使留出误差恶化 2.73%，
   说明"响应小"不等于"信息在 encoder 丢了"。
5. **现有实验不能区分编码、读出、监督、数据支持四类解释。**四条线上都只有"某具体干预未获支持"，
   没有任何一条能独占解释权。把 encoder 排在第一位目前缺依据；数据支持／标签质量是尚未排除的
   竞争解释。合法结论是**暂不足以排序**。
6. **两个值得深入研究的模型问题**（不构成实施方案、不排序）：
   (A) 在相同周期边与聚合下，接收—发送—边联合非线性消息内容相对 G2a 逐通道径向门控的表达差别；
   (B) 在完整谱形 + H1 约束下，同组成谱差辅助监督能否把"响应不足"转成泛化收益。
   两者各有最强反证，见第五节；当前证据不足以在 (A)、(B) 与"数据支持／标签质量"之间排序。

## 三、重点审查

### 1. G2a 平局能排除多大范围的几何方案？

**事实：**G2a 只改变一个开关，形态是"普通层之后附加逐通道可分的发送端 Value × 径向门控 × cutoff，
按入度平方根求和"（`utils/g2_periodic_edges.py::build_g2_edges`、
`model/transformer.py::PeriodicEdgeMessage.forward`，R1 附录 B2）。判据在 test、ep10、单 seed、
单 R=5.5 Å 下给出双任务平局。

**排除范围（推断）：**只排除"该形态、该预算下能带来 ≥+0.02 中位 R²"。未排除：(a) 边角关系或有约束
方向／等变消息；(b) 接收—发送—边联合非线性内容（G2a 消息不含 `h_i`，也不含边—边交互）；
(c) 替换式聚合（ALIGNN/ComFormer 的归一化门控平均或 gate×phi）而非附加残差；(d) 35-epoch 或
其他预算下才显出的收益；(e) 子集收益（如同组成对的条件谱差）被全体中位数稀释——结构信号诊断已显示
同组成组内 TV 0.252–0.320，说明存在"该被区分却没被区分"的样本群。

**最强反证：**G2a 已把几何送进消息内容并保留配位信号，通路核验证明影响到达输出（valid eDOS 谱 TV
0.01469），仍无收益；联合边条件探针开放 encoder 更新也未胜过原始读出。"再加一点几何表达就会赢"
不是自动成立的假设。

### 2. 训练拟合是否被当成泛化？

**事实：**四份小样本日志均写明"只证明本批数据可拟合、未检验 valid/test"；`g2-probe-route-review`
明确"成功不能区分能推广的结构规律与专门适配"。32 杄料指标只作补充列示。**结论层没有把拟合当泛化。**

**但风险实存（推断）：**(a) "encoder 参与更新→16/16"与"冻结→8/16"的对比反复出现，容易被读成
"encoder 适配有收益"，而同名联合臂在 117 个未见组成上是恶化（+1.55% vs original）；
(b) 联合臂 25.4M 读出参数始终可训练，成功不能单独归功于 encoder 或 G2；
(c) 最后层臂 32 材料 blind 失败率 3.125%→21.875%，谱差成功与单谱质量明确分离；
(d) 2,000 步对 16 对 vs 10 轮对 2,591 对，暴露次数差约 200 倍，"原 10 轮没学会"与"表征不可读出"
在全配对实验里无法区分——这正是路线复盘撤回继续拆层的依据。

### 3. 冻结关闭分支是否被当成重新训练消融？

**事实：**通路核验把两者分开报告：edge−control（独立训练）Δmedian −0.000709 跨零；
edge−edge_zero（同权重关闭）+0.008300。日志原文明确"不能当作重新训练后的 G2 收益，或将 edge_zero
当作独立训练的 control"。`non_g2` 臂同样被正确限定："G2 输入来自变化中的普通 encoder，其输出仍会
改变；这不是关闭 G2 的消融"。**没有被当成重新训练消融。**引用这组数字时必须带上这个限定，
否则会把 +0.0083 误报为 G2 的收益证据。

### 4. 同组成谱差是否足以定位 encoder？

**不足以（推断）。**证据链：320 valid 对目标 TV 0.2697 vs B7 预测 TV 0.0160（315/320 对预测差小于
目标差）→ 条件响应不足为真。但定位 encoder 需要排除至少四类替代解释：
(i) 读出收缩——冻结读出把响应放大 2.97 倍却使留出误差 +2.73%，说明"响应大小"与"准确"解耦；
(ii) 标签来源差异——D4b 显示负频坐标质量问题真实存在且与 phDOS 失败强相关，同组成对的"真实谱差"
可能混有来源／收敛差异；(iii) 谱形支持不足——valid 最远支持组中位 R² 0.3695、失败 11.76%，
同组成对现象与稀有度共变；(iv) 配对口径——258/320 对"结构匹配判为不同"依赖 StructureMatcher 容差，
"不匹配"不等于已证实不同多晶型。单元素盲点（valid 37/2313=1.60%）只解释极小部分。
另有：320 对覆盖的 394 条 valid 样本中位 R² 0.5406 高于未配对 1,919 条的 0.5108，该现象本身
不解释整体失败尾部。

### 5. 已有实验能否区分编码、读出、监督与数据支持不足？

**不能（事实层面的推断总结）。**四条线各自只有"具体干预未获支持"：
编码侧：G2a 平局、G2 通路有响应但无收益、联合适配留出恶化 → 未定位；
读出侧：R1a 平局、R1b 组合失败、R2b 失败、冻结读出留出恶化 → 未定位；
监督侧：C2.1b 无负冲突、L3 删项无收益、slope-loss 机制不支持、梯度非稀释 → "损失不平衡"类假设
弱化但**未检验过辅助监督**；
数据支持侧：谱形稀有度、train–valid 落差、D4 负频质量均为实证关联，且数据线已收口。
任何把 encoder 单独排在第一位的说法目前都缺依据；同样，把数据当唯一根因也缺依据。

### 6.（P2 附带）数据 A 线两个口径问题

- "train 升、valid 不动 → 标签不可约"**不成立**：最多说明指定扩充方案未获 valid 收益，
  仍可能涉及选样、优化、表示或过拟合（`geometry-message-research` §5 已记录，本报告确认）。
- 121,420 / 7,965 / 外推 7,500 **都不是可训练数量**；把旧增量 95% 落实率外推到缺失群体缺依据。
  A 线保持收口，本轮不争取任何数据加工授权。

## 五、最多两个值得深入研究的模型问题

### 问题 A（编码侧，优先研究但不等于优先实施）：联合边条件消息内容的表达差别

- **问题：**在**相同周期边集合、cutoff、聚合、层位置与 memory 合同**下，把消息内容从
  "发送端 Value × 径向门控"（`PeriodicEdgeMessage.forward:65–80`，逐通道可分、不含 `h_i`）
  改为接收—发送—边联合非线性 `gate(h_i,h_j,e_ij)·phi(h_i,h_j,e_ij)`（ComFormer 节点消息形态），
  是否真能表达 G2a 形态不可表达的环境，并转化为完整 Q1 valid 的谱差响应与精度？
- **依据（事实）：**B7 同质 Value 消去（`TransformerEncoderLayer.forward:703–745`，q=k=v=src）；
  G2a 已修内容缺口但平局；同组成对条件响应不足（0.2697 vs 0.0160）；该问题作用于多元素全体，
  不局限于 1.60% 单元素。
- **最强反证：**G2a 内容已生效却未赢；多层普通注意力 + 前馈可间接合成类似交互；
  联合适配已开放全部 encoder 更新仍未改善留出——若"内容表达力"是主因，开放更新应至少部分受益。
- **替代解释：**瓶颈在读出／监督／数据支持；同组成谱差可能含标签来源差异（D4b）；短预算未学会
  而非不可表达（small-fit 证明 16 对在 2,000 步内可被联合网络拟合）。
- **什么证据会改变排序：**(1) R3／公式核对显示参考实现的消息可化简为"发送项×径向门控"，
  则"新增联合能力"的理由失效，本问题降级；(2) 若同组成对的"预测差≈0"集中在**径向分布相近而角环境
  不同**的样本（可用现有缓存几何只读分层验证），本问题升为第一；(3) 任何在完整 Q1 valid、完整谱形
  目标下的成对结果若平局或退化，按预注册直接 park，不因同组成子集改善晋级。

### 问题 B（读出／监督侧）：完整谱形约束下的同组成谱差辅助监督

- **问题：**保持 B7 默认 SumNorm KL/W1/Huber + H1 不变，只**增加**一个同组成谱差辅助项
  （而非纯谱差替换），能否在不损失共有谱形与 blind／phDOS 的前提下，改善留出组成的条件谱差
  并转化为主验收收益？
- **依据（事实）：**纯谱差目标的两轮探针都显示"缺共有谱形锚定"是主要破坏模式（主 valid oracle
  0.4687→−0.8478）；路线复盘把它列为可评审候选；结构信号诊断显示同组成谱差是真实存在的监督缺口。
- **最强反证：**该辅助监督从未被检验，没有任何结果支持它可泛化；C2.1b／L3／slope-loss 三线
  对监督改动均负；C2.1b 已证明双任务梯度无负冲突，加项只会增加共享参数上的梯度压力。
- **替代解释：**同组成对差异含标签来源成分（D4b），监督该差异可能在拟合噪声；谱形支持不足
  意味着有效样本太少，加损失不解决覆盖问题。
- **什么证据会改变排序：**(1) 若只读分层显示同组成对的目标谱差在**同一来源内部**仍显著
  （排除来源混杂），本问题升为第一；(2) 若先做小样本正对照显示实际网络在保留完整谱形损失时
  无法同时降谱差（可拟合性失败），则该路线降级；(3) 预注册的整体 valid 主指标若无收益，
  直接终止，不以谱差下降或小样本通过晋级。

**排序结论：现有证据不足以在 A、B 与"数据支持／标签质量"三者之间排序。**若 R3 的机制核对不能
把 A 与 G2a 真正区分开，合法选择是暂不改模，先用已有产物做只读的"同组成对 × 来源 × 谱形支持"
交叉分层（不读取新 test 标签、不训练），再决定是否值得占用一次独立验证。

### 三条足以改变方案取舍的反证（P2 要求）

1. **若 R3／公式核对表明候选消息可化简为 G2a 已测形态的重参数化**，则整个"联合内容"路线失去
   超出 G2a 的理由，应整体淘汰而不是缩小范围重试。
2. **若同组成对的目标谱差在控制来源（MP `pheasy` vs JARVIS）后大幅缩小**，则"条件响应不足"
   的相当部分是标签口径现象，A／B 两个模型问题都应让位于数据口径澄清（不等于授权数据加工）。
3. **若小样本正对照显示"完整谱形损失 + 谱差项"在 16 对上不可同时拟合**（实际网络、固定预算），
   则 B 的失败模式是目标冲突而非泛化不足，该路线应在设计阶段终止，不消耗 pilot。
