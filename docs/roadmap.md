# 路线图

项目目标是从晶体结构可靠地盲预测 eDOS 与 phDOS。本页说明方向与阶段关卡；唯一的活跃任务
清单是 `backlog.md`。

## 近期：在固定基线上改进解码器

以 B7 和 Q1 数据池为基础。下一项已批准方向是解码器/读出层：验证条件式逐点读出层或专家混合
网络能否在不破坏 blind 缩放的前提下改进谱。每个假设先做单因素 pilot，只有 pilot 胜出才进行
等算力确认。

## 中期：加强表征与效率

通过解码器关卡后，依次评估编码器改进、仅 eDOS 的辅助学习与预训练选项。分桶 batch、自动混合
精度、lint 与代码拆分等工程改进，除非会改变模型输出，否则不得与模型性能结论混为一谈。

## 长期：连续谱预测

最终目标是在任意能量或频率上查询的谱场。这将解除固定 bin 的限制，但不能借此同时改变数据网格
和解码器假设：应先证明能量条件读出层有效，再考虑非均匀窗口和连续谱场。

## 不可违背的关卡

1. 保持 Q1 数据口径，并分别记录 oracle 与 blind 指标。
2. 生产推理保持仅使用 CIF 的输入约定。
3. 每次只比较一个因果改动，使用等量算力和书面结论规则。
4. 将数据、网格和归一化改动视为新的基线。
5. 通过受版本控制的 CSV 摘要、配置和带日期工作日志保持结果可复现。
