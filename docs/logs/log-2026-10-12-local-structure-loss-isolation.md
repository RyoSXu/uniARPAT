# 2026-10-12 — C1 小样本联合损失与仅谱差损失对照

## 范围与事先固定的协议

用户确认执行分钟级对照，检查其他训练目标是否妨碍已见材料的谱差拟合。
只用修复版 `crystal_q1_v1` 的 train、seed 42；任务是 SumNorm 单位和 eDOS 谱差，
不评估 blind/oracle 物理尺度，不读 valid/test，不改变模型公式、正式接口、划分或源 checkpoint，
不做 Git 提交。这不是从头训练或泛化试验。

- 复用[原小样本拟合](log-2026-10-12-local-structure-small-fit.md)的 16 对/32 材料，
  420 原子、最大 28；材料顺序和两类目标逐值检查，抽样不重新选择。
- 共同初值为 C1 best ep34，逐张量指纹等于原归档；fresh AdamW，lr=5e-5、betas=(.9,.99)、
  weight decay=.01、固定学习率、dropout=.05、FP32，各 600 步，每 100 步评价，比较固定终点。
- joint：完整原训练目标（单材料 eDOS/phDOS 谱形和 H1 eta/gamma 监督）＋零权重谱差。
- pair_only：完整原目标乘零＋λ乘既有 `edos_pair_contrast_loss`；
  λ=3.677382707595825，直接复用原校准值，不重新调权重。
- 两组每步先联合前向、再谱差前向，用同一完整批次、一次 optimizer 更新；
  起始和结束 RNG 摘要须相等，不冻结参数。pair_only 先用零系数反向得到零梯度，
  保留一致的 AdamW 参数参与及衰减；不在谱差路径上的 phDOS/尺度头仅有权重衰减。
- 各 8 步成本探针丢弃，再回到共同初值和空 optimizer。两组预计拟合成本须低于 900 秒；
  超时或非有限值停止，保留不完整证据，不自动追加预算或重跑。

谱差误差 E=.5∑|Δp−Δy|，零响应 E0=.5∑|Δy|，skill=1−E/E0。
沿用整体充分拟合判据：平均 E≤.2平均 E0，且≥75%配对误差减半。
H1/H2 分别按固定 step600 E≤.2E0 判断强拟合；不让整体改善隐藏困难对失败。
成功只支持此次目标替换改善本批拟合，不能确认唯一根因、哪一原损失负责或 valid 收益；
失败不证明表达能力不足，优化、预算、目标对应等解释仍保留。
