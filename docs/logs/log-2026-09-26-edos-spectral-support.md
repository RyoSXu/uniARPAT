## 证据

- **冻结配置与评估口径：**`output/ablation_m1_e9ctl/config_used.yaml` 中 `model=M1`、`seed=42`、`norm=sumnorm`、`use_mask=false`；`checkpoint_best.pth` 为 epoch 33。分别按原始顺序加载 Q1 train 18,706 条和 valid 2,313 条，在 `eval()`、`torch.inference_mode()` 下前向。eDOS logits 经 softmax 后乘真实谱总量并截为非负；目标也反归一化到物理尺度。用 `utils.metrics.per_sample_spectral_metrics` 在全部 128 个 bin 上计算 oracle R²，`R²<0` 为失败；不使用 coverage mask。预测形状 L1 是 softmax 谱形与总和归一化目标谱形的绝对差之和。
- **距离定义：**目标谱最近邻总变差（TV）为目标谱先按总量归一化，再对训练集中每条谱计算 `0.5×Σ|p_i−p_j|` 并取最小值。train 查询时排除所有**各元素计数完全相同**的样本，防止自身和同组成重复谱成为最近邻；valid 查询全部 train。组成距离仅作粗代理：各元素原子数除以总原子数形成元素比例向量，再取最近 train 的欧氏距离；train 同样排除完全相同组成。距离计算采用 FP32，分组阈值只从 train 最近邻 TV 的四分位数得出：`0.161389 / 0.204902 / 0.253176`，边界值分入较远一组。
- **可复核结果：**逐样本 CSV 含划分、划分内索引、MP ID、目标粗糙度、两种最近邻距离、物理尺度 oracle R²、失败标记、谱形 L1 和 train 距离四分位组。valid 对应 MP ID 顺序与 `results/edos_error_attribution_q1_valid_samples.csv` 一致，重算 R² 最大绝对差 `8.35e-7`、粗糙度最大差 `1.06e-8`；与 `results/c2_1b_valid_samples.csv` 的 eDOS 谱形 L1 最大差 `4.77e-7`。train/valid 整体中位 R² 为 `0.605362/0.514983`，失败数为 `152/145`，与先前冻结诊断一致。

- **连续关联与边界：**train/valid 最近目标 TV 中位数为 `0.204902/0.206130`，分布中心接近，不能说 valid 整体明显缺少训练谱形支持。最近目标 TV 与 oracle R² 的 Spearman 相关为 train `−0.308`、valid `−0.451`；与 valid 谱形 L1 为 `+0.805`，与 valid 粗糙度为 `+0.663`。在 valid 粗糙度十等分的每一组内，TV–R² 相关仍为负，但粗糙度等性质与距离有关联，不能将此视为独立因果效应。以 valid 自身距离四分位端点作描述性比较：最近 579 条中位 R² `0.632026`、失败 `13/579=2.25%`；最远 579 条为 `0.366303`、`70/579=12.09%`。最远减最近的中位 R² 差 `−0.265724`，按两组样本独立重采样 2,000 次、seed `20260926` 的 95% bootstrap 区间为 `−0.300593…−0.236257`；失败率差 `+9.84` 个百分点，区间 `+7.08…+12.78` 个百分点。这是关联的抽样区间，不是机制效应区间。
- **粗糙度与组成粗代理：**train p90 粗糙度 `0.351600` 以上的目标 TV 中位数 train/valid 为 `0.331725/0.337379`，其他组为 `0.197767/0.200950`；但高粗糙度 valid 组的最近组成欧氏距离中位数 `0.141421`，比其他组的 `0.182108` 更小。valid 组成距离与 R² 的 Spearman 相关仅 `−0.072`，与失败标记为 `−0.039`。因此简单元素比例距离不支持“高粗糙度误差主要源于组分离训练集较远”的解释；它忽略元素相似性、晶格和局部结构。
- **同组成材料对：**valid 中按各元素计数完全相同分组，有 170 组、394 条样本，形成 320 对缓存结构表示不同的材料。对每对计算归一化目标谱及 B7 预测谱的 TV；目标 TV 中位数 `0.269746`，预测 TV 中位数 `0.016039`，预测减目标 TV 的配对差中位数 `−0.238858`，`315/320` 对预测谱差小于目标谱差。用缓存的 `pos[0]=[a,b,1/c]`、`pos[1]=[α,β,γ]` 和原子分数坐标重建结构；`StructureMatcher(ltol=0.2, stol=0.3, angle_tol=5, primitive_cell=True, scale=True, attempt_supercell=False)` 判为不匹配的 275 对中，目标／预测 TV 中位数为 `0.282521/0.015932`；判为匹配的 45 对仍为 `0.179382/0.017382`。这些对共享样本，匹配与否依赖容差；“不匹配”不等于已证实不同多晶型或标签无误。配对覆盖的 394 条 valid 样本中位 R² `0.540632`、失败 `26/394`，未配对 1,919 条为 `0.510820`、`119/1919`，因此这项现象尚不能解释整体失败尾部。
- **执行验证与复算边界：**在仓库根目录以一次性 `python3 -B` 内存脚本调用 `ConfigBuilder.get_dataset`、冻结 `basemodel`、`per_sample_spectral_metrics`、`torch.cdist` 和 `StructureMatcher`，按上面的路径、公式、排除规则和阈值计算。结果文件写入前核验 Q1 样本数、配置与检查点、valid 缓存逐样本 R²/L1、train/valid 总体中位数及失败数、四分位组样本数、320 个唯一材料对与 45 个结构匹配对。结果文件使用仅创建模式写入；未覆盖既有结果。因本轮不改源码，未保存可直接重跑的评估脚本；无代码测试。

## 结论

- **状态：closed（冻结模型只读诊断）。**稀有目标谱形与较低的 train 拟合准确率、更大的 valid 泛化差距同时出现，关联覆盖全体 eDOS 而非只限于高粗糙度组。valid 同组成材料对还显示 B7 的结构条件谱形变化明显小于真实谱形变化；这是需要进一步检验的条件敏感性线索。
- **解释边界：**最近邻目标 TV 使用了真实 valid 标签，只能用于事后诊断，不能充当部署时可用的输入或证明训练分布漂移。谱形稀有度、粗糙度及 R² 的谱方差分母可能耦合；同组成材料对的真实谱差也可能混有标签或数值条件差异。单个冻结检查点的这些观察不能区分输入信息不足、模型表示、数据覆盖和标签质量，更不能直接授权某种架构、损失或数据处理改动。
