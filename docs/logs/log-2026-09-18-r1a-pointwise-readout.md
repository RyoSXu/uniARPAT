# 工作日志 2026-09-18：R1a 参数匹配逐点读出头

## 改动与验证

- 在 M1 载具上实现参数匹配的逐点 MLP 读出头：
  - eDOS：以逐点 MLP `512→3→1`（中间 GELU）替代单层 Conv1d；实测参数量 1,543（对照 Conv1d 为 1,537，+6 参数）。
  - phDOS：以逐点 MLP `512→2704→2704→2704→2704→2704→1`（中间 GELU）替代六层 Conv1d；实测参数量 30,647,137（对照 Conv1d 为 30,683,137，容量差 −0.117% < 0.2%）。
  - 总模型可训练参数量严格为 71,116,970（对照组 71,152,964，差异仅 −0.05%）。
  - `--r1a_point` 默认关闭；关闭路径的状态字典、参数量及前向输出与当前 M1 完全相同。
- 单测验证：
  - 关闭路径等价性（Bitwise exact）
  - 逐点置换合同（Permutation equivariance contract：$f(P x) \equiv P f(x)$，对比 Conv1d 必然打破合同）
  - 参数预算精确匹配
  - 有限梯度回传（所有输出层参数梯度有限且非零）
  - 全套 42 项单元测试通过
  - 真实 Q1 训练集 CPU 单步冒烟通过
- 训练口径：`_r1actl` 与 `_r1apoint` 均为 Q1、M1×10、seed 42、E0/P0、SumNorm KL/W1/Huber、H1 eta/gamma、dropout 0.05 的 oracle 测试口径。

## 结果

| 臂 | eDOS 中位 R² / 失败率 | phDOS 中位 R² / 失败率 | Cv MAE | 单轮耗时 | 峰值显存 |
|---|---|---|---:|---:|---:|
| `_r1actl` | 0.4751 / 4.50% | 0.7220 / 1.22% | 0.2906 | 189.1s | 8,906 MiB |
| `_r1apoint` | 0.4649 / 4.72% | 0.7122 / 1.22% | 0.2956 | 184.0s | 8,730 MiB |

- 增量（逐点 MLP − 对照 Conv1d）：
  - eDOS：中位 R² −0.0102 / 失败率 +0.22pt
  - phDOS：中位 R² −0.0098 / 失败率 0.00pt
  - Cv MAE：+0.0050
- 性能与开销：两任务指标变化均在平局线（`|Δ中位 R²| < 0.02` 且 `|Δ失败率| < 1.0pt`）之内；单轮耗时降低 5.1s（−2.7%），显存下降 176 MiB（−2.0%），全程无 NaN/Inf。
- 盲推理说明：本轮为 10 epoch pilot 初筛，未取得 accuracy win，按规程保持 oracle 评估口径，不进行 35 epoch 确认。

## 结论

**R1a 技术通过（Technical Pass），但不替换默认 baseline。**
逐点映射不依赖 bin 间卷积局部耦合，在保持等价参数容量下性能位于平局线内，且计算开销与显存略优于 Conv1d。这验证了非卷积接口的可行性，满足 `docs/design/design-r1-readout-migration.md` 设定的准入技术门槛。
