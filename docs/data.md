# 数据约定

本页说明当前训练代码允许使用的数据。为保持简洁，获取过程保留在日志和 Git 历史中；可复现的
缓存边界只在此处维护。

## 当前训练数据池

唯一的生产数据池是 **Q1**：

| 划分 | 样本数 |
|---|---:|
| 训练 | 18,706 |
| 验证 | 2,313 |
| 测试 | 2,287 |

其清单文件为 `data/train4ARPAT/manifest.json`。Q1 排除了 1,682 条电子谱截断或覆盖范围标签
（coverage label）不可用的记录；排除清单为 `data/quarantine_q1.json`。旧数据池保留在本地
`data/archive/` 下，报告时必须标为 **pre-Q**，不得与 Q1 指标直接比较。

## 可复现边界

- 数据划分固定在 `index/split_v2.yaml`。
- 价电子和截断参考表位于 `index/z0_*`。
- 网格定义及 C2b 审计位于 `data/grids_c2b/`；生产使用 E0 + P0。非均匀网格需要非卷积
  解码器。
- 训练缓存文件是机器本地文件，且被 Git 忽略。清单与统计信息受版本控制，因此可检测缓存
  是否缺失。

## 安全操作

通过训练入口使用 `data/train4ARPAT/`。如确实需要重建 Q1 缓存，先阅读
`tools/data/README.md`，再用 `tools/data/process/q1_rebuild.py` 并显式指定源和目标路径。
该脚本会将现有缓存移入 `data/archive/`；不要随意运行。

原始数据获取不是常规训练的前提条件。保留工具见 `tools/data/README.md`；过去数据活动的
细节可从 Git 历史和带日期日志中恢复。
