## 1. 为什么这样切（动机，进论文写 rationale）

- v1 教训：测试集 13.6% 的成分在训练集出现过；且同成分不同构型的谱相关 <0.5 的占 18.5%——
  成分泄漏让 fail 率虚低，测的不是泛化。因此 v2 用**成分组硬隔离**代替随机切分。
- 三层分层保证三集“同分布”：电子结构类型（带隙）、几何对称性（晶系）、谱难度（峰均比），
  否则涨点可能是集间分布差 artefact。

## 2. 方法（四步，可直译为 Methods 段落）

1. **标签**：带隙档（金属 0 / 半导体 0–2 / 绝缘体 >2eV，MP summary）× 7 晶系（原胞 symprec=0.1）
   × 难度三分位（峰均比 `max(峰/均_eDOS, 峰/均_phDOS)`，三分位点 8.74/13.32）。
2. **成组**：元素计数精确相同的样本为一组（同分异构体同组），共 22,656 组；
   组是最小分配单位，整组进同一集。
3. **贪心**：稀有 cell（<10 样本）整包保底进训练集；其余组按大小降序，
   每组补给其主 cell 下 8:1:1 亏空最大的集（seed42 定抽样与并列顺序）。
4. **探针**：测试集中找含训练集未见元素的样本，记 `probeanel.json`（抓到 1 条）；
   He 规则跳过（v2 双谱核心集不含 He，F3 已决断）。

## 3. 结果（进论文写 Data splits + Supplementary Table）

- 20,040 / 2,477 / 2,471（8:1:1）；成分零跨集（脚本 assert 通过）；
  三层各档三集分成与目标偏差均 <±2%（如带隙三档 0.802/0.099/0.099）。
- `split_report.json` 存全部分层表；`split_v2.yaml` 存三集 ID（seed 42，旧索引保留可比）。

- 本切分与 v1 切分无对应关系，绝对分数不与 v1 直比（Design-A6 已冻结此条）。
