# 当前LR2完整模型的物理与晶胞一致性验收

用户于2026-11-02同意执行。冻结staged LR2＋E＋S ep29；不训练、调配方、重新选点或评估test。
本项检查同一结构是否因表示方式产生假谱差，不检验预测精度或同组成谱差泛化。

## 输入与范围

只读取完整train晶体几何与ID，不读取谱标签。排除manifest中两条训练隔离材料。
按原子数十个分位、最大晶胞条件数及seed42补足16条，包含最小／最大完整原子数；不裁剪。
另加单原子立方晶胞边长5.99998、6.00000和6.00002 Å，主动覆盖严格截断边界。

原生`CrystalGeometry`直接变换完整晶格和分数坐标，不经过标准原胞化或固定帧重建。
复用既有六个E(3)变换，另测重复推理、原子重排、整格平移坐标、包裹后的晶胞原点平移、
det±1换基、沿三个轴分别扩成两倍超胞。逐一核对实际送入Encoder的完整邻居记录；
超胞按每个原始中心副本比较，不要求总记录数不变。

FP32对应生产数值；FP64是同一已存FP32输入和学习权重的高精度运算参考，不能恢复源数据精度。
完整模型保持eval与冻结参数，复用生产E0/P0网格和blind重建。
主扫描关闭几何缓存以独立重建记录，另在首个真实样本上复查重复、旋转和超胞的缓存冷／热路径。

## 运行前固定的判据

两任务均检查单位和谱形、每原子窗口总量、每原子blind谱密度及随原子数倍增的总谱。
对比较量先按固定train参照无量纲化：谱形除1，总量除m_ref，每原子谱除m_ref/dx，
总谱除变换后原子数乘m_ref/dx。逐点要求
`abs(a-b) <= atol + rtol*max(abs(a),abs(b))`。

- FP32：atol=2e-6、rtol=2e-5，沿用既有完整模型输出检查量级。
- FP64：atol=1e-10、rtol=1e-8，作为预先固定的双精度数值参考。
- 邻域距离／向量比较复用既有1e-4／1e-6 Å容差，严格`d<6`不变。
- 仅在截止容差内缺失／新增的记录单列`boundary_limited`；不会因此隐藏输出失败或宣称全项通过。
  其余记录、向量不符记为失败；稳定拓扑通过与全部案例通过分别报告。

保存checkpoint、数据、源码指纹，逐案例误差、原谱预测、实际记录比较及参数前后指纹。
输出目录拒绝覆盖。预计分钟级推理，设900秒运行预算；超时保留未完成证据，不自动重跑或调容差。
有限验收通过不能证明所有结构均满足要求；发现违例先区分记录、数值边界及模型路径，
不据此静默改变截断、输入或尺度契约。
