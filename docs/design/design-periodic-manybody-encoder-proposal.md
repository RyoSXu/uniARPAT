# 周期多体局部—全局 Encoder：冻结实验设计

状态：**2026-09-29 已获用户批准并按此设计执行**；执行记录与判决见[实验日志](../logs/log-2026-09-29-periodic-manybody-encoder.md)。目标是在 Q1 上提高结构条件 eDOS 谱形，同时保护 phDOS；本设计只研究 encoder，保留现有 CIF 输入、双谱 decoder/head、归一化和损失口径。以下保留事先确定的判据与预算，不按实验结果改写。

## 已有证据与实验边界

- B7 的六层 encoder 在 `model/transformer.py` 中使用 `q=k=v=src`；相对位置只改变 attention score，Value 不含显式几何。它对单元素晶体有严格的同质 Value 盲点，但 Q1 valid 单元素仅 37/2,313，不能当作总体根因。当前结构条件响应不足及其不确定性见 [`status.md`](../status.md) 和 [`R1 代码审计`](../logs/log-2026-09-26-r1-model-code-audit.md)。
- [G1 日志](../logs/log-2026-09-17-E9P0-G1实现与pilot.md)：枚举 125 个周期平移，为每个原子对选择笛卡尔最近镜像，同时改为稀疏 5.5 Å 图、最多 48 个邻居和 hub。斜晶胞例子由错误的 4.0 Å 修正为 2.65 Å；35 epoch 相对 B7 的历史 test oracle eDOS 中位 R²为 0.514 对 0.518、phDOS 为 0.733 对 0.741。它检验的是组合包，不能单独归因于最近镜像。
- [G2 日志](../logs/log-2026-09-20-g2a-pilot.md)：保留 5.5 Å 内全部周期镜像，让径向距离条件化每层 Value 残差；10 epoch 相对 control 的历史 test oracle eDOS Δ中位 R²为 −0.0066，每轮耗时增加 27.3%。随后[联合边内容 valid 实验](../logs/log-2026-09-28-joint-content-pilot.md)让接收端、发送端和径向边共同决定消息，10 epoch 的 blind eDOS Δ中位 R²为 −0.00055；同组成对预测谱差没有改善。这些结果关闭各自实现，未检验跨层的方向/角度状态。
- 现有 [G2 边审计](../../results/g2_edge_audit_q1.csv)显示，5.5 Å 图的 Q1 valid 原子平均入度中位约 35.6、p99 约 83.7。若显式枚举全部邻边对，费用随入度平方增长。只读抽查 64 个等间隔 valid 样本时，4.5 Å 图的 871 个原子入度中位为 20、p99 为 44，未出现零入度；这是成本设计依据，**不是**全 Q1 的覆盖证明。

## 文献给出的设计线索（不是本项目收益证据）

- 2025 年 [EqDOS](https://pubs.acs.org/doi/abs/10.1021/acs.chemmater.5c01359)把等变图网络用于 DOS，但研究对象是合金表面，损失也包含专门的谱形项，不能照搬其效果。
- 2025 年 [HIENet](https://arxiv.org/abs/2503.05771)讨论不变与等变层的效率取舍；2026 年 [MGT](https://www.nature.com/articles/s41467-026-73627-7)显式更新晶体图的边、角及原子状态。两者的主要基准不是当前双 DOS。
- [原始 Transformer](https://arxiv.org/abs/1706.03762)用独立 Q/K/V 投影，让查询、匹配与传递内容各自学习；这是候选全局层的可选表达能力，不是已定位的 B7 根因。[RoPE](https://arxiv.org/abs/2104.09864)针对有序 token 的相对位置，晶体原子没有自然的一维顺序，因此不直接复制其索引位置编码。
- 跨领域的 [GraphGPS](https://arxiv.org/abs/2205.12454)给出局部消息与全局 attention 的组合思路；[AlphaFold 3 Pairformer](https://www.nature.com/articles/s41586-024-07487-w)说明残基对可以成为持续更新的状态。但本项目 5.5 Å 多镜像图很密，直接复刻 Pairformer 的显式 pair/triangle 计算费用高，周期三角形还需检查镜像闭合。因此本轮只借鉴“关系信息进入持续计算状态”的原则；实际保留的是原子方向状态，并非持久 pair state。

## 唯一候选：窄等变局部状态 + 全局原子注意力

**待验证假设：**影响 eDOS 的局部化学环境不仅取决于距离，还取决于邻键方向的组合。让 `l=1,2` 方向状态跨层存在，并通过张量积回到 `l=0` 原子内容，可能使同组成不同结构的谱形差异进入 decoder。B7 的方向只在打分中使用，G2/joint 只有标量径向边消息，均未实现此路径。

1. 沿用 `utils/g2_periodic_edges.py::build_g2_edges` 的完整周期镜像枚举和 padding 合同，仅把局部计算半径固定为 **4.5 Å**；利用已返回的镜像平移重建笛卡尔边向量。不做任意 top-k 截断。全局 attention 可以混合各原子的局部状态，但不会直接得到 4.5 Å 之外的两原子距离；此取舍本身是候选的一部分。
2. 沿用现有元素数值嵌入，建立 3 个轻量等变局部块；内部通道计划为 `48×0e + 12×1o + 6×2e`，径向基 16 个，方向用已有依赖 `e3nn` 的球谐/张量积。每块更新原子状态，方向通道跨块保留，最后只读旋转不变的 `l=0` 部分。使用稀疏边聚合，避免显式构造邻边对。
3. 保留 6 层全局原子 attention 的 512 维接口，在前三层与局部块交替；全局层对不变原子状态使用独立可学习 Q/K/V 和输出投影，不再使用 B7 的单镜像方向 score。局部 `l0` 投影回 512 维并进入全局主干，最终输出仍是 `[B,L,512]` memory，供原双谱 decoder 和 H1 尺度头读取。
4. 这是一个**完整 encoder 架构包**，不把结果单独归因于 `l=2`、QKV 或 4.5 Å。B7 默认路径及其 checkpoint 保持原样；候选从头按同一 Q1 训练配方训练，不把旧 checkpoint 当成架构兼容权重。

## 执行顺序、判据与预算（批准版本）

1. **实现与合同门。**验证原子顺序置换、分数坐标整格平移及同一晶体不同晶胞基底表达；验证方向通道确实能影响最终标量 memory，并核对 padding/多镜像边。基底重表达合同须针对候选完整路径通过，不能只检查局部块。保留既有 CIF 最多 80 原子合同，不承诺原胞/超胞等价。
2. **资源门。**先对 Q1 train/valid 的 4.5 Å 边数做全量只读审计，再用真实 batch 32 测单步时间和峰值显存。若峰值超过 **24 GB**、单步超过冻结 B7 同设备测量的 **2 倍**，或出现 NaN/OOM，则暂停训练并汇报；不自动缩小模型、换图半径或反复调参。
3. **一次完整候选训练。**资源门通过后，以 Q1 train 18,706 条、seed 42、M1 同一谱损失/归一化训练 **35 epoch**；checkpoint 按与 B7 相同的 valid 选点约定保存。对照为冻结的 B7 `_e9ctl` epoch 33；若改动导致 B7 默认路径或评估口径不再逐样本一致，则先修复，不混用不可比对照。训练及模型选择只用 train/valid，不读取 test。估计在单张 V100 上资源门加一次候选训练最多约 **4.5 GPU 小时**（B7 历史约 190 秒/epoch，实际以资源门为准）。不自动追加种子或第二架构。
4. **Q1 valid 判读。**主科学门为 eDOS **oracle** 全谱中位 R²相对 B7 至少 `+0.02`，且失败率不增加 1 个百分点；部署门另要求 eDOS **blind** 中位 R²至少 `+0.02`，且失败率不增加 1 个百分点。phDOS blind/oracle 中位 R²各不下降 `0.02`、失败率各不增加 1 个百分点。报告 2,313 条逐样本配对差和 bootstrap 区间；320 个同绝对组成对的目标/预测谱差 TV 与谱差误差只作机制读出，不能单独决定晋级。若只过 oracle 门，记录为谱形机制线索，暂停采用并讨论尺度头；若主科学门不过，则停在该候选。若全部通过，再另定多种子复现与角通道消融，不由单次 valid 直接替换默认模型。

## 主要失败解释

Q1 同组成谱差可能受标签计算条件、训练支持或尺度头限制，非角度缺口主导；B7 多层 attention 已可能间接学到部分角关系；4.5 Å 可能漏掉决定电子能带的更长程信息。文献的材料标量、势能或光学谱结果都不能证明双 DOS 会涨点。以上结果即便为平局，也只关闭此宽度、半径、训练配方下的候选，不否定所有周期多体 encoder。
