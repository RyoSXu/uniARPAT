eDOS 盲推理尺度监督；训练数据和隔离规则以 [数据约定](../../docs/data.md) 为准。

数据与旧数组未据此重写，科学审查及当前配方见[状态页](../../docs/status.md)。

## 交付物

| 文件 | 内容 |
|---|---|
| `edos_valence_by_material.parquet` | 24,988 个材料的价电子数审计表，无缺失值。 |
| `valence_by_element.json` | 96 种元素的 PBE 价电子参考表，以及置信度。 |
| `data/train4ARPAT/*/nvalence_*.npy` | 与训练、验证、测试划分顺序一致的价电子数侧车文件。 |

审计表中的机器字段如下。它们用于追溯，不是普通训练输入：

| 字段 | 含义 |
|---|---|
| `mpid` | Materials Project 的材料标识。 |
| `N_val` | 原胞实际价电子数，是本报告的最终值。 |
| `method` | 最终值来自谱积分还是元素表回退的记录方式。 |
| `T_own` | 回退前由该材料自身电子谱得到的原始估计；缺失表示无法可靠估计。 |
| `ratio` | 存储晶胞与原胞之间的整数换算比例。 |
| `confmin` | 元素参考表中最低的置信度：2 为精确，1 为模式值，0 为暂定值。 |

## 判定方法

1. 优先在费米能级以下积分电子态密度，得到材料自身的价电子数估计。
2. 若谱与结构的晶胞比例不一致、积分偏离合理整数，或电子谱不可读，则回退到元素价电子表。
3. 金属样本允许更宽的 25% 偏差带；有带隙的样本使用更严格的整数一致性检查。

这套过程修正了四类已知问题：全谱积分误把未占据能带计入、跨任务费米能级错位、谱所对应的
晶胞与存储结构不一致，以及插值造成的数值振铃。原始细节由审计字段和 Git 历史保留。

## 结果与质量

| 最终来源 | 材料数 | 占比 | 说明 |
|---|---:|---:|---|
| 材料自身电子谱 | 20,546 | 82.2% | 其中 9,808 条为有带隙且整数一致，7,334 条为金属且整数一致，3,404 条未进行整数修正。 |
| 元素价电子表回退 | 4,442 | 17.8% | 包含 311 条晶胞比例异常和 14 条组分不一致记录。 |

材料自身电子谱得出的数值中，84% 与最近整数的差小于 0.02。元素表的暂定值仅用于明确标记的
少数元素；使用它们的样本可通过 `confmin=0` 识别。

## 在 H1 盲推理中的用途

eDOS 的尺度监督目标为 `γ_true = S_win_e / N_val`，其中 `S_win_e` 是 E0 能量窗口内的
电子谱总量。`N_val` 只用于此尺度目标，不改变谱形标签或损失中的 coverage mask。

## Q1 截断隔离规则

以下 D1–D4 是 `data/reference/q1_excluded_records.json` 的依据。

1. **D1：判据。** 截断率为 `trunc = C_full / N_val`；`C_full` 是完整原始电子谱积分，
   `N_val` 是与该谱晶胞对应的核定价电子数。`trunc < 0.5` 表示电子谱截断。该定义与
   `data/reference/q1_excluded_records.json` 的冻结 `criterion` 及 `index/edos_truncation_by_material.parquet` 数值一致。
2. **D2：名单。** 1,668 条满足 D1；另有 14 条 Delta 数据不可读且 `γ_label < 0.1`，表现出
   同样的截断特征。因此共隔离 1,682 条（训练 1,334、验证 164、测试 184）。另有 2 条不可读
   但尺度标签正常的记录保留。
3. **D3：当前数据池。** Q1 为 18,706 / 2,313 / 2,287；旧缓存为 pre-Q，归档于
   `data/archive/train4ARPAT_20260916_preQ1/`，其指标不得与 Q1 直接比较。
4. **D4：影响。** 截断样本移除后，B7 的 eDOS 中位 R² 从 0.463 提升到 0.518；phDOS 是独立
   任务，未见同类问题。
