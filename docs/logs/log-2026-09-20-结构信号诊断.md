# 工作日志 2026-09-20：Q1 同组成结构信号诊断

## 范围

- 任务：检验“G2a 无收益是否意味着结构信息无用”。不训练、不改数据；仅在 Q1 test 上按约化化学式分组，
  度量同组成、缓存结构表示不同样本的真实谱形差异，并与 B7 `_e9ctl` 的逐样本 oracle 误差对齐。
- 工具与产物：新增 `tools/eval/structure_signal_diagnostic.py`，产出
  `results/structure_signal_q1_test_summary.json` 与
  `results/structure_signal_q1_test_groups.csv`。

## 证据

- 数据口径：Q1 test 共 2,287 样本；从原子序数阵列导出 2,061 个约化化学式。176 个公式组同时满足
  至少两条样本且缓存中的元素/晶格/坐标表示不同，共 402 个样本、289 个组内样本对。
- 真实谱均先做总和归一化，只比较谱形。组内中位 total-variation（TV）为 eDOS 0.252、phDOS 0.320；
  p90 为 0.436、0.581。相同数量、不同公式的随机参照对中位 TV 为 0.542、0.588。
- B7 oracle 在这些同公式结构变体样本上的 eDOS/phDOS 中位 R²为 0.532/0.680，整体 test 为
  0.518/0.741；失败率为 5.97%/4.23%，整体为 5.73%/3.50%。按公式组的谱形离散度与 B7 组中位 R²
  的 Spearman 相关为 eDOS −0.507、phDOS −0.650。

## 结论

- 约化化学式不足以唯一确定 Q1 谱形，且同组成结构差异更大的组对 B7 尤其是 phDOS 更困难。因此，
  G2a pilot 的平局不能解释为“结构信息无用”。
- 本诊断不是 composition-only 预测基线：Q1 是 composition-hard-isolation 划分，且缓存结构表示不同
  不等同于空间群去重后的多型证明。它不估计结构信息的完整因果贡献。
