# 数据集 dos_v1

构建时间：2026-11-18（北京时间），替换 2026-11-15 的数组。只从 `data/spectral_db_v1/` 读取，不改数据库。2026-11-15 那版数组已删除；当时的 h2 checkpoint 对不上这套标签。

训练目录是 `views/dos_v1/`（train、valid 和 `manifest.json`）。test 在 `sealed/views/dos_v1/test/`，不放进训练目录。加倍分辨率在 `views/dos_v1_x2/` 和 `sealed/views/dos_v1_x2/`。大数组和过程表不进 Git；本说明、`report.json` 和各视图的 `manifest.json` 进 Git。

合计 73,028 个样本。eDOS 全部来自该材料自己的规范任务，61,835 条。phDOS 26,168 条 MP pheasy、334 条 MP dfpt、4,444 条 PhononDB。JARVIS 没有进入数据集。和 2026-11-15 相比，train 少 2 个样本、eDOS 少 3 条；phDOS 条数不变。少掉的来自同一来源里按每原子面积重排代表，不是新的过滤规则。

主网格上，训练集拟合的能量常数 C：eDOS 12.232，phDOS 0.04029。

## 处理顺序

1. 输入结构。MP summary 的原胞用 pymatgen 标准原胞，`symprec=0.1`，再按现有模型的晶格重建写成 float32。154,377 个材料全部标准化成功。原子数超过 160 的 1,769 个不进数据集，但仍参与匹配，避免它们的计算被挂到别的材料上。
2. 候选。规范 eDOS 62,972 条里能读出结构的、全部 MP 声子、全部 PhononDB，共 100,920 条。JARVIS 不取。
3. 挂到 MP 材料。匹配器参数 `ltol=0.2, stol=0.3, angle_tol=5, scale=True`，不先化成原胞。和提示材料约分化学式相同、匹配成功、每原子体积差不超过 10%，就挂上；晶系可以不同。对不上时，在同一约分化学式里找晶系相同且体积差不超过 10% 的其他材料。只有一个就改挂。有多个时，用 0.75 倍容差再看；仍然只有一个的，挂上但不做标签。
4. 对不上任何材料的声子计算，在同一约分化学式里两两都能匹配、且晶系相同，才收成一组。代表按 MP pheasy、MP dfpt、PhononDB 的顺序，同来源取积分模数更接近每原子 3 的，再按编号。代表的计算结构标准化后作为输入。体积差超过 10%、标准化失败或原子数超过 160 的组整组不用。组里其余谱不单独训练。对不上的 eDOS 不单独成为样本。
5. 标签。一个材料的 eDOS 只用它自己被 MP 指定的规范任务；这条被排除就留空，不用别的任务，也不把别人的规范谱改挂过来。phDOS 按上面的来源顺序取第一条通过规则的。eDOS 窗口态数除以计算胞价电子数大于 3 的不用，这次有 24 条。
6. 切分。盐 `spectral-store-v1/splits-v3/2026-11-12`，约分化学式 SHA-256，10% test、10% valid、其余 train。含 He、Ne、Ar、Kr 的式子进 train。同一式子不会跨划分。没有任何标签的样本不进入数据集。
7. 数组。精确分段线性积分。eDOS 窗口 [−6, 6] eV、128 箱；phDOS [−280, 980] cm⁻¹、64 箱。加倍视图是 256 和 128。谱按输入胞原子数 / 态密度归一化胞原子数缩放。MP 用计算胞。PhononDB 的积分对应 phonopy 原胞，所以用原胞原子数；结构匹配仍用 PhononDB 单胞。没有原胞的 PhononDB 不进入，这次是 0 条。phDOS 在 −20 cm⁻¹ 以下的绝对面积占比超过 5% 时，`imag_flag_phdos` 为真。同一材料上另一条也通过规则的声子谱，按训练集 C 算的每原子能量差超过 0.5 时，`disputed_phdos` 为真。

## 没有采用的做法

- 不把孤立尖峰削掉。异常电子谱只按窗口态数规则排除。
- 体积差超过 10% 的计算直接排除，不留在数据集里再打标记。
- 323 条计算和提示材料的体积差在 10% 以内，但默认匹配器判为不同结构。这个数量低于事先定的 500 条停机线，所以按匹配失败处理，没有改匹配器。

## 过程表

`tables/labels.parquet` 记录每条用了的谱、来源、挂接方式和体积比。`tables/exclusions.parquet` 记录没用的谱和原因。`tables/members.parquet` 记录候选、被合并掉的条目，以及挂上但不做标签的条目。计数在 `report.json`。
