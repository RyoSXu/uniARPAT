# 设计：结构表征与读出重构方向

> 关联：[状态与计划](../status.md)。本文是结构方向的讨论底稿，不是可直接并行实施的任务清单。
> 每个候选在实施前都必须另写单因素设计，并通过 Q1 M1×10 pilot 与等算力确认。

## 一、已经确认的事实

1. **当前基线。**B7 `_e9ctl` 是 Q1 上唯一对照：oracle 测试 eDOS 中位 R² 0.518、失败率
   5.73%；phDOS 0.741、失败率 3.50%。训练目标是 SumNorm KL/W1/Huber，盲尺度由 H1
   eta/gamma 头恢复。
2. **几何当前只进入注意力打分。**M1 encoder 的相对几何编码由距离 RBF 与球谐组成，并作为
   `q_i` 相关的 attention score 偏置；被聚合的 Value 仍只是邻居原子表示。它尚未检验“边几何
   是否应改变传递内容”。
3. **G1 解决的范围有限。**G1 枚举周期平移以寻找每个原子对的最短笛卡尔镜像，修正了斜晶胞中
   的最短镜像错误；随后仍将结果压缩为一个 `[L,L]` 距离/邻接矩阵。因此，它没有保留同一
   `(i,j)` 的多个周期镜像，也不保留 `i=j,T≠0` 的跨胞自镜像边。G1 的 Q1 M1×35 与 B7 统计
   平局且略增成本，故当前默认关闭。
4. **读出接口的已知边界。**R1a 表明参数匹配的逐点 MLP 输出头与卷积头统计平局；R1b 仅否定了
   “plain 标量 MLP 生成全部 query 且 target 为零”的组合，不能据此否定 encoder-only、原子
   PDOS 或未来的锚点式坐标读出。
5. **尺度约定。**当前主任务学 SumNorm 谱形；盲恢复时 phDOS 总量按 `3N_atom`，eDOS 总量按
   `N_valence` 处理。Z0 的 `ratio` 校正的是存储晶胞与谱尺度的比例，不是将所有输入结构统一成
   primitive/conventional 晶胞。
6. **近邻改动的信号。**G1、查询坐标化、损失消融和 token MoE 均未得到 accuracy win；Q1 清洗、
   Z0 与 H1 等数据/尺度闭环则带来更明确的收益。

## 二、近期可执行候选

### E10：宏观晶格状态（park，2026-09-19）

检验模型能否受益于 CIF 可得、且不依赖晶胞表示尺度的全局状态。第一版只使用每原子体积
`V/N_atom` 与质量密度，不使用原胞绝对体积 `V`；它们经训练集统计标准化后，以零初始化残差注入
原子输入表征。该实验不改变 PBC、注意力、数据、标签或损失。

E10 的目标是回答“显式宏观状态是否有信息增益”。Q1 M1×10 的 `_e10macro` 相对 `_e10ctl` 为：
eDOS 中位 R² −0.0060、失败率 −0.04pt；phDOS 中位 R² −0.0058、失败率 +0.74pt；Cv MAE +0.0096。
两项均未获得正向跨线结果，故 **E10 park**，不以更复杂的 token 或 FiLM 融合重试。

### G2：周期多镜像边消息（待专门讨论）

目标是建立显式周期边集合 `(i,j,T)`，使每个截断半径内的真实镜像都作为独立消息边出现，并包括
跨胞自镜像边。它要同时回答两个问题：真实周期邻居如何定义，以及边几何如何改变 Value 消息。

尚未确定实现。候选应在专门讨论后从以下方向中选一个：

- 保留 B7 dense attention，增加零初始化的局域周期边消息残差；
- 用周期多重边替换 encoder 中的局域消息规则；
- 以后再评估包含键角/等变表示的局域几何骨干。

任何 G2 方案都必须先满足：Si 两原子原胞等小胞的多边计数合同、平移/置换/晶胞基矢改写合同、
关闭路径等价性、边数/显存预算；之后才运行训练。G2 不在本轮 E10 实施中隐含加入。

## 三、中期架构方向：encoder-only atomic PDOS

本方向保留，不与连续谱场绑定。其物理形式为每个原子产生固定 E0/P0 网格上的非负局域贡献，按原子
求和后再进行 SumNorm 形状损失；H1 继续恢复每晶胞的 `3N_atom` / `N_valence` 尺度。

它与 decoder 缩减属于同一研究方向，但实验上必须分门：

1. 先筛选 decoder 深度（6→3→1），判断当前 decoder 的容量是否冗余；
2. 再独立评估 fixed-grid encoder-only atomic PDOS；
3. 只有该方向技术可行后，才重新讨论连续坐标、非均匀网格和谱场。

该方向排在 G2 第一轮结论之后、正式大规模预训练之前。

## 四、双任务与数据方向

共享 encoder 只表示两个任务共用结构表征，并不自动证明 eDOS 与 phDOS 有显式相互帮助。若要判断
联合训练的价值，应以后续等预算的 eDOS 单任务、phDOS 单任务与共享双任务比较为依据。

P0 无标签结构预训练的资料来源、许可、去重、CIF 输入边界和预训练目标可提前准备；正式预训练应在
几何 encoder 与 encoder-only 方向基本定型后启动，以免得到无法迁移的预训练权重。显式 EPC 互调制
仅在共享或预训练已显示正迁移后再讨论，不能直接将一个任务的预测谱喂给另一个任务。

## 五、保留但不排入近期顺序

- **组成主导诊断：**作为 G2 研究的前置证据（同化学式不同结构分析；必要时 composition-only
  对照），不单独占一条训练主线。
- **晶胞表示变换：**当前不以 primitive/conventional/supercell 鲁棒性为近期目标；但 E10 不使用
  原胞绝对体积，PDOS 设计继续服从 `3N` 尺度约定。
- **尖峰损失：**仅当错误分层显示失败集中于尖峰谱时，才做峰形诊断和损失候选。
- **负频语义：**负频是坐标而非负的 DOS 值；只有带虚频样本显示特异失败时才做数据语义审计。
- **连续谱场、非均匀网格、窗口/bin：**等待新的读出假设技术通过；R1b 不重跑。
- **C3 PhysMoE：**C5 无收益后降低优先级；不以专家容量扫描取代物理结构假设。
- **SwiGLU、RMSNorm、QK-Norm、额外 AttnRes：**没有当前稳定性或瓶颈证据，不单独作为研究实验。

## 六、工程位置

C4 AMP 与 E6 分桶加动态裁剪均以节省长训成本为目标，不宣称提升准确率。它们应在 P0 或其他长时间
训练前实施；E5 代码边界、E7 CI 和 B7 CIF 推理入口则按工程需要独立安排。
