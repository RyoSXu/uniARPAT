# Encoder v2 全面复核：2025–2026 证据、环境裁定与实验路线

**建档时间**：2026-09-10  
**报告性质**：前沿调研与架构决策复核，不等同于施工设计  
**复核对象**：现有 `uniARPAT` 的 CIF → eDOS/phDOS Encoder、Query Decoder 与物理尺度分支  
**证据口径**：优先采用论文正文/`arXiv`、官方仓库、官方文档、官方模型卡；未找到公开实现或权重时明确写出。论文中的结果与本项目的推断分开记录。

## 0. 最终结论

### 0.1 不建议“大换骨”，建议做受控的三段式升级

当前最稳的目标不是把 `uniARPAT` 改成 MACE、FNO、MoE 或 Hamiltonian 全模拟器，而是：

```text
CIF
  -> 精确周期邻居图（显式 image translation，真实 cutoff）
  -> 低阶不变/等变局部 Encoder + 晶格/全局 token
  -> [B,L,512] atom memory + [B,512] crystal token
  -> 带真实能量/频率坐标的 query decoder
  -> eDOS/phDOS shape + 可审计 scale
```

推荐顺序：

1. **P0：先修数据与几何合同**。在当前数据上禁止直接加入 `3N` 硬投影、Hamiltonian 矩、复杂 MoE 或连续超分辨率。
2. **P0：静态 query 改为坐标条件 query**。用纯 PyTorch Fourier features 或小型 trunk，让模型知道当前 query 对应哪个能量/频率。
3. **P0：把稠密全对几何改为真实周期稀疏边**。先用原生 PyTorch 聚合，不引入编译扩展。
4. **P1：再做谱损失与单标签数据利用**。优先复核 `SumNorm + KL/Huber`，随后做 eDOS-only/phDOS-only 半监督训练。
5. **P2：把 MANDALA、MatBind、DOSSIER 作为辅助思想**，不是第一版主干；完整 Hamiltonian 学习留作独立研究线。

### 0.2 本轮最重要的否决

| 方案 | 裁定 | 原因 |
|---|---|---|
| 直接加载最新 UMA / Orb-v3 / 当前 NequIP / FAIRChem v2 | 否 | 当前官方依赖分别涉及 Torch 2.8、Torch 2.13、`e3nn>=0.6` 或更高版本，超出 `torch 2.2.1 + e3nn 0.5.6` 锁定线；部分权重还需 gated/custom license。 |
| 用 `3N` 对所有 phDOS 输出做硬归一化 | 暂缓 | Phonopy 的全频 raw DOS 确有 `3N` 规则，但当前窗口、primitive/conventional cell、单位和旧 npy 的面积合同尚未统一；当前 npy 的窗口面积审计出现约 1、4、8 倍级别差异。 |
| 用 `N_val` 硬归一化 eDOS | 否 | VASP 的 `NELECT` 是由 POTCAR 的 `ZVAL` 与 POSCAR 原子数决定的全电子口径；当前 eDOS 只覆盖有限窗口，窗口面积不等于价电子总数。 |
| 用完整 FNO/GINO/NeuralOperator 库替换 Decoder | 否 | 这些工作主要有 PDE/通用场证据，没有 DOS 直接证据；完整库还会引入版本或编译风险。只采用可手写的 coordinate trunk 和可选 1D `torch.fft` 消融。 |
| 先上 STMU/NU-TFNO/MPTSS/流匹配/细粒度 MoE | 否 | 尚无本项目实测收益；会同时改变周期图、Decoder、损失和评估，无法归因。 |

### 1.3 当前模型的真实瓶颈

依据 `model/transformer.py`、`utils/rp_encoding.py`、`utils/relative_features.py`：

1. `edos_query_embed` 和 `phdos_query_embed` 是静态可学习参数，形状分别为 `[128,512]` 与 `[64,512]`；它们没有读取真实能量/频率坐标。
2. `RPEncoding(lmax=2,num_radial=64)` 生成 `[B,L,L,576]` 的稠密相对位置张量；`B=32,L=80` 时单个 fp32 张量约为 471.9 MB（约 450 MiB），还未计 autograd、投影和 attention。
3. 目前所有原子对都会进入稠密 attention；代码中没有实际邻居 cutoff mask。`distances.clamp(max=cutoff*1.1)` 不是稀疏化，也不是平滑 cutoff。
4. `model.py:169-173` 当前训练只监督 `outputs['edos']` 和 `outputs['phdos']` 的 Smooth-L1；`predict_scale` 分支的 `phys_*`、`log_scale_*` 没有对应监督，`compute_shape_loss` 也未被调用。现有 Roadmap 已记录 M5 blind 崩塌，因此不能把 Shape-Scale 当作已验证能力。
5. `compute_relative_features` 通过 `diff_frac - diff_frac.round()` 做逐分量最小镜像。对斜晶胞这不保证找到欧氏距离最短的 lattice image。

一个可复现实例：取 `a=(1,0,0)`、`b=(0.8,0.6,0)`、分数差 `(0.49,0.49,0)`，逐分量 round 得到距离约 `0.930`，枚举相邻图片得到真实最短距离约 `0.317`。因此周期图重构必须显式保存整数 image translation，不能把 fractional round 当作一般斜晶胞的精确 PBC 邻居搜索。

### 1.4 数据合同的冲突

当前仓库至少存在以下轴合同差异：

| 位置 | eDOS 轴 | phDOS 轴 |
|---|---|---|
| `docs/01_开发文档/数据加工规范DataSpec.md` | `[-6,6]/128`，盒平均 | `[-280,980]/64`，盒平均 |
| `evaluate_and_plot.py:177-180` | `[-6,6]/128` | `[-280,980]/64` |
| `cif2dos.py:19-20,76-77` | `[-10,10]/128` | `[-280,980]/64` |

这不是绘图小问题。坐标 query、积分、loss、外部模型比较和 checkpoint 都依赖同一份 `grid manifest`；在合同统一前，不应报告“任意分辨率”或物理面积守恒。

### 1.5 当前 phDOS 面积的只读审计

用现有 train npy、`[-280,980]` 端点间隔 `20 cm^-1`、`n_atoms` 由 `elements[:,2:]` 非零且去除 sentinel 计数，计算

```text
area = sum(phdos_i) * 20
ratio = area / (3 * n_atoms)
```

得到：`ratio` 中位数约 1.0，10 分位数约 0.897，90 分位数约 4.0；约 11.5% 样本大于 3，约 1% 小于 0.5。这个结果可能由 primitive/conventional cell、频率单位/强度单位、重复胞、窗口截断或旧数据加工造成，不能仅凭该统计判断是哪一种错误；但它足以否决当前直接施加 `3N` 硬投影。

`DataSpec` 已记录 v2 的单位和 canonical primitive 计划，但该规范是“待 census 完成后执行”，不能拿它替代当前 npy 的 provenance 审计。

### 3.2 几何主干的结论

当前不应追求“最强 foundation model 接入”，而应先验证下面三个可归因层次：

1. **Invariant baseline**：显式周期边、径向基、元素/质量特征、距离 cutoff、原生 scatter/index_add；用于验证数据和周期图合同。
2. **Low-order equivariant**：`e3nn 0.5.6` 上只保留 `0e + 1o` 或小规模 `2e`，最终取 `0e`；用于验证方向/角度信息是否对 DOS 有独立增益。
3. **ACE-style higher body order**：只有在前两者有稳定基线后再加，层数控制在 2–3，不同时引入 SFC、STMU 和 MoE。

## 4. 神经算子、连续谱与预训练

### 4.1 采用“coordinate decoder”，不宣称已经是 Neural Operator

推荐先实现：

\[
b = \operatorname{Branch}(h_{\mathrm{global}}),\qquad
t(x) = \operatorname{Trunk}(\operatorname{Fourier}(x)),
\]

\[
\hat y(x)=\operatorname{Softplus}\left(\langle b,t(x)\rangle+c(h_{\mathrm{global}},x)\right).
\]

其中 `x` 对 eDOS 是带单位和费米零点的能量坐标，对 phDOS 是带单位的频率坐标。固定 128/64 网格仍可作为第一阶段 query；只有在训练中引入随机 query、bin-average 或 held-out resolution 后，才可声称支持连续查询。

证据与边界：

- DeepONet、FNO、Geo-FNO、GINO、FEDONet、SIREN/Fourier Features 的通用函数逼近或 PDE 证据，不能直接称为 DOS 证据。
- `torch.fft` 和纯 MLP trunk 在本机可行；`neuraloperator`、`torch-harmonics`、GINO 的完整依赖不应进入主仓库。
- 1D FNO 残差可以作为后续谱轴消融，但它不自动带来 resolution invariance；FNO 仍受训练网格和数据分布约束。
- 当前 Decoder 的 `Conv1d` 头只处理 query 序列顺序，不等于 query 具备物理坐标。坐标条件化应先于 FNO。

### 4.2 谱预训练的证据层级

| 方法 | 证据 | 可做实验 |
|---|---|---|
| MatBind 式结构↔DOS contrastive | 2026 预印本直接针对结构、DOS 多模态对齐 | 若拿到合法配对谱，预训练结构分支；推理只使用结构。 |
| DOSSIER 式 cross-modal distillation | 2026 预印本使用 universal MLIP 教师蒸馏 composition encoder | 用外部 teacher 生成结构表征/不确定度对照；不要把 composition-only teacher 当几何真值。 |
| masked atom / coordinate denoising | 几何模型中有广泛先例，但没有“必然提升 DOS”的直接证据 | P2 做 CIF-only 结构预训练，对比随机初始化/冻结/全量微调。 |
| 直接 mask 目标谱 bin | 如果 Encoder 只看 CIF，则只是 loss mask，不是自监督重构 | 只有预训练 head 同时接收可见谱值与 `observed_mask` 时，才称完整谱重构；推理时必须移除谱输入。 |

## 5. 物理守恒合同

### 5.1 phDOS：`3N` 是条件成立的物理规则，不是无条件的网络后处理

Phonopy 官方文档写明：在完整频率范围、给定 unit cell 口径下，phDOS 积分为 `3N_a` states；Materials Project 文档使用归一化后的 `g(ω)`，积分为 1，再在热力学公式外乘 `3nN`。

因此必须在 manifest 中同时记录：

- primitive 或 conventional cell；
- `N_atom` 的定义；
- raw DOS / probability DOS；
- 横轴单位（THz 或 `cm^-1`）；
- 是否为盒平均、点采样或 smearing；
- 频率窗口是否截断；
- 负频/imaginary mode 如何处理。

只有当目标为 raw DOS 且窗口覆盖全谱，或已标注“窗口内面积”时，才可使用对应面积约束。负频不能被静默删掉：它是稳定性信号；热力学积分对虚频的处理应与谱预测目标分离。

### 5.2 eDOS：有限窗口不能使用 `N_val` 硬约束

VASP 官方 DOSCAR：DOS 单位为 states/eV，integrated DOS 为 states；`NELECT` 默认由 POTCAR 的 `ZVAL` 与 POSCAR 原子数确定。它是全计算窗口/全电子占据语义，不是任意 `[-6,6] eV` 窗口的 DOS 面积。

因此 eDOS 处理采用：

- 坐标条件形状 + 直接 scale loss，或
- 在**同一窗口和同一 bin 语义**下预测窗口面积，作为独立监督；
- 禁止把元素周期表上估计的 `N_val` 当成所有数据源、伪势、磁性和 charge state 的统一真值。

### 5.3 推荐的守恒实现

第一版不做硬投影，而是输出并评估：

```text
shape: non-negative spectrum on the declared grid
area_pred: quadrature(shape, declared bin edges)
area_target: quadrature(target, same bin edges)
area_error: relative error and absolute error
```

当 `area_target` 经 provenance 审计后稳定，再分别启用：

- phDOS：`shape / area(shape) * area_target`；若 area target 明确是 `3N`，才把 `area_target=3N`。
- eDOS：使用窗口面积 target，不使用 `N_val` 代替。

## 6. 推荐的 Encoder v2 规格

### 6.1 P0 输入与几何预处理

```text
CIF
  -> canonical cell / atom order / occupancy audit
  -> exact periodic neighbor enumeration
       edge = (center, neighbor, integer image T, r = frac_j - frac_i + T)
  -> smooth radial basis + cutoff mask
  -> node/edge local encoder
```

约束：

- 计算距离必须使用 Cartesian `r`，不能将 fractional 坐标直接当欧氏坐标。
- 斜晶胞使用 image enumeration / robust nearest-image search；不使用逐分量 `round` 作为通用最短镜像算法。
- 小单胞重复镜像保留为多重边，不压成一条 `L×L` 距离。
- P0 cutoff 先锁 5.5 Å 或 6.0 Å，但只能有一个 manifest 值；平滑 cutoff 在半径端为 0。
- 记录 `T`，为周期重标定、图片重编号和晶胞基变换单测提供依据。

### 6.2 节点、晶格和局部主干

建议第一版：

| 部件 | P0 规格 |
|---|---|
| 元素 | learned embedding 作为残差，不让稀有元素 embedding 单独决定输出；保留质量、原子半径、电负性等确定性特征并经过 MLP。 |
| 晶格 | 体积/每原子体积、`G=A^T A` 的独立分量、密度/质量密度等 scalar token；不把 `1/c` 存储 hack 当作模型语义。 |
| 局部特征 | radial basis + scalar angle information，先跑 invariant baseline。 |
| 等变消融 | `e3nn 0.5.6` 小规模 `0e+1o`，必要时加少量 `2e`；输出前 invariantize 到 `0e`。 |
| 层数 | 2–3 层，禁止第一版同时追深度、高 `lmax`、STMU 和 MoE。 |
| 输出 | `atom_proj -> [B,L,512]`，masked pool/global token -> `[B,512]`，旧 Decoder 合同不变。 |

### 6.3 坐标条件 Decoder

固定网格阶段也显式传入：

```text
edos_x = declared eV bin centers or edges, centered at EF
phdos_x = declared cm^-1 bin centers or edges, zero at nu=0
task_id = {edos, phdos}
```

建议：

- Fourier feature 32–64 个频率起步；eDOS/phDOS 分开频率尺度；
- `branch(h_global)` 与 `trunk(x,task_id)` 做 dot/bilinear；
- 保留 cross-attention memory 的消融，以判断 coordinate trunk 是否真的优于现有 Query；
- 预测 box average 时在 bin 内采样或使用边界积分，而不是把标签无条件视为 center point value；
- 连续 query 的外推必须限制在训练坐标域内，报告 held-out grid，不报告无证据的“零样本超分辨率”。

## 7. 分阶段实验路线与验收门槛

### Gate 0：数据合同，不改模型

必须新增或生成一个版本化 manifest，至少包含：

```text
source_id, split, cell_convention, n_atom, axis_unit,
bin_edges, bin_semantics, dos_unit, spin_policy,
negative_frequency_policy, area_target, provenance
```

验收：

1. 对同一原始谱，THz → `cm^-1` 的横轴和强度转换保持面积一致。
2. primitive/conventional cell 变换的 `N_atom`、DOS 面积和谱曲线关系可回放。
3. `[-6,6]` 与 `[-10,10]` 只作为不同 grid manifest，不能混称同一 eDOS 任务。
4. 明确当前 npy 中 ratio≈1/4/8 的来源；在此之前禁止 phDOS `3N` hard projection。

### Gate 1：冻结并复现基线

对 M3/M4 重新跑同一数据和同一 split，双报：

- oracle 与 blind；
- median/mean `R²`、失败率、MAE；
- area error、negative-frequency mass、bandgap F1、`Cv(300K)` 和平均频率误差；
- 按晶系、原子数、元素是否训练集出现、成分是否重叠、峰均比/带隙分层。

若不能复现，停止架构实验，先修评估合同。

### Gate 2：只改变 query

固定 Encoder，按以下顺序做成同一 pilot：

| 实验 | 改动 |
|---|---|
| Q0 | 现有静态 query |
| Q1 | 真实坐标 query + 普通 MLP trunk |
| Q2 | 真实坐标 query + Fourier trunk |
| Q3 | Q2 + branch/trunk bilinear，去掉谱轴 Conv head |

验收不是看单一总 MAE，而是 Q2/Q3 是否同时改善尖峰、bandgap/低频声学区、held-out query 点和 blind/oracle gap。

### Gate 3：只改变几何

固定 Q2，比较：

1. 当前 dense RP；
2. 精确周期稀疏 invariant graph；
3. 低阶 `e3nn` equivariant graph；
4. ACE-style body-order 消融。

所有版本做旋转、平移、原子置换、image 重编号、等价晶胞基变换测试。对于标量 DOS，变换前后输出误差必须作为硬回归测试，而不是只看训练 loss。

### Gate 4：损失与物理指标

顺序固定为：

1. Smooth-L1 + non-negative output；
2. 频谱一阶差分/局部峰加权；
3. 在合同修复后做 `SumNorm + KL`；
4. 再做 Wasserstein/CDF 消融；
5. 最后才做面积投影。

`TV loss` 不能被描述为“锐化定理”；它只是一个需要实测的差分损失。对尖峰应同时报告峰位误差、峰高误差和积分误差，防止总 MAE 掩盖物理失败。

### Gate 5：数据效率与外部 teacher

先使用本地合法单标签数据做：

- eDOS-only batch：共享 Encoder + eDOS query loss；
- phDOS-only batch：共享 Encoder + phDOS query loss；
- 双标签 batch：联合 loss；
- 任务缺失使用显式 mask，不填 0。

外部 teacher 顺序：

1. 隔离跑 PET-MAD-DOS 单 CIF eDOS smoke test，记录真实版本、轴、单位和模型卡 license；
2. 再评估 MatterSim/SevenNet 的 atom representation 是否能导出稳定的结构 embedding；
3. 只做 frozen teacher / shallow adapter / distillation 三个受控实验，不把 teacher 输出伪装成 DFT label。

### Gate 6：高风险研究线

只有 Gate 0–5 通过后，才考虑：

- MANDALA-style Hamiltonian auxiliary；
- 结构↔DOS contrastive pretraining；
- 低秩谱 covariance/UQ；
- 1D FNO residual；
- 晶体级 MMoE。

完整 Hamiltonian、流匹配逆向生成、CUDA streaming backend、全局 NUFFT torus operator 不进入当前 Encoder v2 主线。

## 8. 评估与停止规则

### 8.1 必报指标

| 类别 | 指标 |
|---|---|
| 谱逐点 | MAE、Huber、`R²` median/mean、失败率 |
| 谱结构 | 一阶差分误差、峰位/峰高误差、bandgap F1、低频/高频 tail MAE |
| 物理量 | phDOS 面积相对误差、平均频率、`Cv(T)`、Debye/热导派生量误差 |
| 盲推理 | blind 与 oracle 的差值；严禁只报 oracle |
| 不确定性 | 按元素长尾、晶系、原子数、成分重叠分层的 calibration/OOD failure |
| 工程 | 参数量、峰值显存、每 batch 时间、周期图边数、attention/RP 中间量大小 |

### 8.2 不接受的结果解释

- 只用 `R²` 提升证明模型学到了物理；
- 只在 oracle 逆归一化下证明 scale head 有效；
- 把固定网格插值称为连续算子；
- 把 `2 层 triangle update` 称为已经完备编码二面角；
- 把 `3N` 归一化后的面积误差写成 0%，忽略窗口截断、离散求积和 cell 口径；
- 把 MLIP 的能量/力 embedding 直接称为 DOS representation；
- 把外部模型论文的 benchmark 数字迁移成 uniARPAT 的预期收益。

## 11. 复核结语

本轮调研的新增价值不在于再列一批模型，而在于把外部证据映射回当前代码：

- 2026 的谱工作支持“坐标条件 query”和“结构↔谱对齐”，但没有证明必须引入完整 Neural Operator；
- 2026 的 operator 工作支持“先预测电子结构对象再导出观测量”，但当前数据没有 Hamiltonian/overlap 标签；
- 2025–2026 的 foundation models 说明预训练表征有价值，但环境、权重约定、DFT 标尺和 license 都不能忽略；
- 当前最优先的提升点仍是数据合同、精确周期几何和静态 query，而不是架构名词数量。

**最终施工建议**：先完成 Gate 0/1，再只做 Q0–Q3 和 invariant/sparse geometry 两组可归因实验。任何新模块若不能在这两组实验中证明独立增益，就不进入 Encoder v2 主干。
