# 设计：仅更新 G2 消息分支的固定小样本拟合

## 授权与待排除解释

- 马尚酱在上一轮提出“只开放G2消息分支更新”后回复“好”，授权本轮单个实验臂。
- 已有同一16对train材料的结果：冻结encoder末步8／16通过，联合encoder／读出第700步
  首次16／16通过。尚不知道成功是否需要更新普通注意力、相对位置投影、前馈或归一化权重。
- 本轮保持读出训练，只允许encoder内的6个G2消息模块更新，检验这组更新是否足以获得
  全部16对的拟合见证。唯一新增因素是从全encoder更新收窄到G2参数更新。
- 若通过，可以排除“拟合这批材料必须更新其余encoder权重”；不能推出G2的必要性、
  哪一层丢失信息，或全任务泛化收益。若未通过，只说明此限制在指定优化预算内未成功。

## 固定数据、初值与训练合同

- 复用`output/g2_small_fit_q1/train_cache.pt`中的32材料输入、目标和原始memory；核对
  上轮记录的SHA256。复用同一selection并按原选样算法复核，不重新选择或替换材料。
  不加载valid／test数据或混合特征缓存。原数据仅做字节哈希保护，不再提取特征。
- 从原`output/ablation_m1_g2edge/checkpoint_latest.pth`的M1／G2 ep10、seed42初始化，
  不接用小样本联合臂的已训练权重。FP32、eval模式、关闭dropout。
- 调用链仍为固定atom_src → 原encoder层与G2残差 → 原eDOS读出；仅
  `encoder.g2_msgs.*`的W_v、W_g、W_o、alpha以及原读出参数可更新，H1冻结。
  普通encoder层权重冻结，但保留反向传播：后层需要把梯度传到早期G2。
- 冻结注意力权重不等于冻结注意力分数。更新G2会改变后层输入及注意力激活；本实验只
  缩小必要的参数更新范围，不声称排除注意力通路。
- 同一完整16对batch、2000步，原谱差目标
  `mean((128*((p_a-p_b)-(q_a-q_b)))**2)`，不增加单谱锚定。
- 读出和可训练encoder参数分别AdamW：lr5e-5、betas(0.9,0.99)、weight_decay0.01，
  各自梯度裁剪1.0。缩小encoder更新集合会相应改变其裁剪范数，读出裁剪范围保持一致。
  步数与数据暴露相同，不声称与全encoder臂等算力。

## 运行前检查与门槛

- 重算初始预测与缓存的最大TV≤1e-5；blind尺度最大相对误差≤1e-5；读出梯度相对RMS≤1e-3、
  损失相对误差≤1e-5。沿用上轮同一目标的独立logits正对照结果，不重复该优化。
- 在实际完整batch上反向一次但不更新：逐层检查6个G2模块都收到有限非零梯度，其余encoder
  和H1无梯度；清除梯度后再开始2000步。测试另用两层实际encoder核查跨冻结层传播。
- 沿用逐对门槛：残余MSE≤零谱差MSE的1%，残余TV≤目标TV的10%，全部16对同时通过。
  零目标差以MSE≤1e-12、TV≤1e-6处理。第0步及每100步记录一次；保存首次全部通过的
  权重并继续满2000步，报告完整轨迹及末步是否保持，不按验证集选权重。
- 对最终及首次通过checkpoint重新加载、重算逐对结果；检查G2／读出确有更新，其余
  encoder状态及H1逐值不变。补充32材料的oracle／blind中位R²与失败率，blind尺度重算。

## 产物、复用与结果解释

- 复用`g2_small_fit_probe.fit_arm`，增加向后兼容的`g2_only`更新范围；旧两臂入口和目标
  不变。上轮执行脚本保留在其output快照，旧设计、结果、缓存与权重不覆盖；本轮分别登记
  旧执行快照和新公共helper的哈希，避免把新代码冒充旧运行来源。
- 新入口`tools/eval/g2_value_fit_probe.py`，新标签`g2_value_fit_q1`，setsid + nohup运行，
  拒绝覆盖。output保存配置、执行快照、首次／最终权重和预测；results保存逐对轨迹、
  样本指标、summary、JSON结论和重载检查。对照数据从上轮正式CSV复制并登记来源哈希。
- 若通过，下一步建议进一步限制G2的深度范围，以判断早层消息适配是否必需；若未通过，
  根据逐对残留确定尚未恢复哪些对，再提出一个扩大更新范围的对照。均需先记录本轮结论，
  本轮不自动启动新臂、扫描超参数或全体pilot。
- 全部结论限于一次抽样、一个初值与纯谱差训练。共有谱形可漂移，未评估phDOS；不能将
  小样本可拟合性直接晋级为准确率改进或变更默认B7模型。
