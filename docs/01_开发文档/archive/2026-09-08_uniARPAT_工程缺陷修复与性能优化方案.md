### 0.2 数据契约基线（所有修复的公共前提，必须先理解）

|---|---|---|---|
| `elements` | `(N, 82)` int | `inp` → `[B, 82]` long | `[:,0]=126` 恒定哨兵，`[:,1]=127` 恒定哨兵，`[:,2:]=Z` 原子序数（`0=pad`，实测最大 93），`N=(elements[:,2:]!=0).sum()` 平均 12.26、中位 8、范围 1~80 |

| `atom_idx` | — | `[B, 80]` long | `src[:,2:]` |
| `memory` | — | `[B, 80, 512]` | Encoder 输出，`d_model=512, nhead=8, d_head=64` |
| `edos` / `phdos` | `(N,128)/(N,64)` | `[B,128]/[B,64]` | eDOS 网格 `linspace(-10,10,128)`，Fermi 在 cols 63,64；phDOS 网格 `linspace(-280,980,64)`，`d_freq=20.0` |
| `edos_query/phdos_query` | — | `[B,128,512]/[B,64,512]` | Decoder queries |

错误布局示意（FIX-P0-01 的根因）：

```text
Lp=82:  [ s0 | s1 | a0 a1 ... a77 a78 a79 ]   s=哨兵(126/127), a=原子(80个)
mask:    [ F    F    m0 m1 ... m77 m78 m79 ]   F=False(valid), m=True/False
错误 mask_atom=mask[:,:80] = [F,F,m0..m77]  → 对齐到 memory[a0..a79]，头部侥幸同valid，尾部丢 m78,m79
正确 mask_atom=mask[:,2:]  = [m0..m79]       → 与 memory 严格对齐
```

### FIX-P0-01 Padding mask 错位 2 列（最高优先级，所有池化/计数/注意力全错）

- **严重度**：P0（对应《审查报告 §2.2》）
- **待改文件**：
  1. `model/transformer.py:124-126`（`mask_atom` 切片）
  2. `model/model.py:196-197`（`valid_atoms` 计数）
  3. `model/heads.py:133-143`（`global_masked_pool` 调用点在 `model/transformer.py:209`，本身逻辑正确，但需确认传入的已是修复后 mask；若有其它直接传 `mask[:,:atom_len]` 的地方一并改）
- **Shape 契约**：`mask[B,82] → mask_atom[B,80]`，`memory[B,80,512]`，`valid_atoms[B]`。修复后 `N=1` 样本 `valid_atoms==1`（修复前为 3）。
- **危害定量**：`N` 中位数 8 时 `valid_atoms` 多算 2（`2+8→10`，`3N` 求和目标抬高 25~33%）；尾部原子 78,79 恒当有效；`global_masked_pool` 分母偏大稀释晶体向量。

### FIX-P0-03 Encoder 自注意力“算两遍 + 真正分支漏 mask”（合并修复）

- **严重度**：P0（对应《审查报告 §1.1 + §1.3》，同一函数，必须一次改完）
- **待改文件**：`model/transformer.py:283-356`（`TransformerEncoderLayer` 整体，重点 `:321-341`）
- **Shape 契约**：`src[q/k/v; B,80,512]` → 按头切分 `[B*h=8B,80,64]` → `base_scores[B*h,80,80]`，`rp_scores[B*h,80,80]`，`total[B*h,80,80]` → `softmax(dim=-1)` → `attn_out[B,80,512]`。`src_key_padding_mask[B,80]` 需广播为 `[B*h,80,80]` 后对 `total` 做 `-inf` 填充。
- **危害**：每层每步浪费一次完整 `nn.MultiheadAttention`（`3·512²` 投影 + `B·h·L²` 注意力）；且被丢弃分支带的 mask 语义丢失，真实分支 `softmax` 对 pad 全开，短晶体（中位 N=8，pad 72 列）`memory` 被稀释 90%。

**Before（`model/transformer.py:319-346`）**：

```python
B, L, _ = src.size()
q, k, v = src, src, src
attn_output, attn_weights = self.self_attn(q, k, v, attn_mask=src_mask, key_padding_mask=src_key_padding_mask)
rp_emb = self.rp_encoder(rel_diss, rel_dirs)
rp_emb = self.rp_proj(rp_emb)  # [B, L, L, d_model]
...
total_scores = base_scores + rp_scores
attn_weights_new = F.softmax(total_scores, dim=-1)
v_heads = v.view(B, L, self.nhead, d_model_head).permute(0, 2, 1, 3).reshape(B * self.nhead, L, d_model_head)
attn_output_new = torch.bmm(attn_weights_new, v_heads)
```

**After（方案 A：删除重复 MHA + 补 mask，推荐；保持手工几何偏置分支）**：

```python
B, L, _ = src.size()
q, k, v = src, src, src
# FIX-P0-03: 删除被丢弃的 self.self_attn 首算（省 QKV+输出投影与 [B*h,L,L] 中间量）；
# 真正生效的是下面的手工 base_scores + rp_scores 分支，mask 必须加在这里。
# 注意 self.self_attn 模块定义保留与否见 FIX-P1-01（删死投影时一并评估是否删除该子模块）。
rp_emb = self.rp_encoder(rel_diss, rel_dirs)
rp_emb = self.rp_proj(rp_emb)  # [B, L, L, d_model]
d_model_head = self.dim // self.nhead
rp_emb = rp_emb.view(B, L, L, self.nhead, d_model_head)
q_heads = q.view(B, L, self.nhead, d_model_head)
rp_scores = (q_heads.unsqueeze(2) * rp_emb).sum(-1)
rp_scores = rp_scores.permute(0, 3, 1, 2).reshape(B * self.nhead, L, L)

q_scaled = q / (d_model_head ** 0.5)
q_heads2 = q_scaled.view(B, L, self.nhead, d_model_head).permute(0, 2, 1, 3).reshape(B * self.nhead, L, d_model_head)
k_heads = k.view(B, L, self.nhead, d_model_head).permute(0, 2, 1, 3).reshape(B * self.nhead, L, d_model_head)
base_scores = torch.bmm(q_heads2, k_heads.transpose(1, 2))

# 新的总打分
total_scores = base_scores + rp_scores
# FIX-P0-03: 补 key_padding_mask（pad 列填 -inf，softmax 后权重为 0）
if src_key_padding_mask is not None:
    # src_key_padding_mask: [B, L] True=pad → [B*h, L, L]（mask key 维）
    mask_exp = src_key_padding_mask.view(B, 1, 1, L).expand(B, self.nhead, L, L).reshape(B * self.nhead, L, L)
    total_scores = total_scores.masked_fill(mask_exp, float("-inf"))
# 计算新的注意力权重并输出
attn_weights_new = F.softmax(total_scores, dim=-1)
attn_weights_new = attn_weights_new.masked_fill(torch.isnan(attn_weights_new), 0.0)

# 重新计算注意力输出
v_heads = v.view(B, L, self.nhead, d_model_head).permute(0, 2, 1, 3).reshape(B * self.nhead, L, d_model_head)
attn_output_new = torch.bmm(attn_weights_new, v_heads)
```

> 备选方案 B（重构为 `F.scaled_dot_product_attention(rp_scores作attn_mask)`）性能更优但改动大，列为 P1 后续优化，本次 P0 只做方案 A。若未来做 B，需保证 `attn_mask[B*h,L,L]` 与 `is_causal=False` 语义一致并重跑本节测试。

```python
def compute_shape_loss(pred_shape, tgt_shape):
    pred_mean = torch.mean(pred_shape, dim=-1, keepdim=True)
    tgt_mean = torch.mean(tgt_shape, dim=-1, keepdim=True)
    pred_diff, tgt_diff = pred_shape - pred_mean, tgt_shape - tgt_mean
    var_tgt = torch.mean(tgt_diff ** 2, dim=-1)  # [B]
    cov = torch.sum(pred_diff * tgt_diff, dim=-1)
    std_p = torch.sqrt(torch.sum(pred_diff ** 2, dim=-1) + 1e-6)
    std_t = torch.sqrt(torch.sum(tgt_diff ** 2, dim=-1) + 1e-6)
    std_p = std_p.clamp(min=1e-3); std_t = std_t.clamp(min=1e-3)  # 稳健化
    r = cov / (std_p * std_t)
    loss_mse = torch.mean((pred_shape - tgt_shape) ** 2, dim=-1)
    base = (1.0 - r) + 0.5 * loss_mse  # 单分支
    w_flat = torch.sigmoid((1e-4 - var_tgt) * 1e4)  # 平坦渐变而非硬 where
    loss_sample = w_flat * loss_mse + (1 - w_flat) * base
    return loss_sample.mean()
```
