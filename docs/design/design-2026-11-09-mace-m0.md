# 方案：2026-11-09 — MACE 收益归因 M0（仅元素先验）

## 问题

[M1](../logs/log-2026-11-09-mace-features-run.md) 在 h2 上加 MACE 每原子冻结特征后，联合 valid E 改善 0.0080（“有效”），收益主要在 eDOS。
这些特征同时包含两类信息：

- **元素化学知识**：同一元素在所有材料中共有的部分（哪些元素相近、某元素典型的成键环境）。
- **局部环境**：同一元素在不同材料中随周围原子而变化的部分。

两者对后续路线的含义不同：前者只需更好的元素嵌入，自研结构预训练动机弱；后者才支持深挖预训练表示与自研结构预训练。
M0 把每个原子的特征换成**该元素在 train 原子上的平均 MACE 特征**，保留元素知识、去掉环境信息，以此归因。

## 特征

- `tools/data/build_element_mean_features.py` 从 M1 特征（`data/external/mace_mp0b3_medium_v1`）生成
  `data/external/mace_mp0b3_medium_elemmean_v1`（本地），格式与 M1 相同（`external-atom-features-v1`），manifest 记录来源指纹。
- 每元素均值只用 train 原子；train 未出现的元素用 train 全体原子均值（标准化后为 0）。train 有 85 种元素，valid 中无未见元素，test 中有 1 个原子。
- 标准化用新数组的 train 均值与标准差。元素身份可解释 MACE 原始特征约 75% 的方差（各通道合计），即 M1 特征中约四分之一的方差来自环境。

## 臂与对照

| 臂 | 内容 | 对照 |
|---|---|---|
| m0_s42 | h2 ＋ MACE 元素均值特征 | h2_s42（best ep24）、M1（m1_s42，best ep31） |

除特征目录外，注入方式（零初始化 `Linear_256→512` 加到 `atom_src`）、配方、seed、初值、数据顺序、35 轮、选点与保护线均与 M1 相同；无模型代码改动。

## 判读（事先固定）

主判读看 d0 = M0 − h2 的联合 valid blind mean E（门槛同 M1）：

- **元素主导**：d0 < −0.004（M0 本身有效）；
- **部分**：−0.004 ≤ d0 < −0.0013（两者各占一部分）；
- **环境主导**：−0.0013 ≤ d0 ≤ +0.004（M0 与 h2 分不开）；
- **更差**：d0 > +0.004 或 phDOS d0 > +0.0099，或无合格轮次。

M1 联合收益只有约 6 倍极差，联合口径的分辨力有限；eDOS 收益约 21 倍本任务极差，分辨力更强，因此另报事先固定的 **eDOS 读数**
（材料配对 95% 区间）：M0−h2 不含 0 且 M0−M1 含 0 → 元素；反之 → 环境；都不含 0 → 部分；都含 0 → 未分辨。
另报占 M1 收益的比例、同组成材料谱差技能、train/valid 比（只作诊断）。

结论：
- 元素主导 → MACE 主要提供元素先验；自研结构预训练动机弱，可比较廉价元素描述符，主线转向数据。
- 部分 → 两者都有贡献；结构预训练仍是候选，预期收益相应减小。
- 环境主导 → 收益依赖每原子环境信息；深挖预训练表示（更多通道、更大模型、微调）并设计自研结构预训练。
- 更差 → 检查特征尺度或注入方式，不自动调参。

## 成本与执行

- 训练约 4.5 GPU 小时（同 M1），交执行会话按 [AGENTS.md](../../AGENTS.md) 运行与监控；判读回主会话。
