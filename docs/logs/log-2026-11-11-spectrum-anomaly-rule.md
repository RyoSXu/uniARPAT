# 异常谱筛除规则（2026-11-11；用户已批准，经评审会话转达："全部按建议"）

[标签契约 v2](../design/design-2026-11-11-label-contract-v2.md) 第 2 步（重写导出）的补充。起因是[eDOS 标签质量测量](log-2026-11-11-edos-label-quality.md)里极端的 Static 配对：
评审会话发现，其中一些是规范谱本身数值异常（窗口内每原子约 167 个态）。
本页只是提案，用户确认后才写入导出契约。阈值只看 train 定，没有用 valid 或 test；旧 test 的谱一条都没读。

## 做法

- 脚本 `tools/data/spectral_store/measure_spectrum_anomalies.py`（只读，`nice 19`，3 进程）。
  产物 `results/runs/spectrum_anomaly_20261111/{edos,phdos}_features.parquet`，本地，不进 Git。
- 覆盖范围：库内全部非旧 test 材料的 eDOS 任务 508,135 条（含找回的旧标签任务），以及 phDOS 31,318 条（MP、PhononDB、JARVIS）。
- 每条谱计算物理量纲的检查量：
  - eDOS：W = [−6, 6] eV 窗口内的态数 ÷ 计算晶胞的价电子数（价电子数按 MP 赝势的 ZVAL 计）；
  - eDOS：占据态总数 ÷ 价电子数；
  - phDOS：每原子总模式数，应为 3；
  - 两者都算每条谱对 C 的贡献 Σ(DOS/N)²·Δx。

## eDOS：提议规则 W > 3 判为异常并剔除

- **物理依据**：
  - 窗口下半部是占据态，最多容纳全部价电子（贡献 ≤ 1）。
  - 窗口上半部是费米能级以上 6 eV 内的空态，实际不超过同一量级。
  - 所以 W 正常应在 2 左右以内。W 远大于 2，说明态密度的数值尺度本身错了。
- **train 上的分布**（旧 train 材料的规范谱 17,483 条）：
  - 中位 0.81，P99.99 为 2.12。
  - 第 2 大值也只有 2.12，最大值是一条孤立的 9.36。
  - 阈值取 2.5、3 或 4，train 规范谱里都只剔除这一条，所以结论对阈值不敏感。取 3，留出约 40% 的余量。
- **能抓到的异常**：
  - 评审指出的规范谱（窗口内每原子 166.7 个态）W = 13.9。
  - 差异最大的几对 Static：W 为 12–52；最大那一对的 Static 谱峰值达 3,568 态/eV/原子，属数值爆炸。
- **不会误伤的情况**：
  - 含 f 电子元素的材料谱峰高，对 C 贡献大，但 W 正常（中位约 1.0）。
  - train 规范谱中对 C 贡献最大的前 1%，79% 是这类正常谱，规则不碰它们。
- 被剔除的条数（W > 3；括号内为 W > 2.5 / W > 4）：

| 来源 | train（旧） | valid（旧） | 新材料 |
|---|---:|---:|---:|
| 规范谱 | 1（1 / 1） | 0 | 15（60 / 6） |
| 找回的旧标签任务（edos_legacy） | 7 | 0 | — |
| 其他 NSCF Uniform | 1 | 0 | 0（12 / 0） |
| GGA Static | 4 | 3 | 339（800 / 90） |
| GGA+U Static | 0 | 0 | 4（13 / 3） |
| HSE06 / PBEsol / r2SCAN Static | 0 | 0 | 0 |

  旧 test 不计数（不读其谱）。旧标签的 train 材料最多 8 条受影响，valid 0 条。导出时，被剔除的旧标签条目同"找不回"的一样剔除，并报数量。
- **C 的变化**（v2，128 格，在旧 train 规范谱上拟合）：11.971 → 10.450（−12.7%），全部来自那一条 W = 9.36 的谱。
  该谱对 C 的贡献项为 26,609，其余谱的中位是 7.3。256 格的 C 在第 2 步正式导出时一并重拟。
- **为什么不用占据态数作规则**：
  - 它在规范谱中位上是 1.00，但两侧尾部都宽：P1 为 0.63，P99 为 2.69。
  - 原因可能是 DOS 能量范围没覆盖深层半芯态，以及 ZVAL 与实际赝势不一致。
  - 正常与异常分不开，只作诊断。

## phDOS：建议第一轮不筛除，只加标记列

- 声子谱没有数值爆炸：每条谱对 C 的贡献最大约为中位的 10 倍（0.40 对 0.04）。
- 每原子模式数偏离 3 的谱约占 1%。分布连续，没有自然断点，阈值只能人为指定。
- 按 [2, 4] 筛除时的条数：
  - MP：train 111/14,954，valid 16/1,848，新材料 116/6,838；
  - PhononDB：对应旧 train 标签 15/1,894，对应旧 valid 1/243。
- 按 [2, 4] 筛除，C 只从 0.04523 变到 0.04541；按 [2.5, 3.5] 筛除也只到 0.04542。即筛不筛对 C 几乎无影响。
- JARVIS 的原始强度没有归一化，旧流程按 3N 重新缩放，所以无法用面积检查，只能看谱形。

## 局限

- W 依赖按 ZVAL 估算的价电子数；有一些任务用的赝势与 ZVAL 表不同，会带来约 10–20% 的偏差，对阈值 3 没有影响。
- 只针对数值尺度异常。两次计算处于不同磁态等"物理上不同"的情况（重复计算中约 4%）不属于本规则。
