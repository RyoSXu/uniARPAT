# 补充 eDOS 标签核验：零点、网格还是计算质量（2026-11-10）

只读核验，回答：Static 类 eDOS 与规范 NSCF Uniform 谱差异大（[建库记录](log-2026-11-10-spectral-store-build.md)“补充规则验证”），
主要是能量零点没对齐，还是计算本身不同。不训练、不改库、不生成训练视图。

## 一、事先写定的判据（看任何 E 结果之前写下）

### 动手前已知的事实（只看了元数据和 300 对抽样的原始网格，未计算任何 E）

- Static 任务的 DOS 只有 **301 个能量点**，跨约 −50～+20 eV，点距约 0.1–0.4 eV；规范 NSCF Uniform 有 2001 点，点距约 0.02–0.06 eV。
- 项目 E0 网格箱宽 12/128 = 0.094 eV。项目分箱规则 `box_average` 不插值：箱内无点记 0，单点取该点值。
  300 对抽样中，GGA Static 平均每条有约 56/128 个箱是空的（值为 0），规范谱和另一条 NSCF Uniform 为 0。
- 因此除“零点”和“计算质量”外，加入第三个待检假设：**网格/分箱伪差**——Static 谱本身可能没问题，只是项目分箱规则不适合稀疏网格。

### 假设与对应量

| 记号 | 补充谱分箱 | 平移 | 用途 |
|---|---|---|---|
| M0 | 项目 `box_average` | 无 | 复现已有检查（应得 GGA Static ≈0.499、GGA+U Static ≈0.339、对照 ≈0.106） |
| M1 | `box_average` | 最优平移（用规范谱搜索） | 零点假设的上限（任务第 2 步原样） |
| M2 | 分段线性积分分箱（下称“插值分箱”） | 无 | 网格假设；可部署（不用规范谱） |
| M3 | 插值分箱 | 最优平移 | 零点＋网格合起来的上限 |
| M4 | 插值分箱 | 绝对能量对齐（平移量 = 补充 E_F − 规范 E_F） | 诊断：两次计算的本征值是否在同一绝对能标上 |
| R | 规范谱粗化到 Static 自己的能量点后插值分箱 | M3 的平移 | 诊断：分辨率本身的损失（R_floor）与超出分辨率的差异（R_resid） |
| Z | 插值分箱 | 只用补充谱自身信息的重新定零点规则 | 可部署规则（第 4 步，仅在零点有显著作用时做） |

- 规范标签始终是项目口径：规范谱 `box_average` 到 E0，不改。
- E 与已有检查同式：0.09375 × Σ(a/n_a − b/n_b)² / 5.5427，n 为各自计算晶胞原子数；TV 为截负、归一后谱形的总变差距离。
- 插值分箱：把补充谱原始点连成分段线性函数，对每个箱精确积分再除以箱宽；超出原始能量范围的部分记 0。
- 平移搜索：±4 eV，先 0.02 eV 步长粗搜，再在最优点 ±0.02 eV 内 0.002 eV 细搜，目标为 E 最小；最终值用精确分箱重算。
- 对照组（另一条 GGA NSCF Uniform）做完全相同的处理，其 M0→M1、M2→M3 的降幅作为“平移搜索凭空能降多少”的估计。

### 判读规则（组中位数，GGA Static 与 GGA+U Static 分别判）

阈值以对照 ≈0.106 和模型 valid 误差 ≈0.33 为锚：**≤0.15 视为接近对照水平；≥0.30 视为计算质量级差异**。

1. **零点为主**：M1 ≤ 0.15，且 Static 的平移降幅（M0−M1）大于对照降幅的 3 倍。
2. **网格/分箱为主**：M2 ≤ 0.15。
3. 两者单独都不达标、但 M3 ≤ 0.15：**零点与网格共同造成**；按 (M0−M1) 与 (M0−M2) 占 (M0−M3) 的比例分配。
4. **计算质量为主**：M3 ≥ 0.30（两项都修正后仍差）。
5. M3 在 0.15–0.30：**部分解释**，报告分组结果。
6. **金属/有带隙**：若平移带来的额外降幅（M2−M3）和 |最优平移| 主要集中在有带隙材料（有带隙组的 |平移| 中位 ≥ 金属组 2 倍且 ≥0.1 eV），支持零点解释；否则不支持。
   - 分组依据**规范谱自身**判断带隙（库里没有带隙元数据）：费米面两侧占据点（每原子态密度 >0.01 /eV）之间最大空隙，若该空隙与 [−0.3, 0.3] eV 相交，取其宽度为带隙；<0.15 eV 为金属，0.15–0.5 eV 为小带隙，≥0.5 eV 为有带隙。
   - 可部署规则只能用补充谱自身的带隙判断，同法，但金属阈值取 max(0.3 eV, 2.5 × 局部点距)；报告它与规范分类的一致率。

### 可用性规则（第 4 步与结论用）

- 只有不需要规范谱的规则（M2 或 Z）才算“可部署”。
- 按部署时能识别的子组（泛函 GGA/GGA+U × 补充谱自身判断的金属/有带隙）判：组中位 E **≤0.15 为可用**；0.15–0.30 为边缘（介于重复计算噪声与模型误差之间，是否使用由用户决定）；>0.30 为不可用。另报告 P90 与对照的 P90。
- 若需拟合零点规则的常数，按材料随机分两半（种子 20261110）：A 半拟合，只在 B 半报告。
- 新增材料数按建库的可用口径（当前 MP、未弃用、BY-C、结构标准化成功、≤160 原子、不与旧 valid/test 约化组成相同、非旧集合材料）统计。

### 口径

- 材料集：与已有检查相同——有可用规范任务且有其他自有任务、不含旧 test（test_q1）的 57,848 个材料，**全量**，补充任务按现有规则 `type_then_volume` 选取。不读 sealed 表；staging 中旧 test 材料只按 `legacy_split` 过滤掉，不读其谱（与 `verify_store.py fallback` 同法：先按材料过滤再取谱）。
- 不使用任何模型，不选型。

## 二、预注册部分的结果与按原判据的判读（全量 57,848 对）

见第四节结果表。按第一节判据逐条：

- GGA Static：M1 = 0.397（>0.15，规则 1 不成立），M2 = 0.318（规则 2 不成立），M3 = 0.276（0.15–0.30）→ **规则 5：部分解释**。
- GGA+U Static：M1 = 0.277，M2 = 0.257，M3 = 0.226 → **规则 5：部分解释**。
- 规则 6（金属/带隙）：有带隙组 |最优平移| 中位 GGA Static 0.060 eV、GGA+U 0.088 eV，金属组 0.046、0.050 eV，均不到 2 倍 → **不支持零点解释**。
- **判据本身的问题（看结果后发现）**：对照组（另一条 NSCF Uniform，同为 2001 点）在插值分箱下 E 从 0.106 **升到** 0.234。
  原因经同谱检查确认（300 对抽样）：项目 `box_average` 只在箱内采样点之间做梯形积分、丢掉箱两端的残段，
  对 2001 点网格只保留真实面积的约 68%（10–90 分位 55%–80%，随点距变化）；同一条规范谱，项目分箱与精确积分之间 E 中位 0.134。
  所以 M2/M3/M4/R 比的是“精确积分”与“被系统缩小的标签”，网格假设的检验被标签规则混淆，不能按原阈值解读。

## 三、事后补充分析（看到第二节后加，非预注册；判据在运行前写下）

目的：在不受项目分箱规则影响的口径下区分“谱本身不同”与“分辨率/标签规则”，并检验一个可部署的标签仿真规则。

| 记号 | 规范侧 | 补充侧 | 性质 |
|---|---|---|---|
| L | 项目标签 vs 同谱精确积分 | — | 项目分箱规则本身的偏差 |
| N2 / N3 | 精确积分分箱 | 精确积分分箱，无平移 / 最优平移 | 中性口径：谱内容差异 |
| Rn_floor | 精确积分分箱 | 规范谱粗化到补充谱点后精确积分 | 仅分辨率造成的损失 |
| Rn_resid | 粗化规范谱 | 补充谱（N3 平移） | 超出分辨率的差异（k 点、磁态等） |
| D_or | 项目标签 | 补充谱线性插值到**规范谱的实际能量点**后用项目 `box_average` | 标签仿真上限（用了规范网格，不可部署） |
| D_hat | 项目标签 | 线性插值到估计网格后 `box_average`：点距 = κ × 补充谱能量范围 / 2000，网格从补充谱最低能量起；κ 在 A 半拟合（规范/补充能量范围比中位数） | 可部署 |

事后判据：
1. 中性口径下若 Static 的 N2 不超过对照 N2 的 1.5 倍，判为“Static 谱内容接近 NSCF 级别差异，主要差距来自分辨率与标签规则”；超过 2 倍则判为谱内容确有差异。
2. Rn_floor 中位 ≥0.15 视为 301 点网格本身已丢失足够信息，任何部署规则都难达可用水平。
3. 可用性仍用第一节规则：D_hat 对项目标签，按泛函 × 补充谱自身金属/带隙分组，B 半组中位 ≤0.15 可用、0.15–0.30 边缘、>0.30 不可用。

## 五、判读

**按预注册规则：两类 Static 都是“部分解释”（规则 5），零点解释不成立（规则 1、6 均不满足）。**
结合事后分析，结论改写为三层：

1. **能量零点不是主因（事实＋推断）。**
   - 事实：规范谱与 Static 都把零点放在价带顶附近；最优平移中位只有 0.05–0.08 eV（不到一个箱宽 0.094 eV）。
   - 事实：即使用规范谱搜索最优平移，项目口径下中位只降 0.06–0.10（到 0.40 / 0.28）。平移降幅也不集中在有带隙材料上。
   - 事实：可部署的重定零点规则都无改善。
   - 推断：约 10–19% 的材料确实有大于 0.5 eV 的错位，但最优平移与两次计算的 E_F 差不相关（r≈0–0.2）。
     这些更像“计算状态不同”（例如磁态、能带占据不同），不是零点约定不同。
2. **主因是项目分箱规则作用在 301 点的稀疏网格上（事实）。**
   - Static 每条约 60–74 个箱没有采样点，被记为 0，谱形 TV 因此高达 0.5–0.6。
   - 改为先把 Static 线性插值到与规范谱同密度的网格、再用项目规则分箱（D_hat，可部署），E 中位从 0.498 降到 0.151（GGA），从 0.339 降到 0.107（GGA+U）。
     对照组用同一转换为 0.112，即降到同类重复计算的水平附近。
3. **计算本身也有真实差异，但比此前以为的小（事实＋推断）。**
   - 两侧都精确积分时，Static 与规范谱差 0.14–0.18，对照只有 0.03，约 5–6 倍（按事后判据 1 判为谱内容确有差异）。
   - 其中分辨率本身的损失很小（0.035），主要是超出分辨率的差异（0.07–0.10）。
   - 这部分集中在自旋极化（2→2）和 E_F 差大的材料上，推断与磁态、k 点采样不同有关，未逐条确认。
   - 它在项目标签口径下被标签规则自身的噪声（L≈0.15）部分掩盖。所以 D_hat 的中位接近对照，但 P90 仍比对照重（GGA Static 0.835 vs 0.642）。

**附带发现（不在本任务范围内，但影响解读）**：项目 `box_average` 对 2001 点规范谱也只保留约 69% 的面积，比例随点距在 55%–80% 间变化。
同一条谱的项目分箱与精确积分相差 E≈0.15。对照组两次 NSCF 计算在精确积分下只差 0.029，在项目分箱下却差 0.106。
推断：此前作为“重复计算地板”的 0.0526 和对照 0.106，有相当一部分来自标签分箱规则本身，不是物理差异。
旧标签已冻结、检查点依赖它，本核验不建议也不执行任何改动。

**可用性**：按第一节规则（B 半组中位 ≤0.15）：
- 可用：GGA+U Static 全部、GGA Static 有带隙。
- 边缘：GGA Static 金属（0.157）。

注意：
- 逐材料看只有约一半达到 E≤0.15，长尾比对照重。
- 部署时没有规范谱，无法逐条筛除坏标签，只能按子组整体接受或拒绝。

## 六、其他解释核查

| 解释 | 结论 | 依据 |
|---|---|---|
| 能量网格点数与间距 | **事实，主因** | Static 全部 301 点（点距中位 0.175/0.220 eV）；规范 2001 点（0.030 eV）；空箱 60–74/128 |
| 能量零点约定 | 事实：两边一致（价带顶） | 4.2 节；重定零点无改善 |
| 展宽（smearing） | 推断：无高斯展宽痕迹 | 300 对抽样中约 97 个有带隙材料，两类谱在带隙内部均严格为 0；INCAR（ISMEAR/SIGMA）本地没有，**未核实** |
| 能量分辨率 | 事实：损失小 | 中性口径下 Rn_floor 0.035 |
| 自旋通道 | 事实：自旋极化材料差异大 | 规范多为单通道、Static 多为双通道，均按上下求和；2→2 组 D_hat 0.208（GGA）明显高于 1→2 的 0.131，对照 2→2 也达 0.257。推断为磁态差异；Static 的磁矩未读取，**未核实** |
| 每原子归一所用晶胞 | 事实：极少不同 | 计算晶胞原子数不同：GGA 19 对、GGA+U 650 对；E 已按各自晶胞归一，GGA+U 该组 M3 0.256 与总体相近 |
| k 点密度 | **未核实** | 本地无 k 点信息；“超出分辨率的差异”0.07–0.10 与之相容，但不能区分 k 点和磁态 |
| 能量窗截断 | 事实：不影响 | 两侧都覆盖 E0 窗口；规范谱能量范围约为 Static 的 1.14 倍（多算了空带） |

## 七、需要用户决定的事项

1. **是否、以及纳入哪些 Static 补充标签（仅训练用）。**
   - A. 不纳入（现状）：eDOS 新数据 37,278，新双标签 13。标签最干净；数据量最小，双标签几乎没有。
   - B. 纳入“可用”三组（GGA+U Static 全部＋GGA Static 有带隙），用 D_hat 转换：
     eDOS +46,501（到 83,779），双标签 +3,408。这批组中位误差接近重复计算水平，但约一半材料 E>0.15，长尾比对照重。
   - C. 再加边缘组（GGA Static 金属）：eDOS +64,392，双标签 +5,203。多出的 1,795 个双标签来自误差最重的一组（P90 0.96）。
   - 无论 B/C：补充标签只进训练，dev/test 仍只用规范标签；来源码须区分（已有 `mp_fallback`）。
     是否给补充标签降权由训练方案决定。验证只覆盖“有规范任务”的材料，向没有规范任务的材料（更大、更新）外推**未验证**。
2. **若选 B/C：标签转换规则。** 现有 `make_view.py` 的 `canonical_or_fallback` 直接对 Static 用项目分箱，会得到 E≈0.5 的坏标签，**不能直接用**。
   需由设计会话实现 D_hat：线性插值到点距 κ×自身能量范围/2000（κ≈1.13）的网格，再用项目 `box_average`；并补测试。这是补充来源的数据契约变更。
3. **（独立事项，可延后）项目分箱规则本身的偏差。**
   - 维持现状：与冻结标签和已有检查点兼容。
   - 新库改用精确积分分箱：标签噪声可明显降低（对照组 0.106 → 0.029），但属于新的标签口径，不能复用旧检查点，旧标签与新标签也不可混用。
   - 建议另行立项评估，不在本次数据扩充中顺带改。
