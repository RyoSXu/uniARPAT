# 设计：只更新最后一个普通encoder层的16对拟合

## 授权与待排除解释

- 马尚酱批准“只开放最后一个普通encoder层与读出”的下一项对照。本轮只增加`last_layer`臂。
- 已有同一16对／2000步结果：冻结G2、开放全部普通encoder与读出，第700步首次16／16并保持
  至末步；仅训练读出末步8／16。本轮相对前者唯一改动是冻结前5个普通encoder层的参数。
- 若通过，排除“从该G2 ep10模型出发，拟合这16对必须继续更新前5层”的解释；若未通过，
  仅说明最后一层在指定初值、优化设置与预算内未获得见证，保留更早层适配及优化解释。
- 第6层仍直接接收距离／方向相对特征，末尾G2仍使用周期边；通过不等于证明前5层完整保留了
  目标相关几何信息，也不等于定位哪一层丢失信息。这里只收窄获得拟合所需的参数更新位置。

## 固定合同与参数范围

- 复用原G2 ep10／seed42初值、`output/g2_small_fit_q1/train_cache.pt`及同一16对selection。
  仅使用32个Q1 train材料，选样seed20260926；核对缓存、数据和源文件哈希，不接用已适配权重。
- encoder内仅`layers.5.*`可更新，包括该层注意力Q/K/V、相对位置投影、前馈、归一化；
  `layers.0`～`layers.4`、所有`g2_msgs`及其他encoder状态冻结。H1与atom_src固定，原读出训练。
- 预期encoder可更新2,397,184／17,734,662个参数（约13.52%），读出仍25,357,825个参数。
  G2保持前向，最后一个冻结G2必须把梯度传回第6层；不显式切断这段计算图。
- FP32、eval模式、关闭dropout；同一完整16对batch重复2000步。读出与可训练encoder分别
  AdamW，lr5e-5、betas0.9／0.99、weight_decay0.01，各自梯度裁剪1.0。
- 谱差目标不变：`mean((128*((p_a-p_b)-(q_a-q_b)))**2)`。参数范围缩小会相应改变encoder
  裁剪范数；更新步数与数据暴露相同，不声称等算力。

## 验收、边界检查与保存

- 逐对残余MSE≤零谱差MSE的1%，残余TV≤目标TV的10%，16对同时通过。零目标差仍使用
  MSE≤1e-12、TV≤1e-6。第0步及每100步评估；保存首次全部通过权重并继续执行满2000步。
- 初始预测TV≤1e-5、blind尺度相对误差≤1e-5；读出梯度相对RMS≤1e-3、损失相对误差≤1e-5。
  沿用已通过的独立logits目标可行性对照，不重复该优化。
- 实际完整batch反向检查第6层及读出收到有限梯度，其余参数无梯度；第6层整体范数必须非零。
  测试覆盖最后G2被错误切断的反例、冻结前缀与G2逐值保持、最后层和读出实际更新。
- 每个预定检查点立即保存汇总及逐对明细；新臂应有21×16＝336行完整轨迹。
  首次及末步权重严格重载后核对冻结参数和缓冲区，并各前向5次：逐对判定须一致，数值TV差≤1e-5。
- 补充32材料eDOS oracle／blind中位R²及失败率；blind尺度从当前memory经过冻结H1重算。
  纯谱差目标无共有谱形锚定，本轮不评价valid、test或phDOS，不作全体准确率晋级。

## 实现与历史证据

- 新入口`tools/eval/g2_last_layer_fit_probe.py`，复用已有训练、梯度、重载与汇总函数；默认
  既有入口不变。标签`g2_last_layer_fit_q1`，setsid + nohup运行，拒绝覆盖。
- 直接引用`results/g2_non_value_fit_q1`中的四个旧臂及原始模型，不重跑。公共helper的旧执行
  版本按各次入口／共享helper快照区分；新执行代码与设计另存快照并登记哈希。
- 继承仅G2臂缺失304行中间逐对明细的记录及`measurement_source`标记，不补造历史。
