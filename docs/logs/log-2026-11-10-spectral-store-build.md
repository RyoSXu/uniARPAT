### 补充规则验证（审核会话要求，事先定的判据）

**问题**：没有规范 DOS 的材料，能否用它自己的另一条 GGA/GGA+U 任务代替？

**做法**：在有规范任务、又有其他自有任务的 57,848 个材料上（不含旧 test），假装规范任务不存在，用补充规则选一条，与规范谱比较。

- **规则**：先按任务类型（NSCF Uniform 优先，其次 Static），再选体积最接近输入结构的任务。
- **指标**：项目 E（E0 网格，每原子按各自计算晶胞）和谱形 TV。
- **参照**：同结构重复计算目标间 E 中位为 0.0526；模型 valid 误差约为 0.33。

| 补充任务类型 | 材料 | E 中位 | TV 中位 |
|---|---:|---:|---:|
| GGA Static | 40,955 | 0.499 | 0.524 |
| GGA+U Static | 7,352 | 0.339 | 0.617 |
| GGA NSCF Uniform（另一条） | 8,803 | 0.106 | 0.146 |
| GGA+U NSCF Uniform（另一条） | 400 | 0.155 | 0.220 |
| 全部（按类型优先） | 57,848 | 0.403（P90 1.56） | 0.508 |

- 只按体积选、不看类型时更差：E 中位 0.469，TV 0.545。
- **没有规范任务的材料有 68,769 个，其候选几乎全是 Static**（GGA 73,500 条、GGA+U 70,130 条），NSCF Uniform 只有 7 条。
- **判读（暂定）：按未对齐的比较，补充规则不可用。**
  - Static 任务的 DOS 与规范 NSCF Uniform 谱差很大，E 约为重复计算地板的 10 倍，并超过模型自身误差。
  - 原因推断为 Static 计算的 k 点稀疏、展宽设置不同，未逐条确认。
  - **未排除的另一解释**：每条任务按各自的 `efermi` 定零点，有带隙材料的费米能级在带隙内的位置有任意性，两次计算可能整体平移，在固定 E0 窗口下被算成很大的 E。
    该解释由独立会话的平移对齐检查核验（[日志](log-2026-11-10-fallback-shift-check.md)，写成后生效）；是否采用补充标签由用户看结果后决定，新切分方案等这个结果再定。
  - 这批 eDOS 标签不进第一轮训练。旧数据集中 219 个没有规范任务的旧材料原本就带冻结标签，不受影响。
- **视图**：`make_view.py` 保留 `edos_rule: canonical_or_fallback` 选项（来源码 3）以便将来检验。默认 `canonical`，所有视图配置都用默认。

### 声子泛函

- **无法从 MP 数据核实。**
  - API 的 phonon 文档：pheasy 的 `calc_meta` 只有工作流目录和作业名，dfpt 为空。
  - Delta 的 `run_type` 为空。
  - 声子 `identifier` 在 core `calc_types` 里对应的是材料的普通任务（如 GGA Static、r2SCAN 结构优化），不是声子计算本身。
- 库中记为 `unverified`。
- **间接证据**：pheasy 计算体积比输入小约 3.7%（11-05 审计），dfpt 小约 2%，与 PBEsol 一类泛函相符。这是推断，未证实。
