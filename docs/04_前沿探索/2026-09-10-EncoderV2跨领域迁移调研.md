# Encoder v2 跨领域迁移调研（2026-09-10）

> **性质**：前沿探索，不直接指导施工；可迁移点收敛进 Backlog E9。
> **硬约束**：`glibc 2.17` / `Python 3.12` / `torch 2.2.1` / `e3nn 0.5.6` / 无 `nvcc,cmake,C++17,triton,flash-attn`；推理仅 CIF 可导信息，谱只能当预训练目标；license 分代码/权重/数据核对。
> **方法**：四路并行只读调研，只认官方论文正文 + 官方源码/README/依赖 + 权重发布页。缺证据写“未找到官方证据”。

## 0. 最小可行组合（先看结论）

1. **能量 query**：`Fourier(E)` 或 SIREN trunk，`p=64-128`，纯 torch 手写。
2. **结构 branch**：全局 token MLP -> `[B,p]`，`dot(branch,trunk)+bias -> [B,Q,1]`，再 `ReLU + 3N 守恒缩放`。
3. **预训练**：随机 mask 30-40% bins/patches，`MSE_masked + 积分惩罚`，最后 Linear 包 `spectral_norm`。
4. **主干**：`e3nn 0.5.6 + eSCN 降阶思想 + EquiformerV2 block` 重写，`0e` 出原子特征；`DeNS 力条件去噪`作辅助 loss，推理删分支。
5. **MoE**：首选晶体级 MMoE + `z-loss`，次选 Soft MoE；`N<=4`，先软门控不用 top-k。
6. **注意力**：`5.5A 邻接 bool mask + 1 全局 token + 距离标量偏置 + SDPA math 后端`；可选 `torch-pme` 裸包库仑分支（需先验 `torch>=2.3` 冲突）。
7. **不做**：不引 `neuraloperator` 全库 / `torch-harmonics` / DGL / DeepXDE，不载时序权重，不复用老 `.torch` 权重，不装 flash/flex/xFormers/Mamba。

## 1. 谱/信号：神经算子与 mask 预训练

### 1.1 FNO（抄思想不引库）
- 原理：`FFT -> 截断低模复乘 -> iFFT + 局部分支` 学函数到函数映射。论文 `arXiv:2010.08895`，库 `https://github.com/neuraloperator/neuraloperator`。
- 可迁移：谱头用 1-2 层 `SpectralConv1d(torch.fft)` 重构被 mask bins，捕宽峰/带隙。
- 环境：核心 `torch.fft` 可行；`SFNO/torch-harmonics` GPU 版需 CUDA 扩展且官方预编译轮只对 `torch 2.6+/2.7+/2.8+/2.9+`（CPU-only 轮亦只对最新 torch），`torch 2.2.1` 下无匹配轮，源码编译又需 `nvcc`，**环境不可行**。`https://github.com/NVIDIA/torch-harmonics`
- 接口：固定网格头好接，任意能量 query 需再包 DeepONet trunk。
- DOS：原文只做 PDE，**未找到官方 DOS 直接证据**。
- License：`neuraloperator` MIT；旧极简仓许可未核验，不抄代码。

### 1.2 DeepONet branch-trunk（query 模板首选）
- 原理：`branch(结构) dot trunk(查询坐标)` 逼近算子。论文 `arXiv:1910.03193`，原仓 `https://github.com/lululxvi/deeponet`，现库 `https://github.com/lululxvi/DeepXDE`。
- 可迁移：`branch=全局 token -> [B,p]`，`trunk=Fourier(E) -> [B,Q,p]`，`DOS=sum branch*trunk+bias`；mask 可见 Q，branch 重构全谱。
- 环境：手写约 30 行纯 torch 可行；原仓锁老 TF/Matlab，DeepXDE 全功能重，**不直接复用**。
- 接口：完美适配 `[B,L,512]` 作 K/V，全局 token 作 branch。
- DOS：原文无 DOS，**未找到官方 DOS 直接证据**。
- License：原仓 `CC-BY-NC-SA-4.0` 商用不可，DeepXDE `LGPL-2.1` 有传染风险；**只学公式自写**。

### 1.3 PatchTST / MOMENT（mask 策略照搬）
- 原理：切 patch + 通道独立 + 随机 mask 重构。论文 `arXiv:2211.14730` / `arXiv:2402.03885`；仓 `https://github.com/yuqinie98/PatchTST` / `https://github.com/moment-timeseries-foundation-model/moment`。
- 可迁移：`patch_len 8-16`，`mask 30-50%` 随机 + 连续，轻量重构头只算 masked MSE；配 RevIN 缓解量级差。
- 环境：纯 torch/numpy，**可行**；MOMENT 官方推荐 py3.11，py3.12 需自测。
- 接口：能接，可先自监督暖机再冻结。
- DOS：**未找到官方 DOS 直接证据**；不直接载时序权重做 DOS。
- License：PatchTST Apache-2.0，MOMENT 代码/权重 MIT；时序数据许可不代替 DOS 合规。

### 1.4 Fourier Features / SIREN（能量编码首选）
- 原理：`[sin(2πBv),cos(2πBv)]` 克服谱偏置；SIREN 全网 `sin` 拟合信号/导数强。论文 `arXiv:2006.10739` / `arXiv:2006.09661`；仓 `https://github.com/tancik/fourier-feature-networks` / `https://github.com/vsitzmann/siren`。
- 可迁移：`E_norm -> Gaussian/NeRF 频率 -> MLP -> [B,Q,d]` 作 trunk/query；SIREN 用 `ω0=30/1` 初始化，推理必须 clip 到训练域。
- 环境：约 10 行纯 torch，**完全可行**。
- 接口：与 `[B,L,512]` 做 cross-attn 或 dot，任意 Q 分辨率。
- DOS：**未找到官方 DOS 直接证据**，通用坐标回归。
- License：两仓 MIT。

### 1.5 谱归一化与守恒（必做）
- `spectral_norm`：`W/σ(W)` 稳谱头，`torch 2.2.1` 自带，无第三方。论文 `arXiv:1802.05957`。
- `∫g=3N`：网络输出归一 DOS，乘 `3N/∫pred` 恢复绝对量；N 从 CIF 计数合法。直接证据 `Chen et al. Adv.Sci.2021, arXiv:2009.05163`，51 bins，`ReLU+归一化+MSE`，`¯ω` 相对误差作监控；`ALIGNN PRM2023 arXiv:2207.12510` 佐证 DOS-mediated 优于直接预测。
- 环境：思想约 5 行 torch 可行；原 `phonondos_e3nn` 快照锁 torch 1.5/PyG 1.5/老 e3nn，**环境不可行**；ALIGNN 整库需 DGL，**环境不可行**，只借结论。

## 2. 几何点云/蛋白：等变与去噪

- **基座**：`e3nn 0.5.6` 必选，`Irreps+TensorProduct+球谐`，官方要求 `torch>=2.2.0`，纯 pip，无禁依赖。论文 `arXiv:2207.09453`，代码 MIT。
- **eSCN/EquiformerV2**：边对齐 SO(2) 降阶 + 等变注意力三改，只移植逻辑；原 OCP 栈锁 py3.8/torch1.13/e3nn0.4.4，**原样不可行**。论文 `arXiv:2302.03655` / `arXiv:2306.12059`。
- **MACE/Allegro/NequIP**：高阶多体 + 严格局域 + 双截断（5-6A 原子图 / 3A 键图）；去加速后条件可行；权重 MIT/ASL 逐模型核对。
- **TorchMD-Net/PaiNN**：标量+矢量双通道，无 CG 也可写等变块；原仓需 warp/PyG 编译，**原样不可行**，思想重写可行。PaiNN 有分子光谱证据，DOS 仍无。
- **IPA**：标量注意力 + frame 下 point 误差，全局 SE(3) 不变；block 用纯 torch 重写可行，全管线需 MSA/基因库，**全管线不可行**。代码 Apache-2.0/MIT，权重 CC-BY 混杂。
- **GemNet/DimeNet**：显式 `d,θ,φ` 两跳边，最多借角 RBF + 二面角偏置；原仓需 torch-scatter，PyTorch 版 Hippocratic-2.0 商用不可，**不搬整模型**。
- **DeNS/Uni-Mol**：力条件去噪 + mask 原子 + 坐标去噪；训练加噪/力编码，推理删分支保 CIF-only；Uni-Mol 需去 RDKit 2D。论文 `arXiv:2403.09549`；代码 MIT。
- **Point V2/V3**：分组注意力/序列化邻域，只借邻居思想；需 flash/spconv/pointops 编译，**不可行**。
- **晶体 DOS 头**：ALIGNN 有电子/声子 DOS 强证据但代码禁 DGL；DOSTransformer/Xtal2DoS 与 query decoder 同构但均**未找到官方 license**，只借 decoder 范式。

## 3. MoE/多任务：轻量 router

排序（兼顾 11k + 盲推）：**晶体 MMoE + z-loss > Soft MoE > Switch Top-1 > Expert Choice/BASE（只借思想）**。

- **Switch Top-1**：每 token 一专家，`loss=αNΣfP`，`α=1e-2`。论文 `arXiv:2101.03961`，代码 Apache-2.0。纯 torch 重写可行；`N<=4`，监控 `f,P` 直方图与 drop 率。无 DOS 证据。
- **GShard Top-2 / Noisy Top-k**：表达力高但 11k 方差大；`fairscale` 整包不可行，只抄 `top2gate.py` 逻辑（BSD）。无 DOS 证据。
- **Soft MoE**：无离散 argmax，无 dropping，`n=4,p=1-2` 增量极小，11k 首选扩容；官方 JAX 库不可行，纯 torch 重写约 40 行。论文 `arXiv:2308.00951`，代码 Apache-2.0。无 DOS 证据。
- **Expert Choice**：专家选 token，零 aux，但小 batch/单样本推理语义漂移，需 `eval capacity=2.0` 或转 token-choice。论文 `arXiv:2202.09368`。
- **z-loss**：`mean(logsumexp^2)`，`cz=1e-3`，一行，最推荐先加。论文 `arXiv:2202.08906`。
- **MMoE/PLE**：专家共享 + 每任务一门，最贴 `decoupled_decoder`；输入只能用 `h_crystal/memory`，禁 oracle 统计量；`N=3` 起步，监控双门余弦。论文 `doi:10.1145/3219819.3220007` / `doi:10.1145/3383313.3412236`。
- **晶体 vs token**：晶体级一票制最稳、最满足盲推；token 级容量大但方差大；推荐 `Encoder 软 token-MoE + 颈部晶体 MMoE` 混合，总增量约 2M。
- **MoE×全谱 DOS**：**未找到官方证据**；Mat2Spec/Xtal2DoS/E3NN/PET-MAD-DOS 均无 MoE，只能借评测套路。

## 4. 高效注意力：免编译稀疏/长程

首选：`5.5A 邻接 bool mask + 1 全局 token + 距离标量偏置 + SDPA math 后端`。纯 torch，不降渐近复杂度但 `L~50-500` 可接受；距离偏置不破坏周期 SE(3) 不变，`unit_dirs` 原向量进 logits 则破坏。

- **SDPA**：`torch 2.2.1` 自带，CUDA 外回退 C++ 实现，可 `enable_math_sdp()` 强制；BSD-3。`https://docs.pytorch.org/docs/2.2/generated/torch.nn.functional.scaled_dot_product_attention.html`
- **Longformer/Exphormer/GraphGPS**：滑窗 + 全局 token + expander 边，思想强烈推荐；Longformer Apache-2.0 纯 torch 切块可行，`L<1024` 稀疏收益小；Exphormer 核心免编译，别装 `pyg-lib` 加速轮。
- **Performer/Linear**：`phi(Q)phi(K)` 线性化，备选降显存；MIT/Apache-2.0；mask 归一化不如 SDPA 直观，仅全局层用。
- **NATTEN/Swin/BigBird**：NATTEN 需 cmake/CUDA/CUTLASS，**不可行**；Swin 纯 torch 但 2D 网格假设错配；BigBird 原版 TF/TPU 不可行，HF 版 `L~1e2` 负收益。
- **Flash/Flex/xFormers/Mamba**：需 nvcc/ninja/triton/compile，**全部不可行**。
- **Ewald MP**：傅里叶长程校正公式必借，自写 `torch.fft` 分支；整库重依赖，**不搬整库**（license 未找到官方证据，不做断言）。论文 `arXiv:2303.04791`。
- **torch-pme**：可微 P3M/PME，最优长程库候选，BSD-3；但 `pyproject` 要 `torch>=2.3`，锁 2.2.1 需沙盒先验，裸包安装，邻居用自有 5.5A。`https://github.com/lab-cosmo/torch-pme`
- **Matformer/Crystalformer**：周期不变图 + 无限注意力距离衰减，最贴晶体范式；Matformer MIT；Crystalformer 主体有 CUDA 成分，只复刻公式。
- **DOS 锚点**：DOSTransformer `arXiv:2311.12856`、Xtal2DoS `arXiv:2302.01486`、Mat2Spec 与 query 范式同构，但高效注意力库本身**均无 DOS 直接证据**。
