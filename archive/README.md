# 历史材料

此目录集中已退役方案与整理证据。当前入口见 [README](../README.md)，当前科学状态见
[docs/status.md](../docs/status.md)。归档中的历史计划不能自动成为新训练指令。

| 子目录 | 内容 |
|---|---|
| `code/` | 历史模型、支持库、工具和测试；运行版本适配当前路径/导入，原始源码身份另行核验 |
| `docs/` | 历史设计与日志，按原日期和主题查找 |
| `data/` | 本地旧缓存、旧网格和 v1 数据处理材料；不得用于替代当前 Q1 |
| `results/` | 历史报告、运行产物与图；有限证据受控纳入 Git，原始载荷/权重本地保留 |
| `metadata/` | 目录迁移登记、验证摘要、原始源码身份、旧环境快照 |

历史运行代码使用 `archive.code...` 显式导入。当前共享模型仍保留旧参数开关以兼容权重，
归档是候选状态分类，不自动否定整条研究路线。必要的旧数据和 checkpoint 不随 Git 克隆提供。
旧网格的 30 个失效链接、10 条整理前缺失的源码身份在迁移登记中明确列出，不补造证据。
