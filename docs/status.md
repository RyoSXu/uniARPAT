# 当前项目状态

更新日期：2026-09-29。此页只记录当前基线、研究方向和待共同决定事项；历史结果见对应日志。

## 基线

当前比较基准为 Q1 上的 B7 `_e9ctl`（M1，35 epoch，选用 epoch 33）。精度口径与默认训练约定见
[`decisions.md`](decisions.md)。历史 test 已被用于若干诊断，不应称为从未触碰的独立留出集。

## 研究方向

目标是取得**结构条件谱形突破**：增强模型利用晶体结构预测谱形的能力，优先关注 eDOS，同时保护 phDOS。
当前没有选定具体架构或训练方案。大方向见
[`design/design-structural-refinement.md`](design/design-structural-refinement.md)：

- encoder 如何捕获并转换周期结构信息；
- 共享 encoder 配合任务专属 decoder/head 是否适合两类谱；
- eDOS-only 标签如何与架构、监督训练或预训练结合。

## 当前理解

Q1 valid 同组成材料对的目标谱差中位 TV 约为 `0.270`，B7 预测谱差约为 `0.016`；这是结构条件响应不足的证据，尚未定位根因。近期联合边内容、谱差辅助和 G2 等具体方案没有得到精度提升，但只关闭各自测试的实现。D3a 本地候选不支持直接扩数填补当前支持缺口，没有检验所有 eDOS-only 训练或迁移方法。gamma 校准已 park，不代表其他尺度方案均无效。

## 下一步

先让 agent 对不同架构和数据学习路径提出实质不同的假设并核对项目事实，再由用户选择要深入的方向。方向讨论不等于代码或训练授权；执行前另定范围与判据。
