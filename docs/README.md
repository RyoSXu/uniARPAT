# docs 使用说明（给人看的目录地图）

- 开工 3 分钟：`STATUS.md`（活状态）→ `INDEX.md`（去哪找）→ `GLOSSARY.md`（术语）。
- 任务总表只有一张：`01_开发文档/待开发总清单Backlog.md`。待办只进 Backlog，不散记。
- 结论只记两处：Backlog（执行）+ `01_开发文档/决策纪要Decisions.md`（冻结结论）。
- 流水只记一处：`03_工作日志/日志-YYYY-MM-DD-<主题>.md`，一任务一篇，四件套：改了什么/实测/verdict/下一步。
- 中文历史目录名冻结（`01_开发文档` 等）不再改名，新文档用英文命名，对照见 `INDEX.md`。
