# 术语表

当前配置与公式见[固定契约](decisions.md)，进度见[状态](status.md)；历史编号以对应日志为准。

## 数据与评价

| 术语 | 含义 |
|---|---|
| DOS / eDOS / phDOS | 态密度／电子态密度／声子态密度 |
| Q1 / crystal-q1-v1 / pre-Q | 冻结 Q1／完整结构修复版／更早数据口径；修复版有效 train 为 18,704，版本间不直接作同数据比较 |
| CIF / blind / oracle | 晶体结构文件／由结构预测形状和总量／使用标签总量重建的谱形诊断；oracle 不参与当前选点 |
| N_val / H1 eta、gamma | 历史尺度侧车／有界尺度头；N_val 混有占据谱审计与组成回退，不是统一赝势真值；新 blind 重建不用它 |
| E / 联合 mean E | 按 train 谱能量归一化的每原子 blind 全谱平方误差／两任务材料均值各占 50%，越低越好 |
| SumNorm / S / E＋S | 逐谱除离散和得到形状／KL＋W1＋Huber 谱形辅助／当前联合训练目标；零谱 S=0，S 不进入选点 |
| 中位 R² / P10 / 失败率 | 典型材料 R²／R² 第 10 百分位／R²<0 的材料比例。R²<0 表示平方误差大于按该材料真实谱均值预测的误差，常量谱按实现的数值约定处理 |
| 双任务保护 | 完整 valid 的两任务失败数与中位 R²分别通过固定旧 A64 保护；通过不保证相对每个新对照或每种尾部指标都改善 |
| no_eligible_best / latest | 没有轮次合格，不能宣称 best／只用于按原契约恢复训练 |
| coverage mask | 该箱有无有限源采样点；不等于物理非零区间，当前不据此删评分箱 |
| TV / signed 谱差误差 | 单位和谱形的总变差距离／预测谱差与真实有符号谱差之间的误差；差异幅度更大不等于预测更准 |
| absolute / reduced 组成 | 完整原子计数相同／约分化学式相同；材料对相关，组成组统计不能当独立材料对处理 |
| E0 / P0 | eDOS [−6,6] eV／128 箱，phDOS [−280,980] cm⁻¹／64 箱 |

## 模型与研究状态

| 术语 | 含义 |
|---|---|
| ZP / ZP100 | Embedding→LayerNorm→Linear 的原子序号入口／旧 Q1、100 轮历史参考 |
| encoder / decoder / head | 更新原子结构表示／通过谱查询生成输出表示／产生最终谱形或总量 |
| A / B+ | 不变量局部消息／含高阶等变中间状态的完整局部消息候选；当前暂定 A 研究路线，无总体优胜结论 |
| I1 / I2 / I3 / I4 | 修正骨架上的简单径向 C1／完整 B+／完整 A／B+ 加局部状态直连读出 |
| A64 / W1 / LN1 / LN2 / LR1 / LR2 | 完整 A 64/128／扩宽／内部 pre-norm／外层 post-norm／增量读出／关闭四个内部加法，外层残差保留；当前采用 LR2＋E＋S |
| staged / midpoint / alternating | 两次局部先于六次全局／局部插在全局前和中段／既有交替规则；具体层序由 `LocalGlobalEncoder.execution_order` 决定，不能只凭名称推断 |
| per_atom 总量 | 非负无固定上限的每原子处理后窗口面积；乘 N 并结合箱宽重建密度，不认证原加工面积守恒 |
| 工作点 / 性能参照 | 当前后续研究配置／用于对比的历史成绩；采用工作点不等于全面超越历史参照 |
| epoch / pilot / park / closed | 一轮完整遍历／有边界的探索预算／暂不采用该候选／当前阶段结束；不自动否定更大研究方向 |
| E(3) 不变性 | 晶体整体平移、旋转、反射后最终预测谱一致；有限数值检查与架构保证须区分 |
