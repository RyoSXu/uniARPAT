# D3a eDOS-only 候选支持面裁决设计

日期：2026-09-28。状态：已获准执行本地 500–1,000 条候选审计；不包含训练、联网采集、
Q1 缓存修改或数据契约变更。

## 项目决定

本任务只回答一个问题：本地 MP eDOS-only 候选是否同时具备足够的**可落实率**和对原 Q1
训练谱形支持面的**可测补充价值**，值得进入 10–20k 定向扩充 pilot 的设计。

结果只有两种行动：

- **通过：**下一步只写 10–20k 数据扩充 pilot 设计与数据契约草案，仍不自动训练。
- **停止：**关闭当前数据扩充路线，回到模型机制选择；不继续增加归属样本、放宽质量标准或
  串联另一项数据诊断。

覆盖改善是标签支持面的证据，不等于精度收益。只有后续独立 Q1 valid 成对训练才能给出精度结论。

## 冻结输入与禁止项

- 候选全集固定为 `E − (P ∪ C)`：
  `census_effective_ids.json − (dual_spectra_ids.json ∪ v2_processed.parquet.mpid)`，预期 121,420。
- 结构与候选元数据只读自 `raw/pretrain_structures/structures_*.jsonl`；谱只读自本地
  `raw/delta_mp/core/electronic-structure/total-dos/`。
- Q1 train 标签只用于定义原训练支持面和定向抽样的训练侧元数据统计；valid 标签只在全部候选
  抽样、归属、质量判定完成后做一次冻结覆盖评估；test 不读取。
- 不联网、不读凭据、不恢复历史网络脚本、不写 `raw/`、`v2_release/`、`data/` 或 `index/`，
  不修改 Q1 manifest/split/cache，不启动训练或 GPU。
- 历史脚本只作公式来源；新工具必须使用参数化路径和本地输入，禁止复制历史硬编码凭据。

## 1,000 条冻结抽样

随机种子字符串固定为 `d3a-edos-support-v1`，哈希为
`sha256(seed + "\0" + mpid)`；所有并列项用该哈希再按 `mpid` 排序。

### 概率臂：500 条

在 121,420 条候选上按哈希升序取前 500。该臂是候选总体归属率、标签兼容率和质量可用率的
唯一无偏估计对象；定向臂不得混入可用率主估计。

### 定向臂：500 条

先排除概率臂，再只根据候选元数据与 Q1 train 输入元数据构造分层：

- 精确原子计数组成是否在 Q1 train 出现；
- `nelements`：1、2、3、≥4；
- `nsites`：1–4、5–8、9–16、17–32、33–80、>80；
- 晶系；
- 带隙：0、(0,2]、>2 eV。

每个分层内按冻结哈希排序；分层按“未见精确组成优先、该分层在 Q1 train 中数量由少到多、
分层键字典序”排序，循环每层取一条直到 500。这个臂估计元数据定向策略的支持面上限，
不能用于推断 121,420 条总体可用率。

抽样完成后立即写出清单及其 SHA-256；后续不得按归属或质量结果补抽、换样或改臂。

## 本地归属与标签兼容性

对每条样本，以 `(nsites, species)` 在 `delta_edos_index.parquet` 分块，并保留体积相对差 `<1%`
的 task；已有本地 `dos_task_id` 只能作为候选指针，仍需结构复核。用
`StructureMatcher(ltol=0.2, stol=0.3, angle_tol=5, primitive_cell=True, scale=True)` 比较候选结构和
Delta task 结构。

- 无候选 task：`unresolved_no_task`。
- 无结构匹配：`unresolved_no_match`。
- 有多个结构匹配：按体积相对差、`identifier` 确定性选首条，同时记录匹配数量，不能隐去歧义。
- `run_type` 只接受 `GGA` 或 `GGA+U`；其他类型记 `incompatible_run_type`，不进入可用集。
- 被选 task 必须能从本地 Delta 读到有限 `efermi`、等长能量/密度数组和至少两个有限采样点。

归属状态、候选 task 数、结构匹配数、体积差、task id 和 run type 全部写入逐样本结果。

## 冻结质量与谱形处理

沿用 E0 `[-6,6] eV`、128 bin 和历史 `box_average` 规则；能量先减 `efermi`，上下自旋相加，
缺少合法 down-spin 时按零处理。用与当前 Q1 `data/train4ARPAT/stats_v2.json` 一致的冻结文件
`/root/home/newstudy/getdata/raw/v2_winsor_thresholds.json` 对候选执行与 A4 pass2 相同的
孤立尖峰裁剪，不能用候选重新估计阈值。

候选的任务晶胞价电子数由 `index/z0_zval.json` 对 Delta task 结构逐原子求和。冻结截断指标为
完整原始谱积分除以任务晶胞价电子数；`<0.5` 判为 `truncated`。原胞 `N_val` 另由标准化原胞求和，
只作未来 H1 可行性记录。本轮可用样本须同时满足：

1. 结构归属成功且 run type 兼容；
2. 原始谱可读，截断指标 `>=0.5`；
3. E0 至少一个 bin 有覆盖，处理后 E0 谱质量为有限正数；
4. task-cell 和 primitive-cell `N_val` 均为有限正数。

`edos_mask` 覆盖比例、截断指标、两种 `N_val`、E0 总质量及失败原因都保留。coverage 只报告，
不新增一个比 Q1 更严格的过滤阈值。

## 支持面指标

所有谱先在 E0 上总和归一化，距离固定为总变差
`TV(p,q)=0.5*sum(abs(p-q))`。

1. **可落实主指标：**概率臂 500 条中可用比例及 Wilson 95% 区间。
2. **候选新颖度：**每条可用候选到原 Q1 train 目标谱的最近 TV；报告中位数及超过冻结 train
   Q3 阈值 `0.253176` 的比例。
3. **冻结 valid 覆盖主指标：**只取既有结果中 `train_support_quartile=4` 的 Q1 valid 样本，比较其
   到原 Q1 train 的最近 TV 与加入本轮可用候选后的最近 TV。报告配对中位下降、相对下降、严格改善比例，
   并按 valid 样本 bootstrap 2,000 次、seed `20260928` 给出中位下降 95% 区间。
4. 分别报告概率臂、定向臂和合并集；正式裁决使用合并集，可用率仍只使用概率臂。

### 执行期质量复核与保守敏感性

首次正式运行后发现，新候选只能用元素表估算 task-cell `N_val`，不是冻结 Z0 对每条材料的完整
核定过程。为避免裁决依赖这个近似值，定稿前增加两项不改变样本、不改变预注册门槛的复核：

1. 在已有 6,344 条增量材料上比较同一近似判定与冻结 `z0_trunc.parquet`。有限冻结标签中记录
   假放行和假排除数量；冻结缺值另行列出，不能混入准确率。
2. 另报“全部可读”敏感性：凡结构归属成功、run type 兼容、E0 谱形有限且可归一化的候选均进入
   支持面，包括近似 `trunc < 0.5` 的记录。此结果只检验支持面停止结论是否依赖截断近似，不能把
   疑似截断谱改称可训练数据，也不替代预注册的严格裁决。

## 预注册裁决

只有以下条件全部满足才通过：

- 概率臂可用率 Wilson 95% 下限 `>=0.50`。这直接保证按同流程处理 20k 候选时，保守预期仍能得到
  至少 10k 可用样本，连接到拟议 pilot 的 10–20k 规模。
- 合并可用集使冻结 valid Q4 的最近支持距离中位数相对下降 `>=5%`，中位绝对下降 bootstrap 95%
  区间下限 `>0`，且至少 `25%` 的 Q4 样本获得严格更近的候选谱。5% 与 25% 是进入昂贵训练前要求的
  最小幅度和覆盖广度门槛，不解释为预计 R² 收益。
- 抽样清单无 Q1 成品重叠、没有非 GGA/GGA+U 样本进入可用集，逐样本结果数量与冻结清单一致。

任一条件失败即停止。不得因接近阈值而补样、放宽匹配或改质量标准。
