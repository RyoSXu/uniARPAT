# 日志：YYYY-MM-DD — 主题

对应设计：链接。记录日期：YYYY-MM-DD；状态：准备／执行中／已完成／中断／暂不采用。

## 范围与身份

- 问题、对照/候选、数据版本/cohort、任务、blind/oracle、loss 与选点规则：
- 有效命令、唯一标签、seed、epoch 预算、配置/协议与输入/源码指纹：

## 执行与证据

- 实际运行的测试、预检、训练/恢复、成本与异常；未执行项及原因：
- history、best/latest、完整导出与独立核验位置；区分 Git 收录证据和需另存的本地产物：
- 当前主表：分任务 E 均值/中位/P90、R² 中位/P10、失败数/率、checkpoint 资格；历史协议按其原指标报告：
- 配对差、区间及其抽样单位/适用范围；Oracle 与同组成谱差只作诊断：

## 结论与交接

- 事实、推断、未证明事项；是否达到事先判据，采用决定由谁在何时确认：
- 同步当前状态/契约/导航；下一项需决定的问题，不自动追加实验：
- 若仍需长时间执行或监控，在回复中提供给新 agent 的提示词，不存入仓库。
