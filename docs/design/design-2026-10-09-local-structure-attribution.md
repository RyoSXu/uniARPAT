# 设计：局部结构信息的贡献诊断与最小对照

对应 [当前状态](../status.md)。第一阶段已有模型的无更新诊断已完成，见
[诊断日志](../logs/log-2026-10-09-local-structure-diagnosis.md)。用户随后确认继续实施同骨架
C0/C1 对照；第二阶段的代码、验证、执行状态见
[对照实施日志](../logs/log-2026-10-09-local-structure-controls.md)。数据与 A/B+ 公式保持。

## 目标与证据边界

当前问题是：新 Encoder 更强的训练集拟合和结构响应为什么没有转化为验证收益？
旧 baseline 与新模型同时改变了多个 Encoder 设计，既有结果不能单独归因于局部模块。
第一阶段以已有 baseline/B+ 分段 L=2、G=6 的 35/100 轮模型为对象，区分：

1. 对几何有响应，但谱变化的方向或幅度不正确；
2. 几何信息进入局部状态，后续全局混合或读出利用不足；
3. 训练覆盖或目标条件限制结构规律的泛化。

只加载原协议 `balanced_oracle_mae` 选出的真实 best checkpoint。没有保存的 R² 峰值权重
不能从历史指标恢复，也不把 35 轮模型当作 100 轮学习率轨迹的第 35 轮。

## 第一阶段：已有模型诊断

入口：[lg_structure_diagnosis.py](../../tools/eval/lg_structure_diagnosis.py)。
复用 `load_run/select_best` 的配置、历史与 checkpoint 契约检查，以及
`evaluate_split` 的 SumNorm/H1 blind/oracle 重建与逐材料指标。

- 数据：`crystal_q1_v1`，全量有效 train 用作结构支持参考；固定既有 train 子集 2,048 条
  与完整 valid 2,313 条用于四模型前向。按材料 ID 对齐，绝对组成与约化组成分别统计。
- 使用 train/valid 文件哈希验证数据，禁止加载或计算 test。模型设为 eval，不构造优化器。
- GPU 短测后运行；资源成本以本次记录为准，未训练，不将诊断耗时作为训练成本。

### 谱差是否预测正确

对于同组成材料对，令 `Δy = y_i-y_j`、`Δp = p_i-p_j`，在两种任务各自的单位和为 1
谱形空间计算：

- 目标差异 `TV_target = 0.5 × sum(abs(Δy))`；
- 预测响应 `TV_pred = 0.5 × sum(abs(Δp))`；
- 有符号谱差误差 `E_pair = 0.5 × sum(abs(Δp-Δy))`；
- 相对于「两材料预测相同」的收益 `skill = 1-E_pair/TV_target`。

`skill=0` 表示与零结构响应参照相同，负值表示更差，1 表示谱差完全正确。
目标差异接近零时不计算比例。另报谱差向量夹角余弦，幅度相同、方向相反不能判为改善。
模型差值按组成组先求组内配对误差均值，再重采样组成组；共享材料的配对不按独立样本重采样。
这只表达材料/组成组层面的不确定性，不能代替跨训练种子证据。

### 信息传递与分支敏感性

记录元素入口、局部 64 维投影/标量读出、各局部与全局层、两任务 decoder 输出的
token 均值和逐通道均方根。使用置换不变汇总的相对配对距离，只在同一模型/同一阶段内解释。
这些汇总有损，不能将距离缩小解释为完整信息被擦除，也不能跨模型直接对齐表示坐标。

对固定 seed=42、标签无关抽取的 256 条 valid，临时进行推理敏感性检查：

- 局部残差乘 0.9，以及整体关闭局部残差；
- 仅径向 RBF 输入置零，仍保留邻接、截断权重与计数；
- 关闭额外 l=3/4 高阶角度输入；
- 关闭高阶输入并屏蔽非标量球谐，保留径向消息与计数。

这些操作可能产生训练分布外状态，不是 C0/C1 重训对照，不用于决定生产开关。
所有 hook 在正常/异常退出时恢复；检查恢复前后的输出、同设置重复前向的 FP32 数值波动、
内存模型状态哈希及磁盘 checkpoint 哈希。物理谱与归一化谱使用相对/绝对容差组合。

### 数据覆盖与标签核查

在完整有效 train 和 valid 当前晶胞上重新计算 6 Å 周期记录。结构支持代理是每原子的
16 维 cutoff 加权 RBF 和、配位数标准差和单原子体积；只用 train 标准差归一化，
在相同约化组成的 train 中寻找最近邻，排除材料自身。没有同组成参考时单独标记，
不将其距离填零或误报为有支持。此代理不包含完整角度或长程结构信息。

按组成是否见过、原子数、配位数、径向支持远近及目标谱熵分组；阈值由 train 决定。
目标谱熵属于事后标签诊断，不可作为预测输入。报告 5–6 Å 边比例、cutoff 质量比例及
涉及该壳层的邻边对 cutoff 权重比例，权重比例本身不说明该壳层的物理重要性。

同组成对用 StructureMatcher 的明确容差查找相近结构，并报告目标谱差；尺度归一与
匹配容差允许实际结构差异，匹配成功不等同于输入完全相同。当前缓存不含完整磁态、展宽与
计算设置，不能仅凭匹配结果判定标签错误。

## 第二阶段：已确认的同骨架对照

固定新骨架：ZP、L=2、G=6、分段、六层共享 decoder、512 维外部标量，保持 E(3) 输出要求。
数据、归一化、损失、优化器、学习率、batch、选点及有效样本集合与现有 35 轮 G6 一致。
固定预算 seed=42、35 轮、batch=32、lr=5e-5，warmup/余弦沿用实际 35 轮执行配置。
预算用于当前条件下归因，不代表充分收敛；不因某臂结果不佳单独增加轮次。

| 组别 | 局部分支内容 | 解释范围 |
|---|---|---|
| C0 | 无几何逐原子网络；保留 512↔64 投影、两块与相近残差/LN 组织 | 新骨架的组成参照 |
| C1 | 邻居元素＋距离 RBF 的标量消息；6 Å 全镜像、原 cutoff、计数和聚合归一化 | 简单局部结构方案的收益 |
| C2 | 当前 B+，包含方向通道与高阶角度统计 | 复杂局部方案相对简单方案的收益 |

C0 不能读取邻居选择、周期镜像、距离、角度、配位计数或晶格。仅 RBF 置零不满足 C0。
C1 也不能通过方向状态或角度统计间接读取角度。
实现前计算有效参数量，优先让 C0 与 C1 接近，公开各局部分支及全模型参数数目；
参数量相同也不意味着表达能力相同，C1/C2 差异不能全部归因于角度。

共同 ZP、全局、decoder/head 及语义相同的局部投影/LN 使用同一未训练参考权重。
分支特有参数单独初始化，保存模型与训练开始 RNG 摘要。C2 仅在参数、初值、数据顺序、
学习率轨迹、实际执行选项及选点协议复现已有记录后复用；否则必须明确重跑成本，不能冒充配对。
不同分支使用独立 tag/契约，禁止借用训练后权重初始化其他分支。

### 已实施的局部内容

C0 每块使用 `64→208→64` 的逐原子消息 MLP，再将原标量与该消息拼接，经
`128→129→64` 更新 MLP 和残差/LN。C1 每块使用 `144→128→64` 的邻边消息 MLP，
输入为中心/邻居各 64 维标量与 16 维距离 RBF；按原 cutoff 加权求和、除以硬配位数平方根，
再拼接原标量、径向聚合、`log1p(k)` 与 soft count，经 `130→128→64` 更新 MLP 和残差/LN。
所有参数均进入实际计算，无用于凑数的失活参数；每调用保留两个内部块和相同的 512↔64 投影。

两次调用的局部消息参数量：C0 **340,164**、C1 **340,096**、C2 **369,544**；C0/C1 只差 68。
全模型参数量分别为 **75,894,280 / 75,894,212 / 75,923,660**。C0/C1 容量相近是控制措施，
不证明它们表达能力相同。C1/C2 还改变消息形式和内部通道，不能解释为仅移除角度。

C0 的预测路径不构建周期记录、距离或结构缓存；公共入口仍检查晶体输入是否合法，
几何数值不作为预测特征。`q1_coord` 表示谱网格坐标条件，不是原子空间坐标。
C1 不构建单位方向、邻边对、球谐或高阶角度统计，复用有预算的缓存仅保存径向结构特征。

共同 ZP、六层全局、decoder/head、外层 LN 和局部投影/块 LN 均逐值来自未训练 B+ G6。
初始化协议为 `local-structure-control-init-v1`，checkpoint 契约为
`local-structure-control-model-v1`，其中记录 route 与局部内容版本，不能混用 C0/C1/C2 权重。
训练 runner 原有的循环前 seed reset 与 `DistributedSampler(seed=0)` 保持；新增实际开始/恢复 RNG 摘要。

现有 C2 的全部初始化哈希、冻结配置、数据、选点、完整预算和自第一轮生效的执行策略已复核。
C2 当时未保存训练开始 RNG 摘要，其 seed reset 依据既有 runner 代码和 seed=42 执行记录重建，
不能称为复核了当时保存的开始状态。结果分析还会复算 C2 valid，与前阶段逐材料结果及失败标志比较。

训练入口是 [`local_structure_compare.py`](../../tools/eval/local_structure_compare.py)，默认只打印两条
命令；`--run` 要求成功的真实数据预检，核对代码指纹、参考 checkpoint、配置和数据身份后顺序训练。
异常即停并保留现场，不自动重试。完成后在共同 MAE 选点上导出固定 train 子集与完整 valid，
比较三组的 blind/oracle R²、MAE、失败率和有符号同组成谱差误差；区间不代表跨训练种子稳定性。

采用判断暂不新设综合分数。保留共同 MAE 选点，分析 valid eDOS oracle 谱形、blind
部署指标、两类谱失败率和 phDOS 保护；并列完整轨迹，禁止每臂事后挑不同规则报胜。

| 结果 | 后续优先核查 |
|---|---|
| C1 有收益、C2 无额外收益 | 复杂聚合、压缩及优化；保留简单径向参照 |
| 几何方案只改善 train | 结构支持与泛化，之后再决定容量/正则化 |
| 几何方案改善 valid，但仍落后旧 baseline | 全局层、读出与几何入口限制 |
| 两种几何方案均无 valid 收益 | 数据、监督、读出；不否定局部结构的一般价值 |
| oracle 改善而 blind 恶化 | 尺度预测与谱形分开诊断 |

## 验证

测试覆盖谱差方向、零响应参照、零目标差异、配对身份、组成组统计、支持参考自排除，
以及推理 hook 在异常退出时恢复且不改变参数。小规模运行只验调用链；正式报告写清
实际数据量、checkpoint 选点、无更新检查、运行成本及尚未排除的解释。
