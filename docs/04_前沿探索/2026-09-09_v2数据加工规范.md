## 2. 自旋/通道规则

- eDOS总量 = spin_up + spin_down；单通道（非磁性，~83%）即总量；
- 磁性样本双通道都存，processed视图存总量 + 备注（通道级建模留Phase 2）。

## 3. 结构 canonical 化

MP summary结构为准；统一**原胞 + 固定symprec**（A2发现3%常规胞/原胞混用）；symprec值与pymatgen版本写入provenance；round-trip抽1000条 diff=0 方可放行。

## 4. CIF六项清单（per-sample必存）

结构JSON全文、canonical CIF文本、对称性（空间群号+晶系+Wyckoff）、占位向量、谱原始、provenance行。

## 5. 占位规则（已审计）

pilot 100材料1450格点**0部分占位**（MP全有序）。规则：断言全1，违规样本隔离+日志，不静默丢弃；JARVIS侧同样审计后再定。

## 6. 离群规则（A2归因表驱动）

单bin spike类伪影 → winsorize（阈值=该bin p99.9，按能量bin分别算）；真物理尖峰（f电子）→ 保留 + 训练降权；不可考 → 缺失处理。

## 7. 切分（`index/split_v2.yaml`）

成分去重跨集隔离 + 难度（峰均比/带隙）/晶系分层 + seed固定；旧索引保留对照。

## 8. 存储

Parquet全集（含split列，可复用）→ `build_v2_cache.py` → npy/memmap训练缓存；删哨兵；float32；mask唯一化；manifest sha。
