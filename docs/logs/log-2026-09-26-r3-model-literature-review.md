# 日志：2026-09-26 — 周期几何消息与谱对齐机制调研报告

马尚酱，你好。根据你的要求，我已完成对 ComFormer、ALIGNN 以及 Mat2Spec 的文献与实现对照、核验和自检。以下是调研结论。

## 核心结论 (Conclusion Summary)

当前 B7 模型的几何机制确实存在信息路径限制（几何仅用于注意力权重计算，无法在同质节点间产生特征破缺）。但 G2a（径向内容残差）的失败表明，仅补充径向距离内容不足以带来 DOS 预测精度的整体突破。
在对比了几何路线（ComFormer、ALIGNN）与直接谱相关路线（Mat2Spec）后，我推荐以下两个最具讨论价值的机制片段：
1. **几何路线：基于张量积/角度的条件内容更新（借鉴 ComFormer）**，以解决同质多形体的配位盲点。
2. **谱相关路线：结构-谱潜空间对齐（借鉴 Mat2Spec）**，直接针对项目当前面临的“高粗糙度/高熵谱形预测过度平滑”问题。

## 机制一：ComFormer 的几何条件消息与等变表示 (ICLR 2024)

1. **来源与版本**: ICLR 2024, github `divelab/AIRS`, commit `4a16c68`。关键章节：Section 3 (周期表示), 4 (等变消息)。关键代码：`iComformer.forward`, `eComformer.forward`, `ComformerConv.message`。
2. **解释 (I/O 与计算)**: 输入带周期性边界的原子图，输出标量及 SO(3) 等变特征。核心在于将距离和方向/角度直接与源原子的隐含特征进行非线性或张量积结合，然后送入聚合函数（求和/平均）。此时，几何不仅影响“听谁的”（权重），也直接改变了“听到了什么”（内容）。训练和推理均需完整的结构与坐标。
3. **对照 B7/G2a**:
   - **B7 的盲点**: 几何通过 RPEncoding 仅改变注意力的 `total_scores`。若源节点（如纯 Si）初始特征 `v` 全同，则不管权重如何，加权和 `sum(w*v)` 仍全同。
   - **相对 G2a 的提升**: G2a (`g2_periodic_edges.py`) 的 `v_src * gate(d)` 解决了内容注入，但只有径向距离。ComFormer 引入了相对方向和周期参考向量，捕获了角度与配位构型。
4. **适配与推广**: 在同质 Value 下，只要角度/方向不同，内容就会破缺。完全可以推广至项目的连续谱输出。
5. **接口与依赖**: 可保留当前原子 memory、decoder 和 H1 接口。直接替换 Encoder 即可。但作者代码强依赖 `e3nn` 和 `torch_geometric`，在本项目零额外依赖的原则下需自行手写张量积/球谐聚合模块，资源成本较高。
6. **最强证据与反证**:
   - **支持证据**: 在 Material Project 形成能和带隙任务上达到 SOTA，证明等变方向表示对晶格有效。
   - **最强反证**: G2a 在 Q1 上增加了 27% 耗时但 R2 无提升；单元素在 valid 仅占 1.60%。等变操作的 OOM 风险和极高耗时可能直接导致项目不可用，且没有证据表明带隙的增益能平移到连续的高维 DOS 谱上。

## 机制二：ALIGNN 的键角线图组织 (USNIST)

1. **来源与版本**: npj Comput Mater 2021, github `usnistgov/alignn`, v2025.4.1。关键代码：`EdgeGatedGraphConv.forward`, `ALIGNNConv.forward`。
2. **解释 (I/O 与计算)**: 显式构建原子图（节点为原子，边为键）和线图（节点为键，边为键角）。消息在原子-键，以及键-键之间交替传递。几何以角度的形式直接进入线图的节点特征。聚合方式为带 `eps` 的门控归一化。
3. **对照 B7/G2a**: 不是在一次消息中融合所有几何，而是让“边（键）”拥有自己独立的隐层特征，并由角度更新。B7 和 G2a 均缺乏边级别的持久化记忆。
4. **适配与推广**: 对于全连接的 Transformer，边数为 O(N^2)，其线图边数高达 O(N^3)。
5. **接口与依赖**: 极难直接适配 TransformerEncoder。依赖 `dgl`，图构建逻辑与当前 `utils/relative_features.py` 的稠密张量计算不兼容。
6. **最强证据与反证**:
   - **支持证据**: ALIGNN (2021) 和后续 ALIGNN-phDOS 表明其在声子带和性质预测上极为有效。
   - **最强反证**: 其归一化聚合在同质网络下如果忽略 `eps` 门控会被完全消去；更致命的是线图构造在多镜像周期条件下面临指数级的内存爆炸，无法在全连通的 M1 架构中以低成本推广。

## 机制三：Mat2Spec 的结构—谱潜空间对齐 (Contrastive Alignment)

1. **来源与版本**: github `gomes-lab/Mat2Spec` (2023 框架)。
2. **解释 (I/O 与计算)**: 这是一条**直接针对 DOS 预测**的机制。Mat2Spec 不仅训练结构 GNN，还通过变分自编码器（VAE）或对比学习（Contrastive Learning）将真实的连续 DOS 谱压缩到低维连续潜空间。结构的 memory 被强制与真实的 DOS 潜空间对齐。推理时依靠生成或解码。
3. **对照 B7/G2a**: 跳出了“如何更好地把几何输入网络”的限制，解决了“如何更好地监督高维复杂的输出”的难题。当前 `status.md` 中提到 B7 对于高粗糙度组预测过度平滑（over-smoothing）。KL/Huber 属于点对点强回归，在尖峰微小错位时会产生巨大的惩罚。潜空间对齐容忍了微小的横向偏移，更注重宏观拓扑。
4. **适配与推广**: 完美兼容现有的 B7 架构，不改变推理的前向传播。
5. **接口与依赖**: 无需任何第三方图网络库，保留所有 memory、decoder 和 H1。只需在训练时加入一个处理 target 的 CNN Encoder。
6. **最强证据与反证**:
   - **支持证据**: 针对高维连续谱预测设计的机制，直接打击当前“高粗糙度组 eDOS 预测平滑”的痛点。
   - **最强反证**: 项目之前尝试过 E10 宏观状态、G2 谱差读出等，均因为无法有效把全局损失分配到具体的局部原子而被搁置（见 status 中冻结探针的结果）。全局潜空间对齐可能导致原子级表征反而退化。

## 最终推荐机制讨论 (Recommendations)

### 推荐一：几何内容直接门控 (启发自 ComFormer)

- **项目限制**: B7 同质原子的配位盲点，以及 G2a 仅具备径向响应（`status.md`：G2a无精度 win 且 G2 联合适配无支持）。
- **机制假设**: 如果将原子间的相对方向矢量（或其余弦角度）映射后，通过哈达玛乘积直接作用于 `v_heads`，可以轻量级地打破对称性，并允许模型感知四面体/八面体等方向拓扑，且避免 `e3nn` 的极高开销。
- **论文公式**: `h'_i = sum_j f(h_j) * gate_angle(r_ij) * gate_dist(d_ij)`
- **作者代码**: 简化版 `ComformerConv.message`，在内容端注入几何。
- **项目修改位置**: `model/transformer.py::TransformerEncoderLayer.forward`，在计算 `v_heads` 后，将其与 `rp_emb` 衍生的内容掩码相乘，然后再进行 `attn_weights` 聚合。
- **替代解释**: 性能可能只来自于参数量的增加，而非物理角度。
- **验证结果会改变决定**: Q1 M1x10 pilot。若此非等变、纯角度标量门控能在不增加 5% 显存的情况下，使得 eDOS/phDOS 中位 R2 改善 > 0.02 且失败率持平，则证明角度/方向内容比径向更有效。具体例子：纯硅 (Si) 的不同多形体，距离相近但键角不同。B7 由于同质节点特征相同，无法区分；加入键角条件后，模型能感知到 tetrahedral 还是其他配位。

### 推荐二：谱形对比对齐先验 (启发自 Mat2Spec)

- **项目限制**: 当前 KL/W1/Huber 直接回归在面对高粗糙度、多尖峰的 DOS 时遭遇过平滑（`status.md`: 粗糙度偏差中位数 `-0.318`，高梯度边误差占比增高）。
- **机制假设**: 直接回归使模型在遇到位置不确定性时倾向于预测“均值平缓曲线”以最小化期望损失。通过在训练期引入一个预训练或联合训练的“谱形 Encoder”，将 `h_crystal` 与真实谱的潜向量做余弦对齐（Contrastive Loss），能迫使网络保留尖峰特征先验。
- **论文公式**: `L_total = L_recon + lambda * (1 - cosine_sim(Encoder_S(X), Encoder_DOS(Y)))`
- **代码实现**: 类似对比学习 loss。
- **项目修改位置**: `model/transformer.py` 的 forward 补充可选的 DOS input 通路，训练代码中引入对比损失。
- **替代解释**: 表现改善可能仅仅是正则化效应或损失权重的隐式改变。
- **验证结果会改变决定**: 开启对比辅助损失进行 Q1 pilot。若高粗糙度组的预测形状 TV (Total Variation) 显著改善且中位 R2 提升，则采用。
- **具体例子**: 两组相似材料，真实谱在高频有一个窄而高的声子带。传统 Huber 预测如果峰偏了 1 个 bin，会受双倍惩罚（没猜中的地方和错猜的地方）；模型因此学得“矮胖”。潜空间对齐允许模型先学到“这里需要一个尖峰”的宏观概念（潜向量匹配），再由局部微调，从而保留谱的粗糙度。

## 未核实项与自检结论

- **最强反证归纳**: 任何额外复杂的图计算或对比学习都会大幅增加原本就吃紧的 V100 训练时间和内存。从 G2a 和已 park 的机制实验看，模型当前的精度瓶颈可能不仅在“几何表示力”，而在全局/局部特征到 128 bin 分布的非线性映射（Decoder 端）上。
- **未核实项**: 没有验证 `divelab/AIRS` 和 `alignn` 源码的第三方环境（如 `e3nn`、`dgl`）在当前项目基础设施下能否成功编译运行。Mat2Spec 潜空间对齐所需的额外超参 `lambda` 和 Encoder 结构暂无最佳默认值。
- **自检**: 已核对引用来源、机制核心计算和对代码修改位置的具体建议。无 Git 写操作，没有启动训练，符合只读、非侵入性调研原则。
