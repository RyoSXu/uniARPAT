## 结论

- **判读为“环境主导”**：只保留元素先验的 M0 相对 h2 联合 Δ −0.0011（区间 [−0.0042, +0.0021]，含 0），与 h2 分不开；
  相对 M1 差 +0.0069（区间不含 0）。M1 的收益依赖每原子的局部环境信息，不是“更好的元素嵌入”。
- **eDOS 读数为“环境”**：M0 的 eDOS 与 h2 完全相同（Δ 0.0000），M1 的 eDOS 收益（−0.0134）全部消失。
- **phDOS 分不开**：M0 与 M1 的 phDOS 都比 h2 低约 0.002（区间都含 0），与 M1 时一样在噪声内，无法归因。
- **同组成材料**：M1 区分同组成不同结构材料谱差的能力（技能 0.025–0.044）在 M0 回到 h2 水平（0.002–0.026），与“环境信息起作用”一致（诊断）。
- **train/valid**：M0 的 train/valid 比（约 0.60）接近 h2（0.62–0.63），不像 M1（0.47–0.54）那样拉大；M1 多出的拟合能力也来自环境信息。
- 含义：预训练得到的**结构相关原子表示**是有效杠杆。按设计，下一步可深挖预训练表示（更多通道、更大模型、微调）并设计自研结构预训练。
  需注意 MPtrj 含评估结构（无 DOS），环境表示正是可能“记住”这些结构的部分，定稿时须用干净留出或不重叠的预训练数据复查。
