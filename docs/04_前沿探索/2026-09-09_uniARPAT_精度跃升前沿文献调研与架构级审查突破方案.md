## 1. 执行纲要

在完成 Week-2 的 100 轮消融实验（M1-M5）并彻底根治 Step 2 中的四大 P0 级代码工程缺陷（对齐 Mask、修复倒格矢、阻断 Padding 泄露、注入 Query 梯度）后，uniARPAT 已经具备了一个坚实可靠的 Baseline。然而，当前模型在物理能谱逼真度上仍面临两大核心天花板：
1. **电子能谱（eDOS）中位 $R^2$ 徘徊在 $0.48 \sim 0.49$，失败率约 $12\%$**：主要表现为带隙边缘（Band Edge）变钝、绝缘体伪态泄漏、以及费米面附近的 Van Hove 奇异点尖峰被过度平滑；
2. **声子能谱（phDOS）中位 $R^2$ 约为 $0.682$，$\Theta_D$ 与 $\kappa_L$ 误差受低频声学支主导**：声学支在 $\omega \to 0$ 处未受到物理德拜色散律 $\omega^2$ 的梯度硬约束。

通过系统调研 2024–2026 年材料科学与机器学习顶级会议/期刊论文，并深入审查本地现有代码，我们发现：**无需引入复杂的生成式扩散模型，仅通过在现有 Transformer 主干上做物理信息流的“升维修复”、“先验注入”与“导数约束”，即可释放巨大的精度红利**。

## 2. 前沿文献调研与先进技术迁移矩阵（2024–2026）

| 文献与模型 | 核心机理 | 现有缺陷对应点 | 迁移方案与在 uniARPAT 的落地形态 |
| :--- | :--- | :--- | :--- |
| **DOSTransformer**<br>*(NeurIPS 2023, Noh et al.)* | 1. 将连续能量划分为独立模态，通过 Cross-Attention 实现原子-能量交互；<br>2. 引入 7 大晶系（Cubic, Hexagonal等）作为 Prompt 引导。 | 当前 `edos_query_embed` 是完全随机的离散静态参数；模型不知晶胞宏观对称性。 | 1. 将随机 query 替换为**连续物理能量坐标嵌入**；<br>2. 从晶格参数直接解析 7 大晶系，作为晶体 Prompt Token 注入编码器。 |
| **PotNet**<br>*(ICLR 2023, Lin et al.)* | 基于 Ewald 求和将实空间与倒易空间电荷势能、色散势能（Coulomb $1/r$、London $1/r^6$）整合为完备边特征，攻克 MIC 截断截失。 | `relative_features.py` 采用简单 MIC 折回，对于小晶胞丢弃了第二配位壳层以上的长程势场。 | 在相对距离 RBF 之外，直接解析晶胞体积与多周期镜像距离，构建近似 Ewald 长程静电衰减特征。 |
| **FEDONet / 连续神经算子**<br>*(JCP 2025/2026, Sojitra et al.)* | 证明标准 MLP 存在“谱偏置（Spectral Bias）”，优先拟合低频平滑轮廓；通过随机傅里叶特征（RFF）$\gamma(E)=[\sin(2\pi B E), \cos(2\pi B E)]$ 扩展假设空间，高频误差暴降 70%。 | MSE/Smooth-L1 将 eDOS 的 Van Hove 奇异点尖峰严重抹平。 | 在能谱解码器 Trunk/Head 中引入能量高频傅里叶投影层，强化尖峰锐度。 |
| **Mat2Spec**<br>*(Nat. Commun. 2022, Kong et al.)* | 证明在能谱归一化分布空间下，Wasserstein-1 距离与 SumNorm-KL 在带隙分类与形状保真度上显著优于 MSE，避免了局部平移导致的 $R^2$ 崩溃。 | 点对点 Smooth-L1 对带隙位置轻微偏移惩罚过大，但在平坦区域无法提供充足梯度。 | 损失函数中引入一阶导数（Total Variation/Gradient）正则与微弱的带隙 KL 散度约束。 |
| **PhysMoE 混合专家**<br>*(2025–2026 稀疏 MoE 科学计算进展)* | 金属（$E_F$ 处连续高 DOS）、窄带隙半导体、绝缘体（宽带隙零 DOS）拓扑差异巨大。采用晶体级门控路由器分配不同 FFN 专家。 | 统一解码器导致金属高峰与绝缘体平坦基线的梯度严重冲突。 | 在解码器 FFN 层引入 4 专家晶体级稀疏路由（Top-2 激活），参数量仅增 ~2M，计算量几乎不变。 |

## 3. 现有代码逻辑与架构缺陷的深度审查（五大突破口）

### 3.1 突破口一：原子物理特征的严重“秩亏损”（致命信息瓶颈）
- **代码位置**：[`utils/atom_feature.py:61-84`](file:///root/home/newstudy/uniARPAT/utils/atom_feature.py#L61-L84) 与 [`model/transformer.py:47`](file:///root/home/newstudy/uniARPAT/model/transformer.py#L47)
- **现状审查**：
  ```python
  # atom_feature.py:61-66
  self.feature = np.array([
      self.get_atomic_mass(),
      self.get_atomic_radius(),
      self.get_electronegativity()
  ]).T  # 形状为 [118, 3]
  ...
  # transformer.py:47
  self.num_emb_encoder = AtomFeatureEncoder(input_dim=3, out_dim=d_model)
  # 其中 self.proj = nn.Linear(3, 512)
  ```
- **病理诊断**：
  1. **代数秩亏损**：将一个 3 维特征向量经过单层无激活线性变换 `Linear(3, 512)`，其输出张量在 512 维特征空间中的代数秩（Rank）**最大不超过 3**！整整 509 个基向量是完全线性相关的冗余空间；
  2. **信息遗漏**：而在 [`utils/periodic_table_v2.csv`](file:///root/home/newstudy/uniARPAT/utils/periodic_table_v2.csv) 中，整整拥有 **29 列** 珍贵微观量子物理参数：
     - 原子价电子分布：`NsValence`, `NpValence`, `NdValence`, `NfValence`, `NValence`（直接决定费米面附近的电子杂化轨道与能带成键/反键特征）；
     - 未填满轨道计数：`NsUnfilled`, `NpUnfilled`, `NdUnfilled`, `NfUnfilled`；
     - 能量标度：第一电离能 `IonizationEnergy`、电子亲和能 `ElectronAffinity`；
     - 周期律：周期 `Row`、主族 `Column`、晶体密度 `Density`、熔点 `MeltingPoint`。
- **改进方案**：
  - 将输入特征扩充至 24 维真实物理化学特征；
  - 投影层升级为两层带非线性激活的 MLP：`Linear(24, 128) -> GELU -> Linear(128, 512)`，彻底激活 512 维隐空间的表征秩。

### 3.2 突破口二：宏观晶胞（Lattice/Cell）全局物理量的“严重断层”
- **代码位置**：[`model/transformer.py:122-152`](file:///root/home/newstudy/uniARPAT/model/transformer.py#L122-L152) 与 [`utils/relative_features.py:16-48`](file:///root/home/newstudy/uniARPAT/utils/relative_features.py#L16-L48)
- **现状审查**：
  ```python
  # transformer.py:124-129
  B, Lp, _ = pos.shape
  atom_len = Lp - 2
  mask_atom = mask[:, 2:2 + atom_len]
  atom_idx = src[:, 2:]  # 剥离前两行哨兵
  # 前两行是 lattice (a,b,1/c) 和 angles (alpha,beta,gamma)
  distances, unit_dirs = compute_relative_features(pos)
  memory = self.encoder(src=atom_src, ...) # 仅有原子 token!
  ```
- **病理诊断**：
  1. 晶格参数 $(a, b, c, \alpha, \beta, \gamma)$ 仅仅被用于在 `compute_relative_features` 中将分数坐标转为实空间笛卡尔距离；
  2. **宏观物理标量完全丢失**：
     - 晶胞真实体积 $V = \mathbf{a} \cdot (\mathbf{b} \times \mathbf{c})$；
     - 晶胞密度 $\rho = \frac{\sum M_i}{V \cdot N_A}$ 与平均原子体积 $V_{\text{atom}} = V / N_{\text{atoms}}$；
     - 7 大晶系（Cubic, Tetragonal, Orthorhombic, Hexagonal, Trigonal, Monoclinic, Triclinic）的对称性信息。
  3. **理论错位**：根据金属自由电子气模型，态密度幅值与 $V$ 直接成正比；根据声子德拜模型，截止频率反比于平均原子间距 $(V/N)^{1/3}$。目前模型在没有体积先验的情况下，迫使注意力机制去“猜”晶胞体积。
- **改进方案**：
  - 构造 `GlobalCellEncoder`，计算标量 $[V, \rho, a, b, c, \alpha, \beta, \gamma, V_{\text{atom}}]$ 及晶系类别，投影为 1 个全局晶体 Token，置于 Encoder 序列首位（类似 ViT 的 `[CLS]` Token），参与全程自注意力。

### 3.3 突破口三：解码器 Query 的“连续能量坐标感知缺失”
- **代码位置**：[`model/transformer.py:84-89, 155-186`](file:///root/home/newstudy/uniARPAT/model/transformer.py#L84-L89)
- **现状审查**：
  ```python
  self.edos_query_embed = nn.Parameter(torch.zeros(edos_num, d_model))
  self.edos_tgt = nn.Parameter(torch.zeros(edos_num, d_model))
  ...
  # 在 _reset_parameters 中：
  nn.init.xavier_normal_(p)  # 随机高斯初始化
  ```
- **病理诊断**：
  1. `edos_query_embed`（128）与 `phdos_query_embed`（64）是 100% 自由可学习参数，没有任何物理能量坐标先验；
  2. 真实物理能量网格具有明确的物理意义：
     - eDOS: $E_i \in [-10.0, 10.0]\text{ eV}$，且 $E = 0$ 是绝对意义的费米能级；
     - phDOS: $\nu_j \in [-280.0, 980.0]\text{ cm}^{-1}$，且 $\nu = 0$ 是声学支零频极限；
  3. 缺乏坐标先验导致 Query 在自注意力中无法利用临近能量的相关性（例如 $E_i$ 与 $E_{i+1}$ 能量相距仅 $0.156\text{ eV}$，物理态必然高度相关），需要极多 epoch 才能重建一维拓扑。
- **改进方案**：
  - 引入**连续能量坐标编码（Continuous Energy Coordinate Encoding）**：
    $$E_i = -10.0 + i \cdot \frac{20.0}{128}, \quad \gamma(E) = \left[\sin(2\pi \cdot 2^k E / L), \cos(2\pi \cdot 2^k E / L)\right]_{k=0}^{K-1}$$
  - 将坐标编码通过轻量 MLP 注入 `query_pos`，使解码器天生具备能量连续性与费米面归纳偏置。

### 3.4 突破口四：编码器内部的死参数与球谐特征重复计算
- **代码位置**：[`model/transformer.py:291, 304-312`](file:///root/home/newstudy/uniARPAT/model/transformer.py#L291)
- **现状审查**：
  ```python
  # TransformerEncoderLayer.__init__
  self.self_attn = nn.MultiheadAttention(...)  # 未使用 (0.52M 死参数)
  self.rbf_encoder = RBFEncoding(...)          # 未使用 (死变量)
  self.rel_proj = nn.Linear(64, d_model)       # 未使用 (0.03M 死参数)
  self.dir_proj = nn.Linear(dim_sph, d_model)  # 未使用 (0.01M 死参数)
  self.rp_encoder = RPEncoding(num_radial=64, lmax=2, cutoff=10.0) # 6层各实例化一个
  ```
- **病理诊断**：
  1. 6 层 Encoder 均实例化了独立的 `rp_encoder`。然而 `distances` 与 `unit_dirs` 在 6 层之间完全恒定，`RPEncoding` 内部没有可学习权重，导致在每个 batch、每个 layer 重复计算 6 次昂贵的 $O(B \cdot L^2)$ `spherical_harmonics`（显存峰值与延迟的元凶）；
  2. 死参数占据约 $3.5\text{M}$ 参数量，污染显存。
- **改进方案**：
  - 清理未使用的死参数与死模块；
  - 将 `RPEncoding` 提升为 Transformer 顶层计算一次并跨 6 层复用缓存，节约约 30% 显存与 20% 前向时间。

### 3.5 突破口五：损失函数“等权盲点”与谱线一阶导数（Gradient/TV）正则缺失
- **代码位置**：[`model/model.py:171-174`](file:///root/home/newstudy/uniARPAT/model/model.py#L171-L174)
- **现状审查**：
  ```python
  loss_edos = F.smooth_l1_loss(predict_edos, edos_target)
  loss_phdos = F.smooth_l1_loss(predict_phdos, phdos_target)
  total_loss = loss_edos + 1.0 * loss_phdos
  ```
- **病理诊断**：
  1. **缺乏一阶导数正则（Van Hove 奇异点与带隙模糊）**：点对点 Smooth-L1 只惩罚幅值，对斜率（一阶导数）毫无感知。这使得模型倾向于在带隙跃迁处产生平缓过渡（过度平滑）；
  2. **能谱等权对待（物理不敏感）**：
     - eDOS 中，费米面附近的电子态（$E \in [-1.5, 1.5]\text{ eV}$）直接决定导电性与塞贝克系数，而深能级（$-10\text{ eV}$）对物性几乎无贡献；
     - phDOS 中，低频声学支直接决定晶格比热 $C_v$（$T^3$ 定律）与晶格热导率 $\kappa_L$（Slack 公式中 $\Theta_D^3$ 放大），超高频微小误差远不如低频关键。
- **改进方案**：
  - 增加**谱线梯度一致性损失（Spectral Gradient Loss）**：
    $$\mathcal{L}_{\text{grad}} = \frac{1}{N-1} \sum_{i=1}^{N-1} |\Delta \hat{y}_i - \Delta y_i|, \quad \text{where } \Delta y_i = y_{i+1} - y_i$$
  - 增加**费米面与声学支物理敏感加权掩码**：动态提升带隙边缘与低频声学支在总损失中的贡献度。
